1. **Title**: PAT-Agent: Autoformalization for Model Checking (arXiv:2509.23675)
   - **Authors**: Xinyue Zuo, Yifan Zhang, Hongshu Wang, Yufan Cai, Zhe Hou, Jing Sun, Jin Song Dong
   - **Summary**: This paper introduces PAT-Agent, a framework that combines large language models (LLMs) with formal verification tools to automate the creation of verifiable formal models from natural language descriptions. It employs a planning LLM to extract key modeling elements and a code generation LLM to synthesize formal models, which are then verified using the Process Analysis Toolkit (PAT). A repair loop iteratively corrects models based on counterexamples, enhancing verification success and efficiency.
   - **Year**: 2025

2. **Title**: SLD-Spec: Enhancement LLM-assisted Specification Generation for Complex Loop Functions via Program Slicing and Logical Deletion (arXiv:2509.09917)
   - **Authors**: Zehan Chen, Long Zhang, Zhiwei Zhang, JingJing Zhang, Ruoyu Zhou, Yulong Shen, JianFeng Ma, Lin Yang
   - **Summary**: SLD-Spec addresses the challenge of generating formal specifications for programs with complex loop structures. The method introduces program slicing to decompose functions into simpler fragments and logical deletion to filter out incorrect candidate specifications using LLM-based reasoning. This approach improves the correctness, relevance, and completeness of generated specifications, facilitating more effective program verification.
   - **Year**: 2025

3. **Title**: FVEL: Interactive Formal Verification Environment with Large Language Models via Theorem Proving (arXiv:2406.14408)
   - **Authors**: Xiaohan Lin, Qingxing Cao, Yinya Huang, Haiming Wang, Jianqiao Lu, Zhengying Liu, Linqi Song, Xiaodan Liang
   - **Summary**: FVEL presents an interactive environment that integrates LLMs with formal verification through automated theorem proving. It transforms code into Isabelle formal language and utilizes neural theorem proving to verify correctness. The approach leverages the structured rules of Isabelle and the adaptability of LLMs, demonstrating improved verification success rates on benchmarks like Code2Inv and SV-COMP.
   - **Year**: 2024

4. **Title**: VeCoGen: Automating Generation of Formally Verified C Code with Large Language Models (arXiv:2411.19275)
   - **Authors**: Merlijn Sevenhuijsen, Khashayar Etemadi, Mattias Nyberg
   - **Summary**: VeCoGen combines LLMs with formal verification to automate the generation of C programs that meet formal specifications. Starting with an ANSI/ISO C Specification Language (ACSL) specification, it generates candidate programs and iteratively refines them until they satisfy the formal requirements. Evaluated on Codeforces problems, VeCoGen successfully solves a majority, showcasing the potential of integrating LLMs with formal methods for reliable code generation.
   - **Year**: 2024

6. **Title**: CodeMirage: Hallucinations in Code Generated by Large Language Models (arXiv:2408.08333)
   - **Authors**: Vibhor Agarwal, Yulong Pei, Salwa Alamir, Xiaomo Liu
   - **Summary**: CodeMirage investigates hallucinations in code generated by LLMs, where the models produce plausible but incorrect code snippets. The study introduces a taxonomy of code hallucination types and presents the CodeMirage dataset, containing hallucinated code snippets. It evaluates various LLMs' abilities to detect these hallucinations and discusses mitigation strategies, highlighting the need for improved reliability in LLM-generated code.

8. **Title**: Large Language Models have Intrinsic Self-Correction Ability (arXiv:2406.15673)
   - **Authors**: Dancheng Liu, Amir Nassereldine, Ziming Yang, Chenhui Xu, Yuting Hu, Jiajie Li, Utkarsh Kumar, Changjae Lee, Jinjun Xiong
   - **Summary**: This study examines the intrinsic self-correction capabilities of LLMs, where models can revise their outputs without external feedback. **Key Challenges:**

1. **Ambiguity in Natural Language Specifications**: Translating user intent from natural language into precise formal specifications is challenging due to inherent ambiguities and variability in human language.

2. **Ensuring Correctness of LLM-Generated Code**: LLMs may produce code that appears correct but contains subtle errors or vulnerabilities, necessitating robust verification mechanisms to ensure reliability.

3. **Scalability of Formal Verification Methods**: Traditional formal verification tools often struggle with scalability, especially when applied to complex or large-scale codebases, limiting their practical applicability.

4. **Integration of LLMs with Formal Methods**: Effectively combining the generative capabilities of LLMs with the rigor of formal verification requires careful design to address potential inconsistencies and ensure seamless interaction.

5. **Handling Complex Code Structures**: Generating and verifying specifications for code with intricate structures, such as nested loops or concurrent processes, remains a significant challenge due to increased complexity and potential for errors.
