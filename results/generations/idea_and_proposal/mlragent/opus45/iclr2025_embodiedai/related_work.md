1. **Title**: Mem4Nav: Boosting Vision-and-Language Navigation in Urban Environments with a Hierarchical Spatial-Cognition Long-Short Memory System (arXiv:2506.19433)
   - **Authors**: Lixuan He, Haoyu Dong, Zhenxing Chen, Yangcheng Yu, Jie Feng, Yong Li
   - **Summary**: Mem4Nav introduces a hierarchical spatial-cognition memory system for vision-and-language navigation in large-scale urban environments. It combines a sparse octree for fine-grained voxel indexing with a semantic topology graph for high-level landmark connectivity. The system employs long-term memory to retain historical observations and short-term memory for real-time obstacle avoidance and local planning, leading to significant improvements in task completion and path efficiency.
   - **Year**: 2025

2. **Title**: CityNavAgent: Aerial Vision-and-Language Navigation with Hierarchical Semantic Planning and Global Memory (arXiv:2505.05622)
   - **Authors**: Weichen Zhang, Chen Gao, Shiquan Yu, Ruiying Peng, Baining Zhao, Qian Zhang, Jinqiang Cui, Xinlei Chen, Yong Li
   - **Summary**: CityNavAgent addresses the challenges of aerial vision-and-language navigation in urban environments by introducing a hierarchical semantic planning module that decomposes long-horizon tasks into sub-goals. It also incorporates a global memory module that stores historical trajectories in a topological graph, enabling efficient navigation and improved performance in continuous city environments.
   - **Year**: 2025

3. **Title**: SSR-ZSON: Zero-Shot Object Navigation via Spatial-Semantic Relations within a Hierarchical Exploration Framework (arXiv:2509.24763)
   - **Authors**: Xiangyi Meng, Delun Li, Zihao Mao, Yi Yang, Wenjie Song
   - **Summary**: SSR-ZSON proposes a zero-shot object navigation method that integrates spatial-semantic relations within a hierarchical exploration framework. It utilizes a viewpoint generation strategy that balances spatial coverage and semantic density, along with an LLM-based global guidance mechanism to direct navigation towards high-value spaces, resulting in improved success rates and path efficiency.
   - **Year**: 2025

4. **Title**: Aeon: High-Performance Neuro-Symbolic Memory Management for Long-Horizon LLM Agents (arXiv:2601.15311)
   - **Authors**: Mustafa Arslan
   - **Summary**: Aeon introduces a neuro-symbolic cognitive operating system that structures memory into a spatial index and an episodic graph. It features a Semantic Lookaside Buffer for predictive caching, achieving sub-millisecond retrieval latencies. This system addresses the limitations of LLMs in handling long-horizon interactions by providing persistent, structured memory management.
   - **Year**: 2026

**Key Challenges**:

1. **Persistent and Structured Spatial Memory**: Developing memory systems that can effectively store and retrieve hierarchical spatial information over long time horizons remains a significant challenge.

2. **Integration of Multimodal Information**: Combining visual, semantic, and spatial data into a cohesive memory structure that LLM agents can utilize for navigation and reasoning is complex.

3. **Scalability in Large-Scale Environments**: Ensuring that hierarchical spatial memory networks can scale efficiently to handle the vast and dynamic nature of open city environments is difficult.

4. **Generalization to Unseen Areas**: Enabling LLM agents to generalize learned navigation strategies and memory structures to unfamiliar urban areas without extensive retraining poses a challenge.

5. **Human-Agent Collaboration**: Designing interpretable memory structures that facilitate effective collaboration between human users and LLM agents in urban applications requires careful consideration.
