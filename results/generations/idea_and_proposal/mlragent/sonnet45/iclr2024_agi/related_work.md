1. **Title**: Towards a Neurosymbolic Reasoning System Grounded in Schematic Representations (arXiv:2509.03644)
   - **Authors**: François Olivier, Zied Bouraoui
   - **Summary**: This paper introduces Embodied-LM, a neurosymbolic system that grounds understanding and logical reasoning in schematic representations derived from sensorimotor experiences. By operationalizing these cognitive structures using declarative spatial reasoning within Answer Set Programming, the system enhances LLMs' interpretability and effectiveness in logical deduction tasks.
   - **Year**: 2025

2. **Title**: Making LLMs Reason? The Intermediate Language Problem in Neurosymbolic Approaches (arXiv:2502.17216)
   - **Authors**: Alexander Beiser, David Penz
   - **Summary**: This study addresses the challenge of selecting suitable formal intermediate languages for neurosymbolic systems. It highlights how LLMs' difficulties in distinguishing syntax from semantics impact their performance in translating natural language into formal representations, emphasizing the need for carefully chosen intermediate languages to improve reasoning capabilities.
   - **Year**: 2025

3. **Title**: Improving Rule-based Reasoning in LLMs via Neurosymbolic Representations (arXiv:2502.01657)
   - **Authors**: Varun Dhanraj, Chris Eliasmith
   - **Summary**: The authors propose a method that encodes LLM hidden states into neurosymbolic vectors, facilitating problem-solving within a neurosymbolic vector space. This approach offloads computation through neurosymbolic representations, enhancing efficiency, reliability, and interpretability in numerical reasoning tasks.
   - **Year**: 2025

4. **Title**: SymCode: A Neurosymbolic Approach to Mathematical Reasoning via Verifiable Code Generation (arXiv:2510.25975)
   - **Authors**: Sina Bagheri Nezhad, Yao Li, Ameeta Agrawal
   - **Summary**: SymCode reframes mathematical problem-solving as verifiable code generation using the SymPy library. By grounding LLM reasoning in a deterministic symbolic engine, it achieves significant accuracy improvements on benchmarks like MATH-500 and OlympiadBench, offering more accurate and trustworthy AI in formal domains.
   - **Year**: 2025

5. **Title**: REACT: Synergizing Reasoning and Acting in Language Models (arXiv:2210.03629)
   - **Authors**: Shunyu Yao, Jeffrey Zhao, Dian Yu, Nan Du, Izhak Shafran, Karthik Narasimhan, Yuan Cao
   - **Summary**: REACT explores the integration of reasoning traces and task-specific actions in LLMs, allowing for greater synergy between the two. This approach enhances performance on tasks like question answering and fact verification by interacting with external sources and generating human-like task-solving trajectories.
   - **Year**: 2023

6. **Title**: BINDER: Binding Language Models in Symbolic Languages (arXiv:2210.02875)
   - **Authors**: Zhoujun Cheng, Tianbao Xie, Peng Shi, Chengzu Li, Rahul Nadkarni, Yushi Hu, Caiming Xiong, Dragomir Radev, Mari Ostendorf, Luke Zettlemoyer, Noah A. Smith, Tao Yu
   - **Summary**: BINDER is a training-free neural-symbolic framework that maps task inputs to programs, allowing LLMs to extend their grammar coverage and tackle diverse questions. It employs GPT-3 Codex as both the program parser and the underlying model, achieving state-of-the-art results on datasets like WIKITABLEQUESTIONS and TABFACT with minimal annotations.
   - **Year**: 2023

**Key Challenges:**

1. **Intermediate Language Selection**: Choosing appropriate formal intermediate languages for neurosymbolic systems is critical, as LLMs often struggle to distinguish between syntax and semantics, impacting their translation accuracy.

2. **Integration Complexity**: Developing architectures that effectively combine neural networks with symbolic reasoning engines requires careful design to ensure seamless collaboration and bidirectional communication.

3. **Interpretability and Verification**: Ensuring that the outputs of neurosymbolic systems are interpretable and verifiable remains a significant challenge, particularly in complex reasoning tasks.

4. **Scalability**: Scaling neurosymbolic approaches to handle large datasets and diverse problem domains without compromising performance or accuracy is an ongoing concern.

5. **Generalization**: Enabling neurosymbolic systems to generalize across various tasks and domains, especially those requiring multi-step logical reasoning and constraint satisfaction, is a key hurdle in achieving AGI-level reasoning.
