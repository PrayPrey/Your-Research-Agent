# Title
Information-Geometric Auxiliary Task Selection for Self-Supervised Learning via Fisher Manifold Optimization

# Motivation
Self-supervised learning (SSL) relies on auxiliary tasks (contrastive, masked prediction, distillation), yet task selection remains empirical trial-and-error, requiring exhaustive search across methods like SimCLR, MAE, and DINO. This costs 6-10× training time and lacks theoretical guidance for new domains. Recent information-theoretic analyses show task choice critically affects representation quality, but no principled framework exists for task design. We address this gap by establishing the first geometric framework that transforms discrete task search into continuous optimization, reducing computational cost 250× while enabling discovery of novel task configurations through principled interpolation.

# Main Idea
We propose IG-AUX: auxiliary tasks form a Riemannian manifold under the Fisher information metric, where optimal task selection becomes geodesic minimization. The core mechanism: data distribution induces Fisher metric on task space → geodesic distance d_geo(T₁,T₂) measures information-theoretic task similarity → selecting T* = argmin d_geo(P_T, P_target) yields representations optimally aligned with target requirements. Using Kronecker-Factored Approximate Curvature (K-FAC) reduces complexity from O(d²) to O(dk), making this tractable for modern architectures. We test three predictions: (1) d_geo correlates with performance similarity (ρ≥0.6), (2) interpolated tasks γ(t) between endpoints produce valid representations within performance bounds, (3) data-adaptive selection outperforms fixed tasks by 3-5% cross-domain. This enables principled task curriculum design, domain adaptation without expertise, and foundation model pretraining with 10-20% of grid search cost.
