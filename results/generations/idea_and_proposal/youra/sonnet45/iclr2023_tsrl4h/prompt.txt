# Title
Fairness-Aware Contrastive Learning with Subgroup-Adaptive Augmentation for Healthcare Time Series

# Motivation
Healthcare time series analysis faces critical challenges: limited labeled data, patient subgroup imbalances (pediatric/adult/elderly), and missing values. Current self-supervised learning methods apply uniform augmentation strategies, causing fairness gaps of 12-20% across age groups—minority populations like pediatric ICU patients suffer degraded performance. This threatens equitable clinical deployment and exacerbates healthcare disparities in underrepresented groups.

# Main Idea
We hypothesize that **subgroup-adaptive augmentation policies combined with fairness-constrained optimization** will reduce fairness gaps to <5% while maintaining robustness to 30-50% missing data. The causal mechanism operates through three steps: (1) physiologically-informed augmentation (pediatric: 20% masking for short-duration patterns; elderly: elevated noise simulation) creates subgroup-appropriate representations; (2) fairness constraints (max performance gap <5%) prevent majority group dominance during contrastive learning; (3) fair pretraining transfers to downstream tasks with missing-pattern-specific robustness. 

We will test this on MIMIC-III/IV using stratified 5-fold cross-validation, comparing against COMET baseline. Success requires ≥60% fairness gap reduction (from ~15% to <5%) and AUROC >0.75 on missing data. Falsification occurs if fairness gap ≥10% or robustness <0.70, indicating mechanism failure. This enables equitable clinical AI for minority patient populations.

### 1.3 Causal Mechanism

**3-Step Causal Chain (N=3):**

**Step 1: Subgroup-adaptive augmentation policies → Subgroup-appropriate representation quality**
- **Mechanism:** Pediatric data augmented with low masking (20% vs 40% baseline) preserves short-duration patterns critical for pediatric diagnosis (faster heart rates, shorter episodes). Elderly data augmented with elevated noise simulation (0.15 vs 0.1 jitter) builds robustness to sensor artifacts common in elderly patients (more comorbidities, sensor failures). Each subgroup's representation learns from physiologically-appropriate augmentations rather than one-size-fits-all strategy.
- **Falsification:** If within-subgroup SSL convergence is identical for adaptive vs uniform augmentation, this link fails.

**Step 2: Subgroup-appropriate representation quality → Reduced fairness gap in pretraining**
- **Mechanism:** When each subgroup receives optimized augmentation, contrastive loss achieves similar convergence rates across groups (no subgroup left behind due to inappropriate augmentation intensity). Fairness constraint (performance gap <5%) explicitly prevents majority group (adult) from dominating learned representations. Group-level importance weighting ensures minority groups (pediatric, elderly) contribute equally to optimization.
- **Falsification:** If fairness constraint cannot satisfy both overall performance >0.80 AND fairness gap <5%, this link fails (infeasible constraint region).

**Step 3: Reduced fairness gap in pretraining → Fair downstream task performance with missing data robustness**
- **Mechanism:** Representations learned with fairness constraints transfer to downstream tasks while maintaining fairness properties (transfer learning preserves subgroup parity). Missing data robustness emerges from augmentation policies that simulate realistic missing patterns per subgroup (pediatric: burst missing during procedures, elderly: gradual sensor degradation), creating masking-invariant representations.
- **Falsification:** If downstream fairness gap >2× pretraining gap OR missing data robustness <0.75 AUROC, transfer learning failed and this link breaks.

**Falsification Criteria:**

The hypothesis will be **REJECTED** if any of the following occur:

1. **Primary Failure:** Fairness gap ≥10% (no meaningful improvement over 12-15% baseline)

   - Statistical threshold: p ≥ 0.05 (no significant difference from baseline)

2. **Mechanism Failure:** Within-subgroup SSL convergence identical for adaptive vs uniform augmentation (Step 1 → Step 2 link fails)

3. **Transfer Failure:** Downstream fairness gap >2× pretraining fairness gap (Step 3 link fails)

4. **Robustness Failure:** Missing data robustness (AUROC at 30-50% missing) <0.70

5. **Feasibility Failure:** Fairness constraint optimization cannot converge to solution satisfying both overall performance >0.80 AND fairness gap <5%
   - Indicates infeasible constraint region (ε = 0.05 too strict for this problem)
