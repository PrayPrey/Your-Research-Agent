# Title
Task-Similarity Routed LoRA Ensembles for Unified Multi-Objective Foundation Model Adaptation

# Motivation
Current foundation model adaptation methods excel at single objectives—continual learning prevents forgetting, parameter-efficient fine-tuning reduces costs, or personalization improves user experience—but fail to achieve all three simultaneously. This fragmentation limits real-world deployment where models must continuously learn new tasks without catastrophic forgetting, serve millions of users with minimal resources, and personalize to individual preferences. Existing approaches force practitioners to choose between objectives, creating a critical gap for production AI systems requiring unified multi-objective adaptation.

# Main Idea
We propose MLoRA-Ensemble, a modular adapter framework that achieves continual learning, parameter efficiency, and personalization simultaneously through task-similarity routed LoRA composition. The core mechanism trains independent low-rank adapters (0.1-0.5% parameters each) per task, creating approximate parameter space orthogonality that prevents catastrophic forgetting. A zero-shot router uses pre-trained encoders to compute task similarity, selecting top-k adapters via weighted ensemble with conflict detection fallback. This enables: (1) continual growth by adding adapters without modifying existing ones (BWT > -5%), (2) efficiency through selective activation (<1% active parameters), and (3) personalization via per-user adapter subsets (>+10% user-specific gain). We predict MLoRA will be the first method achieving all three targets simultaneously while maintaining ≥95% of full fine-tuning performance, validated across vision-language and text domains with rigorous statistical testing (n=26-45 per condition, power=0.80).
