# Title
Diagnosing the Cognitive Integration Gap in Large Language Models Through Hierarchical Task Decomposition

# Motivation
While LLMs demonstrate impressive performance on isolated cognitive tasks (reasoning, navigation, planning, theory of mind), their ability to coordinate these capabilities in integrated real-world scenarios remains unclear. Current benchmarks evaluate cognitive abilities in isolation, missing a critical dimension: integration capacity. This creates a fundamental knowledge gap—do LLMs that excel at individual cognitive tests maintain performance when these abilities must work together? Understanding this "cognitive integration gap" is essential for deploying LLMs in applications requiring coordinated cognition, such as embodied agents and multi-step decision systems.

# Main Idea
We hypothesize that LLMs exhibit systematic performance degradation when cognitive abilities must be integrated, beyond what task complexity alone predicts. Using Hierarchical Cognitive Task Decomposition (HCTD), we evaluate 10 state-of-the-art models across three levels: primitive (isolated abilities), pairwise (six ability combinations), and multi-cognitive (all four abilities). Novel metrics—Integration Coefficient (IC) and Multi-Cognitive Integration Score (MCIS)—quantify integration efficiency by comparing integrated task performance to isolated baselines. Control tasks matched for complexity isolate integration effects from difficulty confounds. We predict IC < 1.0 for most ability pairs, hierarchical degradation (MCIS < IC), and architectural variation in integration capacity. Dependency graph analysis will reveal bottleneck abilities (predicted: planning). This framework provides the first systematic diagnosis of cognitive integration limitations, guiding next-generation architectures toward explicit coordination mechanisms.
