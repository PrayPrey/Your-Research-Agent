# Title
Hierarchical Bayesian Uncertainty Decomposition for Hybrid Physics-ML Climate Models

# Motivation
Current climate projections rely on expensive multi-model ensembles (CMIP6: 225k simulation-years) that provide total uncertainty estimates but cannot identify whether errors originate from physics parameterizations, machine learning components, observational data, or natural variability. This "black box" uncertainty prevents targeted model improvements—scientists cannot determine whether to refine physics schemes or collect more ML training data. Hybrid physics-ML models like NeuralGCM promise computational efficiency but lack rigorous uncertainty quantification frameworks that attribute prediction errors to specific sources, limiting their adoption for climate decision-making.

# Main Idea
We propose the first hierarchical Bayesian framework that decomposes hybrid climate model uncertainty into four statistically independent sources: physics modules (σ²_phys), ML components (σ²_ml), input data (σ²_data), and climate variability (σ²_var). The core innovation is a spatial-temporal attribution ratio γ(x,t) = σ²_ml/(σ²_phys + σ²_ml) that quantifies physics versus ML contributions at each location and time, enabling evidence-based resource allocation. Using variational inference for scalability and conformal prediction for extreme events, we will validate on 10-year NeuralGCM forecasts through ANOVA F-tests (>80% variable-zone combinations showing statistical independence, p<0.05). Expected outcomes include 90% cost reduction versus CMIP6 while matching total uncertainty within 20%, plus actionable uncertainty maps showing "ML-critical" regions (γ>0.6) where targeted training data collection yields 25% uncertainty reduction versus 10% untargeted improvements.
