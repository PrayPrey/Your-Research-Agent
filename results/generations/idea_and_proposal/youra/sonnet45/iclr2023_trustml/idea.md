# Adaptive Event-Triggered Recalibration with Differential Privacy for Resource-Constrained ML Systems

## Motivation
Machine learning models deployed on edge devices face a critical challenge: maintaining calibration under distribution shift while respecting strict privacy and computational constraints. Existing approaches either recalibrate periodically (wasting resources) or ignore privacy (risking data leakage). This creates a three-way trade-off between calibration quality, privacy preservation, and computational efficiency that current methods fail to address, particularly in resource-constrained deployments where both privacy budgets and computational resources are scarce.

## Main Idea
We propose adaptive event-triggered recalibration that dynamically adjusts when to recalibrate based on calibration degradation while preserving differential privacy budgets. The core innovation transfers event-triggered control theory from Model Predictive Control to ML calibration: recalibration triggers only when Expected Calibration Error (ECE) exceeds an adaptive threshold τ(t) = τ₀ · (1 + α · budget_depletion_ratio), which increases as privacy budget depletes, preserving resources for severe shifts. We test this across 36 conditions varying shift severity, initial thresholds, and sensitivity parameters on CIFAR-10/100 with ResNet-50. Expected outcomes include 40-60% computational cost reduction versus periodic baselines while maintaining ECE ≤ 0.05 and satisfying (ε≤1.0, δ=10⁻⁵)-differential privacy, enabling practical privacy-preserving calibration for edge deployments.
