# Title
Compression-Native Pre-Training: Eliminating Post-Training Compression Through Multi-Objective Foundation Model Training

# Motivation
Current foundation models require costly post-training compression (quantization, pruning) before deployment, adding 10-20% computational overhead and requiring separate calibration phases. While methods like AWQ achieve 4-bit quantization with minimal accuracy loss, they treat compression as an afterthought. This creates inefficiencies: models learn representations that must later be forcibly compressed, wasting resources on a two-phase process. The fundamental question remains unexplored: can we train models to be compression-ready from the start, eliminating the separate compression phase entirely while maintaining performance?

# Main Idea
We propose Compression-Native Pre-Training (CNP), which integrates compression objectives directly into foundation model pre-training using phased multi-objective optimization. The core mechanism employs MGDA (Multi-Gradient Descent Algorithm) to balance three losses: task performance (L_task), quantization readiness (L_quant via differentiable quantization), and structured pruning (L_prune via Information Bottleneck). Training proceeds in three phases: (1) 0-10%: L_task only for stable representations, (2) 10-70%: add L_quant for quantization-friendly activations, (3) 70-100%: add L_prune for structured sparsity. This phased approach prevents gradient conflicts while producing models with inherently low activation variance and high weight entropy—enabling direct 4-bit quantization without calibration. We predict CNP will achieve equivalent task performance (≤1% degradation) to standard pre-training while reducing total computational cost by 10-20% and producing deployment-ready compressed models, validated on 1-7B parameter language models.
