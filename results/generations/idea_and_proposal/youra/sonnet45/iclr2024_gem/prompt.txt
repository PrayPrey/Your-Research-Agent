# Research Idea: Adaptive Closed-Loop Protein Design via Thompson Sampling and Parameter-Efficient Model Retraining

## Title
Adaptive Closed-Loop Protein Design via Thompson Sampling and Parameter-Efficient Model Retraining

## Motivation
Current biomolecular design suffers from a critical disconnect: generative ML models (ProteinMPNN, RFdiffusion) remain static after pre-training, failing to learn from expensive experimental feedback. Existing approaches like MAGECS demonstrate closed-loop experimental integration but don't update their generative models, while standard Bayesian optimization treats deep generative priors as black boxes. This creates inefficiency—requiring 200-300 wet-lab experiments to reach optimal designs at $250-1000 per assay. Bridging computational and experimental perspectives requires models that continuously adapt from small experimental batches while preserving chemical validity, a challenge unaddressed by current methods.

## Main Idea
We hypothesize that integrating **discounted Thompson Sampling** for exploration-exploitation in generative latent spaces with **parameter-efficient fine-tuning** (LoRA + Bayesian regularization) achieves 30-50% improvement in sample efficiency over static models. The causal mechanism operates through five linked components: (1) Thompson Sampling provides principled probabilistic exploration by maintaining posteriors over latent regions, (2) LoRA enables continuous model adaptation from 10-50 experimental samples without catastrophic forgetting via 99% parameter reduction, (3) Bayesian regularization preserves pre-trained chemical priors through KL-divergence penalties, (4) discount factors (γ=0.9-0.99) adapt to non-stationary latent spaces as models retrain, and (5) multi-fidelity optimization (AlphaFold + wet-lab) maximizes information gain per cost. We validate through two phases: in-silico benchmarking on FLIP protein tasks (10 runs × 5 tasks) and wet-lab validation on enzyme/antibody design (200 assays per task). Expected impact: reduce experimental budgets by 40-60% while discovering high-performers missed by static approaches, with open-source implementation enabling broad adoption across protein engineering applications.

### 1.3 Causal Mechanism

**Mechanism Decomposition (First Principles):**

The hypothesis operates through a **closed-loop learning system** with five causal links:

**Link 1: Thompson Sampling → Improved Exploration**
- **Mechanism:** Thompson Sampling maintains posterior distribution P(reward | latent region) over the generative model's latent space, updated via Bayes' rule after each experimental batch. Sampling from this posterior enables probabilistic exploration where high-uncertainty regions (wide posterior) are explored to reduce uncertainty, and high-reward regions (high posterior mean) are exploited.
- **First Principle:** Information-theoretic exploration - optimal balance between gathering information (exploration) and using known information (exploitation) follows from Bayesian decision theory.
- **Quantification:** Regret bounds for Thompson Sampling: O(√T log T) where T is number of rounds, demonstrating sublinear regret growth.

**Link 2: Parameter-Efficient Fine-Tuning → Continuous Model Improvement**
- **Mechanism:** LoRA decomposes weight updates as low-rank matrices ΔW = BA where B, A have rank r << original dimensions. Only B, A are trained, freezing pre-trained weights W₀. Each experimental batch D_t updates model parameters θ_t → θ_{t+1}, improving prediction accuracy in explored regions.
- **First Principle:** Gradient-based learning with constrained parameter space - low-rank constraint acts as implicit regularization while enabling learning from small datasets (10-50 samples).
- **Quantification:** 99% parameter reduction (Li et al., 2025) - e.g., ProteinMPNN with 500M parameters → 5M trainable via LoRA rank 16.

**Link 3: Bayesian Regularization → Chemical Prior Preservation**
- **Mechanism:** Loss function includes KL divergence penalty: L = L_data + λ·KL(θ||θ_pretrained), preventing catastrophic forgetting by penalizing large deviations from pre-trained distribution.
- **First Principle:** Bayesian posterior approximation via Laplace approximation - parameters with high pre-training curvature (important for chemical validity) are heavily penalized if changed.
- **Quantification:** Chen & Garner (2024) show Kronecker-factored Laplace approximation preserves 95%+ of pre-trained task performance.

**Link 4: Discounted Thompson Sampling → Non-Stationarity Adaptation**
- **Mechanism:** Discount factor γ ∈ [0.9, 0.99] down-weights observations from round i by γ^(t-i) at round t. As model retraining shifts latent space geometry, old observations become less reliable. Discounting prevents overconfidence in stale data.
- **First Principle:** Time-varying distributions - non-stationary bandit theory (He et al., 2023) extends classical TS to evolving reward landscapes.
- **Quantification:** Optimal discount factor balances memory (γ→1: long memory) vs adaptation (γ→0: only recent data). Typical range γ=0.9-0.99 for moderately non-stationary environments.

**Link 5: Multi-Fidelity Optimization → Resource Efficiency**
- **Mechanism:** Information gain per cost criterion: select fidelity level (AlphaFold fast/cheap vs wet-lab slow/expensive) that maximizes IG(x)/Cost(fidelity). AlphaFold filters candidates before expensive wet-lab validation.
- **First Principle:** Value of information - optimal sequential decision-making allocates resources to measurements with highest expected information gain per unit cost.
- **Quantification:** Deshwal (AAAI 2025) demonstrates 40-60% cost reduction via multi-fidelity optimization in materials discovery.

**Integrated Causal Chain:**
```
(Latent space + TS posterior) → probabilistic candidate selection
→ (AlphaFold + wet-lab) multi-fidelity evaluation
→ experimental data D_t
→ (LoRA + Bayesian reg) model update
→ improved latent space
→ better TS posterior
→ LOOP CONTINUES
```

Each iteration creates **cumulative advantage**: (1) TS explores better due to informed posterior, (2) model exploits better due to continuous learning, (3) multi-fidelity wastes fewer resources, (4) discount factor adapts to evolving landscape.

**Evidence for Causal Links:**

**Link 1 (TS → Exploration):**
- Sun et al. (2025): Thompson Sampling with LLM-based reward prediction demonstrates effective exploration-exploitation balance
- He et al. (2023): Discounted TS for non-stationary MAB achieves O(√T) regret bounds

**Link 2 (PEFT → Learning):**

**Link 4 (Discount → Adaptation):**

**Link 5 (Multi-fidelity → Efficiency):**

- Song et al. (Nature Comm 2025): MAGECS achieves 35% high-activity structure generation (though without generative model updating)

**Key Tension:**
**Exploration vs Exploitation in Non-Stationary Landscape**

The fundamental trade-off is between:
- **Exploring** novel latent regions to discover unexpected high-performers (wide TS posterior, high uncertainty)
- **Exploiting** known good regions to optimize incrementally (narrow TS posterior, high confidence)

This tension is managed **probabilistically** via Thompson Sampling (posterior width) and **temporally** via discount factor (recent data weighted more). As model improves through PEFT, exploitation becomes more valuable (better local optimization), but latent space shifts require continued exploration. Static models cannot navigate this tension - they explore blindly without learning from past failures.

### 1.5 Scope & Boundaries

**Applies To:**
- **Protein sequence design** for binding affinity optimization (antibody-antigen, protein-protein interactions), enzymatic activity improvement, thermal stability enhancement
- **Small molecule design** with generative models (VAE, diffusion) where pre-trained models exist (e.g., MolGAN, ChemVAE, Reinvent 4)
- **Materials discovery** with generative models where closed-loop experimental validation is feasible (following MAGECS precedent)
- **Scenarios** where:
  - Experimental feedback is expensive but available iteratively (cost: $500-$5000/assay, latency: days-weeks)
  - Pre-trained generative models exist with learned chemical/structural priors
  - Computational structure prediction (AlphaFold, DFT) provides fast low-fidelity evaluation
  - Target property is measurable via wet-lab assay
  - Budget allows 100-500 experimental evaluations

**Does NOT Apply To:**
- **De novo design without pre-trained models** - No chemical priors to preserve, PEFT advantage disappears
- **Pure in-silico optimization** - If no experimental validation, multi-fidelity and closed-loop learning are irrelevant
- **Properties uncorrelated with generative model's latent space** - e.g., purely extrinsic properties like manufacturability, regulatory approval, market demand
- **Extremely sparse data regimes** (< 5 samples per round) - LoRA may underfit, insufficient data for posterior update
- **Ultra-high-throughput scenarios** where experiments are cheap (< $10/assay) - Adaptive design overhead not worth it; random/greedy sampling sufficient
- **Real-time closed-loop with latency < 1 hour** - Model retraining (even with LoRA) takes hours on single GPU

**Known Limitations:**
- **Hyperparameter sensitivity**: Discount factor γ, LoRA rank r, regularization weight λ require problem-specific tuning (2-3 orders of magnitude search)
- **Multi-fidelity assumption**: Requires AlphaFold-wetlab correlation ρ ≥ 0.6; not guaranteed for all properties (e.g., cell-level phenotypes, in vivo efficacy)
- **Computational overhead**: LoRA retraining takes 1-4 hours per round on A100 GPU; may bottleneck rapid experimental loops
- **Theoretical gaps**: Convergence guarantees for discounted TS in non-stationary continuous action spaces not fully established (ongoing research)
- **Bayesian approximation quality**: Laplace approximation may be poor for highly non-convex losses; can cause either underfitting or catastrophic forgetting

**Boundary Conditions:**
- **Minimum experimental budget**: ~50-100 assays required for TS posterior to converge; below this, random sampling may be competitive
- **Maximum non-stationarity rate**: If latent space geometry changes drastically (> 50% embedding shift) between rounds, discount factor may not adapt fast enough
- **AlphaFold quality threshold**: If AlphaFold predictions are random (ρ < 0.3), multi-fidelity becomes single-fidelity (wetlab only), losing resource efficiency advantage

### 1.8 Statistical Verification Design

- **Replication:** 10 independent runs per method per task (50 tasks × 4 methods × 10 runs = 2000 total trials)

**Phase 2: Wet-Lab Validation (12 months, ~$50-100K)**

- **Methods:** Proposed vs best-performing baseline from Phase 1
- **Oracle:** Wet-lab experimental assays (expression, purification, functional assay)
- **Budget:** 200 wet-lab evaluations per task (400 total), $250/assay average
- **Replication:** 3 independent experimental campaigns per task
- **Sample size:** Based on Phase 1 effect size, n=100 per method per task provides 90% power

## 2. Contribution Summary

**Theoretical Contribution:**
**First formalization of Thompson Sampling with parameter-efficient generative model retraining for adaptive experimental design in biomolecular discovery**

We extend classical Thompson Sampling theory (discrete arms, stationary rewards) to continuous latent spaces with non-stationary reward distributions induced by model retraining. Key theoretical innovation: discounted Thompson Sampling (He et al., 2023) adapted to generative model setting where posterior over latent regions evolves as model improves. Provides principled framework for balancing exploration-exploitation under model non-stationarity, with regret analysis showing sublinear growth O(√T log T) under discounting.

**Novel Analysis:** Convergence guarantees for TS when the action space (latent embeddings) is itself changing due to model updates - extends fixed-space TS theory to co-evolving model-acquisition dynamics.

**Methodological Contribution:**
**Closed-loop integration framework combining Thompson Sampling acquisition, parameter-efficient fine-tuning, and multi-fidelity optimization for biomolecular design**

Three methodological innovations:

1. **TS in Generative Latent Space:** Sample candidate latent vectors z ~ TS(P(reward | z, data), D) where posterior P is continuously updated via experimental feedback. Leverages learned generative priors (ProteinMPNN embeddings) instead of generic kernels (standard BO).

2. **PEFT Protocol for Biomolecules:** LoRA (rank r=8-16) + Bayesian regularization (λ=0.1) + OPLoRA orthogonal projection preserves chemical validity while enabling adaptation from small batches (10-50 samples). First application of parameter-efficient fine-tuning to closed-loop protein design.

3. **Integrated Multi-Fidelity Decision Rule:** Information gain per cost IG(x)/Cost(fidelity) criterion selects between AlphaFold (fast, ~$1/eval) and wet-lab (slow, ~$1000/eval) dynamically per candidate, optimizing resource allocation under uncertainty.

**Differentiation from Prior Work:**
- **vs Wang et al. (2023):** They use static protein language models as feature extractors; we retrain generative models via PEFT
- **vs Frank et al. (2024):** They use in-silico gradient-based hallucination; we use experimental feedback + Thompson Sampling acquisition
- **vs MAGECS (Song et al., 2025):** They use bird swarm algorithm without deep generative models; we integrate generative priors + retraining
- **vs Standard Adaptive Design (Deshwal, Noarov):** They propose generic black-box methods; we integrate with domain-specific generative models and chemical priors

**Practical Contribution:**
**Open-source implementation demonstrating 30-50% sample efficiency improvement on protein design benchmarks with real wet-lab validation**

**Deliverables:**
