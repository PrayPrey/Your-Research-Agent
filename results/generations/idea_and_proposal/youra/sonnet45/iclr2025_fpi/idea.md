# Adaptive Sampler Selection via Performance Prediction for Efficient Probabilistic Inference

## Motivation
Probabilistic inference via sampling faces a critical challenge: different samplers (flow matching, diffusion models, Langevin MCMC) excel at different problem phases—flows provide broad coverage during exploration while MCMC refines convergence. Fixed sampler choices waste computation by mismatching method strengths to problem states. Existing approaches lack principled mechanisms to dynamically switch samplers based on real-time problem characteristics. This research addresses the gap by developing an adaptive selection framework that reduces total sampling cost by ≥20% through intelligent sampler allocation.

## Main Idea
We hypothesize that a lightweight performance predictor (<1000 parameters) can select optimal samplers by monitoring four state features: Effective Sample Size, convergence rate, problem dimension, and curvature. The causal mechanism operates through three steps: (1) extract problem state from current samples, (2) neural predictor estimates efficiency for each sampler with uncertainty quantification, (3) Thompson sampling balances exploration-exploitation to select samplers dynamically. Early phases favor flows/diffusion for broad coverage; late phases use Langevin for refinement. Warm-starting enables low-overhead switching (<15% cost). We validate through comparative experiments on Bayesian inference benchmarks, testing predictor accuracy (≥65%), switching overhead, and robustness. Success demonstrates that matching sampler strengths to problem phases via learned state-based selection significantly outperforms fixed strategies.
