## Localized Learning Workshop

Despite being widely used, global end-to-end learning has several key limitations. It requires centralized computation, making it feasible only on a single device or a carefully synchronized cluster. This restricts its use on unreliable or resource-constrained devices, such as commodity hardware clusters or edge computing networks. As the model size increases, synchronized training across devices will impact all types of parallelism.

# Asynchronous Forward-Forward Greedy Learning for Memory-Efficient Distributed Training

## Motivation
Global backpropagation requires centralized computation, large memory footprints, and synchronized updates across devices—limiting deployment on resource-constrained edge devices and unreliable commodity hardware. As models scale, memory bottlenecks prevent training on distributed heterogeneous systems. Existing localized learning methods address individual limitations but lack integration: Forward-Forward eliminates backward passes but hasn't been combined with greedy layer-wise expansion, while greedy methods still use backpropagation within modules. This research addresses the critical gap of achieving extreme memory efficiency while enabling distributed training on unreliable hardware.

## Main Idea
We hypothesize that combining Forward-Forward layer-local objectives with asynchronous greedy layer-wise expansion achieves 70-80% memory reduction versus backpropagation while maintaining ≥90% accuracy on heterogeneous device clusters (10-100 nodes). The causal mechanism operates through five steps: (1) Forward-Forward's dual-pass goodness objectives eliminate activation storage for backpropagation (40-60% per-layer savings), (2) enabling greedy sequential layer training, (3) which isolates cross-layer memory (additional 60% reduction), (4) allowing asynchronous convergence detection via local goodness metrics, (5) coordinated through quorum protocols tolerating device failures. Staged validation will isolate each mechanism component, testing FF-only, FF+greedy synchronous, then full asynchronous integration across vision and sequence tasks, with falsification if memory reduction <50% or accuracy <75% of baseline.

### 1.3 Causal Mechanism

**Causal Chain (N=5 steps):**

**Step 1 → Step 2:** FF dual-pass goodness objectives → Elimination of activation storage for backpropagation
*Mechanism:* Forward-Forward trains each layer using only forward passes with positive/negative data, optimizing a local "goodness" function (sum of squared activities). This eliminates the need to store intermediate activations for backward pass gradient computation.
*Outcome:* 40-60% per-layer memory reduction

**Step 2 → Step 3:** Per-layer memory reduction → Greedy sequential layer training becomes viable
*Mechanism:* With FF reducing per-layer memory footprint, greedy layer-wise training can now process one layer at a time without memory bottlenecks. TRGL regularization prevents the stagnation problem that previously blocked greedy methods.
*Outcome:* Only one layer's activations in memory at a time

**Step 3 → Step 4:** Greedy sequential processing → Cross-layer memory isolation → Additional 60% memory reduction
*Mechanism:* Greedy layer-wise training processes layers sequentially rather than simultaneously, keeping only the current layer's parameters and activations in memory. This is orthogonal to per-layer FF savings, yielding multiplicative benefits.
*Outcome:* 60% cross-layer memory reduction combines with 40-60% per-layer savings → 70-80% total reduction

**Step 4 → Step 5:** Layer-local FF objectives + Greedy convergence detection → Asynchronous layer addition opportunities
*Mechanism:* Since each layer has a local objective and convergence criterion (goodness variance < 0.01), devices can independently detect when their local layer has converged and signal readiness for the next layer without global synchronization.
*Outcome:* Devices asynchronously propose new layers when local convergence detected

**Step 5 → Outcome:** Async layer addition with quorum coordination → Training continues despite device failures → Distributed training on unreliable hardware
*Mechanism:* Quorum-based protocol (≥50% devices ready) coordinates layer additions using lightweight consensus primitives (Hivemind framework). Training progresses when quorum reached, tolerating individual device failures.
*Outcome:* Enables distributed training on commodity hardware and unreliable edge devices
