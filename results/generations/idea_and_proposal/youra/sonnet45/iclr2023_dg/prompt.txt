# Research Idea: Adaptive Invariance Selection for Domain Generalization

## Title
Adaptive Invariance Selection for Domain Generalization via Meta-Learned Confidence Estimation

## Motivation
Domain generalization methods based on invariance principles (like IRM) often fail to consistently outperform standard baselines because they assume invariant features are always optimal—yet theory shows this assumption breaks down when invariant features capture all label information. Current approaches use static combinations of invariance and information bottleneck objectives with fixed hyperparameters, requiring expensive per-dataset tuning. This creates a critical gap: practitioners lack principled, data-driven guidance on *when* to enforce invariance versus when to compress representations. We need automated method selection that adapts to each dataset's invariance quality.

## Main Idea
We propose AIS-DG, which meta-learns a lightweight confidence estimator that predicts whether invariance-based optimization will succeed by monitoring three observable signals: gradient disagreement across domains, mutual information between inputs and representations, and validation performance gaps. The meta-learner outputs a confidence score that dynamically interpolates between IRM (invariance) and IB-ERM (compression) losses via bi-level optimization. 

**Core mechanism**: High gradient disagreement + low mutual information → high confidence → favor IRM; opposite patterns → favor compression. We test this on PACS, OfficeHome, and DomainNet benchmarks, predicting ≥1% improvement over static baselines with statistical significance. Success requires learned confidence correlating (ρ>0.5) with oracle performance and avoiding worst-case failures of either pure strategy, directly operationalizing theoretical optimality conditions into practical automated method selection.

### 1.3 Causal Mechanism

**Mechanism Chain:**

```
[Data Properties] → [Observable Signals] → [Confidence Estimation] → [Adaptive Loss] → [Improved OOD Performance]

Where:
1. Data Properties: (Invariance Quality Q_inv)
   - High Q_inv: Invariant features sufficient for prediction (IRM optimal)
   - Low Q_inv: Spurious correlations dominate (IB-ERM safer)

2. Observable Signals:
   - Gradient Disagreement: High σ²(∇L) → domains differ in optimization direction → IRM needed
   - Mutual Information: High I(X;Z) → representation retains too much info → IB needed
   - Validation Gap: High Δacc → domains perform differently → uncertain regime

3. Confidence Estimation:
   - Meta-learner φ: (σ²(∇L), I(X;Z), Δacc) ↦ c ∈ [0,1]
   - Trained via bi-level optimization to maximize target val performance

4. Adaptive Loss:
   - c → 1: Strong IRM penalty (enforce invariance)
   - c → 0: Strong IB penalty (compress representation)
   - c ≈ 0.5: Balanced combination

5. Improved OOD:
   - Better than static IRM: Avoids IRM when conditions fail (Koyama 2020 violations)
   - Better than static IB-ERM: Uses invariance when conditions hold
```

**Evidence for Causal Links:**

1. **Link 1: Data Properties → Observable Signals**
   - **Evidence:** Koyama & Yamaguchi (2020) prove that when invariant features capture all label info, IRM is suboptimal. This theoretical result establishes that data properties determine optimal strategy.
   - **Mechanism:** Gradient disagreement directly measures IRM's penalty term magnitude (core IRM signal)

2. **Link 2: Observable Signals → Confidence Estimation**
   - **Evidence:** Meta-learning literature (MAML, MetaReg) shows that validation performance on source domains predicts target domain performance
   - **Mechanism:** Bi-level optimization uses target validation signal to learn mapping from observables to confidence

3. **Link 3: Confidence Estimation → Adaptive Loss**
   - **Evidence:** Deterministic function: L = c·L_IRM + (1-c)·L_IB_ERM (direct application)
   - **Mechanism:** Smooth interpolation ensures differentiability for end-to-end training

4. **Link 4: Adaptive Loss → Improved OOD**
   - **Evidence:** Ahuja et al. (2021) show that IRM+IB static combination outperforms pure IRM
   - **Mechanism:** Adaptive weighting provides "best of both" while avoiding worst-case scenarios

**Key Tension:**
The fundamental tension is between **exploiting structure** (invariance via IRM) vs **avoiding spurious patterns** (compression via IB). Static methods must commit to one trade-off point; adaptive switching resolves this by learning when each strategy dominates. The tension is analogous to control theory's model-based vs adaptive control trade-off (exploitation vs exploration).

### 1.8 Statistical Verification Design

1. **Dataset Split Protocol:**
   - PACS: Leave-one-domain-out (4 target domains, 3 sources each)

   - DomainNet: Leave-one-domain-out (6 target domains, 5 sources each)
   - Source domains: 80% train, 20% validation (for meta-optimization)

2. **Replication:**
   - 5 random seeds per (dataset, target domain) configuration
   - Report mean ± std across seeds
   - Statistical significance: paired t-test vs best baseline (p<0.05)

3. **Hyperparameter Search:**
   - Grid search over: K ∈ {1,3,5,10}, lr_inner ∈ {1e-4,1e-3,1e-2}, lr_outer ∈ {1e-5,1e-4,1e-3}, λ_IRM ∈ {1,10,100}, β_IB ∈ {0.01,0.1,1.0}
   - Selection: Maximize average source validation accuracy (not target - to avoid leakage)
   - Fixed across all target domains once selected

4. **Ablation Studies:**
   - Remove each input feature (gradient disagreement, MI, validation gap) to measure contribution
   - Compare to static confidence values c ∈ {0, 0.25, 0.5, 0.75, 1.0}
   - Test with alternative MI estimators (InfoNCE, CLUB)

5. **Confidence Analysis:**
   - Compute oracle confidence: c* = argmax_c acc_target(c) via sweep
   - Measure correlation: ρ(c_learned, c_oracle) across datasets
   - Visualize c vs (gradient_dis, MI, val_gap) for interpretability

6. **Statistical Tests:**
   - **Primary:** Paired t-test on target accuracy: AIS-DG vs max(baselines)
   - **Secondary:** Wilcoxon signed-rank test (non-parametric alternative)
   - **Effect Size:** Cohen's d to quantify improvement magnitude
   - **Multiple Comparisons:** Bonferroni correction for 3-6 comparisons

**Success Criteria:**
- ✅ AIS-DG > best_baseline on ≥75% of (dataset, target_domain) pairs
- ✅ Statistical significance: p < 0.05 on average across all target domains
