**Temporal Evolution of ToM in AI Research (2018-2025):**

   - **Machine ToM** (Rabinowitz et al., ICML 2018) → CILAB-MA/Machine_ToM implementation
   - **"Knowing me, knowing you"** (Cuzzolin et al., 2020) establishes need for hot cognition
   - Focus: Basic belief attribution, observable behavior modeling

   - **MindCraft** (Bara et al., 2021) → First situated dialogue ToM dataset
   - **Deep Interpretable ToM Models** (Oguntola et al., 2021) → Internal mental state modeling
   - **Computational Language Acquisition with ToM** (Liu et al., 2023) → ToM for language learning
   - **Collaborative Plan Acquisition** (Bara et al., 2023) → Extension of MindCraft to active collaboration

3. **Critical Assessment Period (2023):**
   - **"LLMs Fail on Trivial Alterations"** (Ullman, 2023) → 313 citations, skeptical evaluation benchmark
   - **SymbolicToM** (Sclar et al., ACL 2023) → Plug-and-play symbolic belief tracking

- Observable behavior → Internal mental states (2018-2021)

### Identified Gaps

#### Gap 1: Unified Framework Integrating Cognitive Foundations with Production NLP Systems

**Current State:** Research shows fragmentation between cognitively-inspired ToM models (psychology-grounded) and production NLP systems. Cognitive models (e.g., Bayesian ToM, RSA framework) have strong theoretical foundations but limited scalability. Production LLMs show emergent ToM but lack explicit cognitive grounding. No unified architecture successfully bridges this divide at scale.

**Missing Piece:** A scalable neuro-symbolic architecture that:
1. Incorporates explicit cognitive ToM theories (perspective-taking, recursive reasoning, pragmatic inference)
2. Operates efficiently on production-scale LLMs (billions of parameters)
3. Maintains interpretability while achieving state-of-the-art performance
4. Provides theoretical guarantees about ToM capabilities

**Potential Impact:** **HIGH** - Would enable:
- Theoretically-grounded ToM in deployed AI systems
- Better alignment with human mental models
- Explainable decision-making in safety-critical applications (medical AI, autonomous vehicles, social robots)
- Reduced hallucinations in scenarios requiring mental state modeling

#### Gap 2: Temporal and Dynamic Belief Updating in Real-Time Interaction

**Current State:** Most ToM research focuses on static belief attribution at discrete timepoints (Sally-Anne test, false belief tasks). Existing benchmarks (OpenToM, ToMBench, MOMENTS) present complete narratives before questioning. Real human interaction requires continuous belief updating as new information arrives, handling partial observations, uncertainty, and belief revision. Only 1 dataset (DynToM) explicitly addresses temporal evolution, but lacks real-time interaction component.

**Missing Piece:**
1. Real-time belief tracking architecture that updates incrementally as dialogue unfolds
2. Mechanisms for handling belief uncertainty and revision when expectations are violated
3. Integration with dialogue management for ToM-aware response generation
4. Benchmarks for continuous interaction (not just post-hoc reasoning)
5. Methods for tracking belief confidence and identifying when to seek clarification

**Potential Impact:** **HIGH** - Critical for:
- Conversational AI that adapts to evolving user mental states
- Collaborative robots that update partner models during joint tasks
- Therapeutic chatbots tracking patient emotional/cognitive states
- Negotiation agents that revise opponent models based on offers/counteroffers
- Error recovery in human-AI collaboration (detecting misunderstanding from behavior)
