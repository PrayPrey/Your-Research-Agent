# ChunkFlow: Real-Time Multimodal Audio Generation via Adaptive Flow Matching

## Motivation
Current state-of-the-art multimodal audio generation systems (e.g., video-to-audio) operate offline with latencies exceeding 200ms, preventing real-time applications in VR/AR, live streaming, and mobile gaming. Existing methods face a fundamental trade-off: high-quality generation requires computationally expensive models incompatible with real-time constraints. This research addresses the critical gap in real-time, low-latency multimodal audio generation by enabling streaming synthesis with <75ms latency while maintaining perceptual quality and reducing power consumption by 2x.

## Main Idea
We propose ChunkFlow, the first streaming architecture for multimodal video-to-audio generation combining four innovations: (1) chunk-based flow matching decomposition (200ms chunks, 50ms overlap) with phase-coherent stitching to enable streaming while maintaining temporal continuity; (2) adaptive quality selection using GRU-based resource prediction (borrowed from video ABR) to dynamically adjust generation steps (20-50) based on compute availability; (3) FPGA hardware acceleration with 16-bit quantization achieving <15W power consumption; (4) overlap-add with phase vocoder ensuring <-40dB spectral discontinuity at chunk boundaries. We test predictions that ChunkFlow achieves <75ms P95 latency, maintains CLAP score >0.65 across quality tiers, and delivers 2x power efficiency versus GPU baselines. Success demonstrates cross-domain transfer from video streaming to generative audio and establishes chunk-based synthesis as viable for real-time applications.
