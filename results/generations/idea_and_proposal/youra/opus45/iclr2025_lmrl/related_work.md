## Related Work

**Related Papers**
1. **Title**: Item Response Theory in Educational Assessment
   - **Authors**: Janssen, Tuerlinckx, Meulders, De Boeck
   - **Summary**: Demonstrates that hierarchical IRT enables mastery classification via criterion-referenced measurement with Gibbs sampler estimation.
   - **Year**: 2000

2. **Title**: Multivariate Higher-Order IRT Model and MCMC Algorithm
   - **Authors**: Mun, Huo, White, Suzuki, de la Torre
   - **Summary**: Shows that multi-group multivariate higher-order IRT enables linking individual participant data from multiple studies.
   - **Year**: 2019

3. **Title**: Construct Validity in Psychological Testing
   - **Authors**: Cronbach & Meehl; Messick
   - **Summary**: Establishes classic psychometric theory for convergent, discriminant, and criterion validity framework, demonstrating that true measurement requires theoretical grounding and multiple validity evidence sources.
   - **Year**: 1955; 1989

4. **Title**: scGPT: toward building a foundation model for single-cell
   - **Authors**: Cui et al.
   - **Summary**: Develops a foundation model for single-cell analysis using task-specific metrics such as cell type accuracy and batch mixing; BioConstruct-SC provides a standardized alternative approach.
   - **Year**: 2024

5. **Title**: Biology-driven insights into the power of single-cell foundation models
   - **Authors**: Wu et al.
   - **Summary**: Provides a comprehensive benchmark with 12 metrics including scGraph-OntoRWR, validating the need for knowledge-based evaluation approaches.
   - **Year**: 2025

6. **Title**: Evaluating pre-training dataset size for single-cell FM
   - **Authors**: DenAdel et al.
   - **Summary**: Highlights evaluation inconsistency across models, motivating the need for a standardized evaluation framework.
   - **Year**: 2025

7. **Title**: CLIP Architecture Pattern
   - **Authors**: Not specified
   - **Summary**: Demonstrates multimodal alignment evaluation via contrastive learning, providing an analogous approach to construct validity assessment.
   - **Year**: Not specified

**Key Challenges**
1. **Evaluation Inconsistency**: Current single-cell foundation models use inconsistent evaluation approaches across different models, making meaningful comparisons difficult.
2. **Task-Specific Metrics Limitations**: Existing models rely on task-specific metrics (e.g., cell type accuracy, batch mixing) rather than standardized evaluation frameworks that enable cross-model comparison.
3. **Lack of Theoretical Grounding**: True measurement in model evaluation requires theoretical grounding and multiple validity evidence sources, which current approaches often lack.
4. **Need for Knowledge-Based Evaluation**: Comprehensive benchmarking reveals the necessity for knowledge-based evaluation approaches beyond purely data-driven metrics.
5. **Standardization Gap**: The absence of standardized frameworks for evaluating foundation models creates barriers to systematic progress in the field.
