## Research Question Development

### Initial Question

How can principles, structures, and symmetries from physical systems be leveraged to construct novel machine learning methods with improved properties (trainability, expressivity, generalization)?

### Refined Question

What physics-inspired inductive biases (symmetries, conservation laws, dynamical systems formulations) can be embedded into neural network architectures to achieve superior performance in both scientific and classical machine learning applications?

### Detailed Sub-Questions

1. **Interpretability via Physics:** Can standard machine learning methods (Transformers, RNNs, diffusion models) be interpreted and analyzed from a physics perspective, and what novel insights can we gain from such analysis?

2. **Unexploited Symmetries:** What types of structures and symmetries in physical systems have not yet been leveraged in machine learning architectures, and how can they be incorporated?

3. **Beyond Brute-Force:** In which machine learning applications to physical sciences are only brute-force approaches currently applied, and how can physics-based structure be leveraged to improve them?

4. **Reverse Transfer:** Which methods developed specifically for scientific applications (e.g., Hamiltonian neural networks with invertibility properties) could benefit the broader machine learning community for classical tasks?

5. **Physics-First Design:** What is a systematic approach for tackling problems in classical machine learning (computer vision, NLP, speech) using structure from physical systems?
