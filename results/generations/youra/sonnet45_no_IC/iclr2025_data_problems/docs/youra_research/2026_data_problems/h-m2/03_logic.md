## M2-3: DPR Implementation (Complexity: 14, Budget: 4)

**Applied:** HuggingFace Transformers DPR pattern, batch encoding pattern

### API Signatures

```python
from transformers import DPRQuestionEncoder, DPRContextEncoder
from transformers import DPRQuestionEncoderTokenizer, DPRContextEncoderTokenizer
import torch
import numpy as np
from typing import Dict, List, Tuple

class DPRRetriever:
    def __init__(
        self,
        question_encoder: str = "facebook/dpr-question_encoder-single-nq-base",
        context_encoder: str = "facebook/dpr-ctx_encoder-single-nq-base",
        device: str = "cuda"
    ):
        """Initialize DPR encoders."""
        self.device = device
        self.q_encoder = DPRQuestionEncoder.from_pretrained(question_encoder).to(device)
        self.c_encoder = DPRContextEncoder.from_pretrained(context_encoder).to(device)
        self.q_tokenizer = DPRQuestionEncoderTokenizer.from_pretrained(question_encoder)
        self.c_tokenizer = DPRContextEncoderTokenizer.from_pretrained(context_encoder)
        self.q_encoder.eval()
        self.c_encoder.eval()
    
    def encode_corpus(
        self, 
        corpus: Dict, 
        batch_size: int = 16
    ) -> Tuple[np.ndarray, List[str]]:
        """
        Encode corpus into 768-dim embeddings.
        
        Args:
            corpus: BEIR corpus dict {doc_id: {"title": str, "text": str}}
            batch_size: Batch size for encoding
        
        Returns: (embeddings [N, 768], doc_ids [N])
        """
        ...
    
    def encode_queries(
        self, 
        queries: Dict, 
        batch_size: int = 16
    ) -> Tuple[np.ndarray, List[str]]:
        """
        Encode queries into 768-dim embeddings.
        
        Args:
            queries: BEIR queries dict {query_id: query_text}
            batch_size: Batch size for encoding
        
        Returns: (embeddings [M, 768], query_ids [M])
        """
        ...
    
    def retrieve(
        self,
        query_embeddings: np.ndarray,
        query_ids: List[str],
        corpus_embeddings: np.ndarray,
        corpus_ids: List[str],
        k: int = 10
    ) -> Dict[str, List[Tuple[str, float]]]:
        """
        Retrieve top-k by dot product similarity.
        
        Args:
            query_embeddings: [M, 768]
            query_ids: [M]
            corpus_embeddings: [N, 768]
            corpus_ids: [N]
            k: Top-k to retrieve
        
        Returns: {query_id: [(doc_id, score), ...]}
        """
        ...
```

### Tensor Shapes

| Variable | Shape | Note |
|----------|-------|------|
| query_embeddings | [M, 768] | M queries, 768-dim DPR embeddings |
| corpus_embeddings | [N, 768] | N documents, 768-dim DPR embeddings |
| similarity_matrix | [M, N] | Dot product scores |
| top_k_indices | [M, k] | Top-k doc indices per query |

### Pseudo-code

```
1. encode_corpus():
   a. Iterate corpus in batches (batch_size=16)
   b. For each batch: combine title + text
   c. Tokenize with DPRContextEncoderTokenizer (max_length=512)
   d. Pass through context_encoder: [B, seq_len] -> [B, 768]
   e. Collect embeddings: [N, 768]
   f. Return (embeddings, doc_ids)

2. encode_queries():
   a. Iterate queries in batches
   b. Tokenize with DPRQuestionEncoderTokenizer
   c. Pass through question_encoder: [B, seq_len] -> [B, 768]
   d. Return (embeddings, query_ids)

3. retrieve():
   a. Compute similarity: query_emb @ corpus_emb.T -> [M, N]
   b. For each query: argsort scores, select top-k indices
   c. Map indices to (doc_id, score) tuples
   d. Return {query_id: [(doc_id, score), ...]}
```

### Subtasks [4/4 used]

| ID | Subtask | Description |
|----|---------|-------------|
| L-3-1 | Model loading | Load DPR question/context encoders, tokenizers |
| L-3-2 | Corpus encoding | Batch encode corpus (768-dim), handle memory |
| L-3-3 | Query encoding + retrieval | Encode queries, compute dot product, top-k |
| L-3-4 | Result caching | Save embeddings to disk (avoid recomputation) |

### Pseudo-code

```
1. compute_recall_at_k():
   a. For each query_id in query_ids:
      - Get top-k docs from results
      - Get relevant docs from qrels
      - Check if any relevant doc in top-k
      - Record 1 if found, 0 otherwise
   b. Return mean(recalls)

2. split_by_bm25_performance():
   a. For each query_id in qrels:
      - Get top-k BM25 results
      - Get relevant docs from qrels
      - If any relevant doc in top-k:
        → Add to lexical_queries
      - Else:
        → Add to semantic_queries
   b. Return (lexical_queries, semantic_queries)

3. compute_differential_metrics():
   a. Compute 4 Recall@k values:
      - baseline_lexical, baseline_semantic
      - retrieval_lexical, retrieval_semantic
   b. Compute deltas:
      - delta_semantic = retrieval_semantic - baseline_semantic
      - delta_lexical = retrieval_lexical - baseline_lexical
   c. Check gate:
      - gate_pass = (delta_semantic >= 0.04) AND (delta_lexical <= 0.01)
   d. Return metrics dict
```

### Subtasks [2/2 used]

| ID | Subtask | Description |
|----|---------|-------------|
| L-5-1 | Recall@k computation | Fraction with ≥1 relevant doc in top-k |
| L-5-2 | Differential metrics | Compute ΔRecall, check gate condition |
