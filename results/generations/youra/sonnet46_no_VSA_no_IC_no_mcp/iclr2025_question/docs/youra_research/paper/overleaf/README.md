# Overleaf LaTeX Project

**Paper:** When Does Semantic Entropy Win? Task-Structure-Dependent Uncertainty Estimation at 7B Scale

**Format:** ICML 2025

## Structure

```
overleaf/
  main.tex              # Root document
  references.bib        # BibTeX references
  icml2025.sty          # ICML 2025 style
  icml2025.bst          # ICML 2025 bibliography style
  sections/
    00_abstract.tex
    01_introduction.tex
    02_related_work.tex
    03_methodology.tex
    04_experiments.tex
    05_results.tex
    06_discussion.tex
    07_conclusion.tex
  figures/              # All paper figures (PNG)
  output.pdf            # Compiled PDF (after build)
```

## Compilation

```bash
cd overleaf/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Or use Overleaf: upload the entire folder contents, set compiler to pdfLaTeX.
