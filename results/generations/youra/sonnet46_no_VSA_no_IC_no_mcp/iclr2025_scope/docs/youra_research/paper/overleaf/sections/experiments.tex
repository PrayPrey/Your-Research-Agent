\section{Experimental Setup}
\label{sec:setup}

\textbf{F1 scale:} All F1 values in this paper are reported as percentages (standard LongBench reporting convention). Tables also show raw 0--1 scale values in parentheses for completeness.

We design experiments to answer three diagnostic research questions:

\textbf{RQ1:} Is the M0 (full KV) pipeline functionally correct on LongBench 4-task QA?

\textbf{RQ2:} Does the KV shape eviction mechanism (50\% retention, top-k per head per layer) reduce cache dimensions as expected?

\textbf{RQ3:} Does M1 (prefill-observation with \texttt{DynamicCache} reconstruction) produce non-degenerate generation?

\subsection{Dataset}

We evaluate on LongBench v1~\cite{bai2023longbench}, using 4 QA tasks:

Examples sampled with seed=42, truncated to 4096 tokens (LLaMA-2 native context window).

\subsection{Model}

LLaMA-2-7B-chat-hf~\cite{Touvron2023LLaMA2}: instruction-tuned, 7B decoder-only, 32 transformer layers, 4096-token native context. FP16 on a single A100 40GB GPU.

\subsection{Implementation Details}

Key hyperparameters:
\begin{itemize}
\item \texttt{retention\_ratio}: 0.50 (M1/M2: retain 50\% of KV positions, $k=2048$ from 4096)
\item \texttt{observation\_window}: 16 (M1: last $W=16$ query tokens)
\item \texttt{max\_new\_tokens}: 50
\item \texttt{attn\_implementation}: \texttt{eager} (required for attention weight capture)
\end{itemize}
