## Compilation (Local)

```bash
cd overleaf/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Output: `main.pdf`

## Overleaf Upload

1. Zip this entire `overleaf/` folder
2. Go to overleaf.com → New Project → Upload Project → select zip
3. Download `icml2025.sty` from https://icml.cc/Conferences/2025/StyleAuthorInstructions
4. Upload `icml2025.sty` to the Overleaf project root
5. Set compiler to **pdfLaTeX** in Overleaf settings
6. Click Compile

## Notes

- Without `icml2025.sty`, `main.tex` falls back to standard article formatting
- All citations marked `[UNVERIFIED]` in `references.bib` require manual verification
- Figures are PNG; Overleaf handles these natively with pdfLaTeX
