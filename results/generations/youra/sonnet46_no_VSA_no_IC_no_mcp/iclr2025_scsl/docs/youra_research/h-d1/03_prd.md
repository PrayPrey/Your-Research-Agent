## 1. Executive Summary

H-D1 tests whether contrastive learning (MoCo-v3) encodes spurious features more strongly than supervised ERM on Waterbirds but shows no significant difference on CelebA, confirming that augmentation-invariance — not label-based spurious correlation — drives differential encoding. This is a purely statistical analysis built on pre-computed H-E1 probe results (Waterbirds) plus new CelebA feature extraction.

**Critical pre-finding from H-E1:** ERM_ratio (1.052) > MoCo_ratio (1.027) on Waterbirds — directionally reversed from H-D1's hypothesis. H-D1 formally tests this and documents all pre-registered interpretations.

---

## 2. Problem Statement

Spurious correlations in vision datasets cause representation learning methods to encode dataset-specific shortcuts. H-E1 established that different learning paradigms encode spurious features at different rates on Waterbirds. H-D1 asks: is the paradigm effect dataset-specific (Waterbirds but not CelebA), and does the direction of the effect confirm the augmentation-invariance mechanism story?

## 3. Functional Requirements

### FR-1: CelebA Data Pipeline

- **FR-1.1:** Load CelebA via `torchvision.datasets.CelebA(root='./data', split='test', download=True)`
- **FR-1.2:** Build group-balanced test split across (Blond_Hair × Male) — 4 groups, equal count per group
- **FR-1.3:** Apply ImageNet normalization: mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225], resize 224×224
- **FR-1.4:** CelebA minimum group size: ≥ 500 samples per group (use min-count balanced sampling)
- **FR-1.5:** Spurious attribute: Male; Task label: Blond_Hair

### FR-2: CelebA Feature Extraction

- **FR-2.1:** Extract frozen ResNet-50-ERM features: `torchvision.models.resnet50(pretrained=True)` with `model.fc = nn.Identity()` — same checkpoint as H-E1
- **FR-2.2:** Extract frozen MoCo-v3 features: `torch.hub.load('facebookresearch/moco-v3', 'resnet50')` — same checkpoint as H-E1
- **FR-2.3:** Output: 2048-dim feature vectors for entire CelebA balanced test split
- **FR-2.4:** Save CelebA features to `h-d1/celeba_features_{paradigm}.pt` for reproducibility

### FR-3: CelebA Linear Probing

- **FR-3.1:** Train logistic regression probes for spurious (Male) and task (Blond_Hair) on CelebA features
- **FR-3.2:** Seeds: 5 (sklearn random seeds 0–4), same scheme as H-E1
- **FR-3.3:** Group-balanced subset for probe training (same DFR protocol as H-E1)
- **FR-3.4:** Evaluate probe accuracy on balanced test split
- **FR-3.5:** Compute `ratio = spurious_acc / task_acc` per paradigm × seed
- **FR-3.6:** Save results: `h-d1/celeba_probe_results.json` → `{'erm': [r0..r4], 'moco': [r0..r4]}`

### FR-4: Waterbirds Results Loading

- **FR-4.1:** Load pre-computed H-E1 Waterbirds probe results (spurious_acc, task_acc, ratio per paradigm × seed)
- **FR-4.2:** Supported load paths: `h-e1/probe_results_waterbirds.json` or equivalent H-E1 output
- **FR-4.3:** Validate 5 seeds × 4 paradigms (ERM, MoCo-v3, DINO, BarlowTwins) all present
- **FR-4.4:** Extract only ERM and MoCo-v3 ratio arrays for primary test; all 4 for secondary analyses

### FR-5: Statistical Analysis — Primary Tests

- **FR-5.1 Waterbirds directional test:** `scipy.stats.ttest_ind(moco_wb, erm_wb, alternative='greater')` → `p_wb_directional`
- **FR-5.2 CelebA null test:** `scipy.stats.ttest_ind(moco_ca, erm_ca, alternative='two-sided')` → `p_ca_two_sided`
- **FR-5.3 Effect sizes:** Cohen's d for both tests
- **FR-5.4 Gate evaluation:**
  - Full support: `p_wb_directional < 0.05 AND p_ca_two_sided > 0.1`
  - Partial support: one condition met
  - No support: neither condition met (report negative result)
- **FR-5.5 Pre-registered reversed-direction documentation:** If ERM > MoCo on WB (expected given H-E1), document as "supervised label conditioning encodes MORE spurious features" — valid scientific finding

### FR-6: Statistical Analysis — Secondary Tests

- **FR-6.1 Pearson r:** Correlation between spurious/task ratio and worst-group accuracy gap across all probe runs (4 paradigms × 2 datasets × 5 seeds = 40 runs)
- **FR-6.2 Worst-group accuracy gap:** Load from H-E1 and H-E2 outputs (WGA per paradigm × dataset × seed)
- **FR-6.3:** `scipy.stats.pearsonr(ratios_all, wga_gaps_all)` with 95% CI via bootstrap (n=1000)
