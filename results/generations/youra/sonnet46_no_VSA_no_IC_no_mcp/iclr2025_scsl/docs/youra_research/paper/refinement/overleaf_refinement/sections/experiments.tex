\subsubsection{4.3 Implementation Details}

Feature extraction is performed once per backbone with no gradient and cached to disk. All probes use sklearn LogisticRegression (C = 1.0, lbfgs, max\_iter = 1000). Group-balanced validation split is constructed by sampling equal counts per group from WILDS val metadata. Experiments run on NVIDIA H100 NVL GPUs.
