# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `references.bib` - Bibliography
- `sections/` - Section files (00-08)
- `figures/` - PNG figures

## Upload to Overleaf

1. Create new Overleaf project
2. Upload all files preserving folder structure
3. Set main document to `main.tex`
4. Compile
