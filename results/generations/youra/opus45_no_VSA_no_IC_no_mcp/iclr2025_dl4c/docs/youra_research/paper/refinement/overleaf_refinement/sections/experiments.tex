For H-M1, 1,095 buggy samples were generated across four bug types (type, logic, syntax, off-by-one) from HumanEval and MBPP. For H-M2, a minimal validation of 5 HumanEval problems was conducted. For H-M3, 147 edit records were analyzed from 100 samples (50 HumanEval, 50 MBPP).

\subsubsection{4.2 Model and Configuration}

\begin{itemize}
\item \textbf{Model:} CodeLlama-7B-Instruct
\item \textbf{Iterations:} k=3
\item \textbf{Temperature:} 0.2
\item \textbf{Timeout:} 10s per execution
\item \textbf{Memory limit:} 512MB
\end{itemize}

\subsubsection{4.3 Metrics}

\begin{itemize}
\item \textbf{Primary:} pass@1 after k=3 refinement iterations
\item \textbf{Mechanism:} CF-score distribution, edit scope distribution, fix rate by scope
\end{itemize}
