\subsubsection{Baselines}

Primary baseline: Self-repair with raw compiler output following the theoxo/self-repair framework.

Control conditions:
\begin{itemize}
\item Scrambled: Structured format content with randomly permuted section order
\end{itemize}

\subsubsection{Evaluation Metrics}

Primary metric: Repair success rate (proportion of errors successfully fixed within max iterations).

Statistical significance: p < 0.05 threshold with Benjamini-Hochberg FDR correction for multiple comparisons.

\subsubsection{Implementation Details}

\begin{itemize}
\item Temperature: 0.0 for deterministic comparison
\item Maximum repair iterations: 5
\item Hardware: $5\times$ NVIDIA H100 NVL (95GB each)
\item Seeded randomization (seed=42) for reproducibility
\end{itemize}
