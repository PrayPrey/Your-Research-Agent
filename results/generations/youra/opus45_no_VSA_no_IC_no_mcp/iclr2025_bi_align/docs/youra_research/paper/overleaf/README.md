# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Section files (00-08)
- `figures/` - Figure files
- `references.bib` - BibTeX references

## Upload to Overleaf

1. Zip entire `overleaf/` folder
2. Upload to Overleaf as new project
3. Set main document to `main.tex`
