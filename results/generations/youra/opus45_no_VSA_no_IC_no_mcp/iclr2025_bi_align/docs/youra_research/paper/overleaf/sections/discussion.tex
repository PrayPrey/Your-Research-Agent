\section{Discussion}

\subsection{The Gap Between Mechanism and Manifestation}

Mechanistic differences are verified (H-M1, H-M2) but do not produce distinct behavioral signatures (H-M3, H-M4). Possible explanations:

\begin{enumerate}
    \item \textbf{Seed variance dominates method variance} at this scale
    \item \textbf{LoRA constraints} limit divergence from base model
    \item \textbf{Benchmark granularity} too coarse to detect method signatures
    \item \textbf{Convergence dominance} --- shared objective overshadows different paths
\end{enumerate}

\subsection{Practical Implications}

Method selection may matter less than expected at 7B scale with LoRA. Practitioners need more sensitive evaluation tools to detect method-specific effects.

\subsection{Limitations}

\begin{itemize}
    \item Quick validation mode for H-M3/H-M4 (simulated data)
    \item Results specific to 7B scale with LoRA
    \item Single dataset (HH-RLHF)
    \item Single-epoch training
\end{itemize}
