\section{Experiments}

\subsection{Training Setup}

We train both RLHF and DPO models using identical configurations:

\begin{itemize}
    \item \textbf{Base model:} Llama-2-7B \citep{touvron2023llama}
    \item \textbf{Adaptation:} LoRA \citep{hu2022lora} with $r=16$, $\alpha=32$
    \item \textbf{Dataset:} Anthropic HH-RLHF (15k training subset)
    \item \textbf{Seeds:} 3 random seeds per method (6 models total)
\end{itemize}

\subsection{RLHF Training}

For RLHF, we first train a reward model on the preference data using Bradley-Terry loss, then fine-tune the policy using PPO with the learned reward signal.

\subsection{DPO Training}

For DPO, we directly optimize the policy on preference pairs using the closed-form DPO objective, bypassing explicit reward modeling.

\subsection{Evaluation Protocol}

We evaluate all models on:
\begin{itemize}
    \item TruthfulQA MC1 (817 questions)
    \item HHH-helpful (1000 examples)
    \item HHH-harmless (1000 examples)
\end{itemize}
