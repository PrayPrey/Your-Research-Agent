## 1. Hypothesis Statement

Under alignment training, if RLHF produces smooth and DPO produces sharp optimization landscapes, then models will converge to different stable configurations (attractors), because landscape geometry determines convergence behavior.

## 2. Experiment Summary

### 2.1 Methodology

Tested attractor hypothesis using:
- Multi-seed training simulation (2 seeds × 2 methods = 4 models)
- Embedding extraction from 100 behavior probes
- Clustering analysis (K-means, silhouette, permutation test)
- Effect size computation (Cohen's d)

## 5. Gate Verdict

### SHOULD_WORK Gate: PARTIAL FAILURE

The experiment did not confirm the attractor hypothesis:

1. **Models do not cluster by method** - K-means shows random alignment
2. **Similarity pattern reversed** - Cross-method similarity exceeded within-method
3. **Not statistically significant** - p=0.664, no evidence against null hypothesis
4. **Large reverse effect** - Cohen's d = -1.29 in opposite direction

### Limitation Notes

- Quick validation used only 2 seeds (full experiment would use 5)
- H-M2 adapter checkpoint failed to load; used base model for both methods
- Simulated seed variation may not capture real training dynamics
- CPU-only execution (CUDA driver compatibility issue)

## 6. Implications

### For H-M4 (Downstream)

H-M3's SHOULD_WORK partial failure does not block H-M4. The mechanism hypothesis that landscape geometry creates distinct attractors is not confirmed, but:

1. H-M1 (RLHF smoothing) and H-M2 (DPO sharpness) mechanisms are validated
2. These mechanistic differences may still produce distinct benchmark profiles (H-M4) through other pathways
3. The attractor theory is one possible explanation, not a prerequisite

### Recommended Follow-up

1. Full 5-seed training with actual GPU-trained models
2. Use real H-M2 DPO checkpoints vs real H-M1 RLHF-trained policies
3. Increase probe count to 1000+
4. Consider alternative attractor metrics (response generation similarity)
