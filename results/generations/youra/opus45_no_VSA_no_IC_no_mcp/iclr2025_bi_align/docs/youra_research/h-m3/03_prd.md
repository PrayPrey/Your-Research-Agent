# Product Requirements Document: H-M3 Attractor Analysis

**Hypothesis ID:** h-m3
**Version:** 1.0
**Date:** 2026-08-26

---

## 1. Overview

Validate that RLHF and DPO converge to different stable configurations (attractors) by training multiple seeds and analyzing behavioral clustering.

## 2. Objectives

1. Train 5 DPO and 5 RLHF models with different random seeds
2. Extract behavioral embeddings from consistent probe prompts
3. Compute within-method vs cross-method similarity
4. Statistically validate method-based clustering

## 3. Success Criteria

| Metric | Threshold | Priority |
|--------|-----------|----------|
| clustering_gap | > 0.05 | PRIMARY |
| silhouette_score | > 0.1 | PRIMARY |
| Cohen's d | > 0.3 | PRIMARY |
| p-value (permutation) | < 0.05 | PRIMARY |

## 4. Functional Requirements

### FR-1: Multi-Seed Training
- Train 5 DPO models (seeds: 42, 137, 256, 512, 1024)
- Train 5 RLHF models (same seeds)
- Reuse H-M1/H-M2 configurations
- Log training trajectories

### FR-2: Behavior Probe Generation
- Extract 1000 probe prompts from HH-RLHF
- Generate responses from all 10 models
- Extract last-layer hidden state embeddings

### FR-3: Clustering Analysis
- Compute pairwise cosine similarity matrix
- Calculate within-method and cross-method means
- Run K-means (k=2) clustering
- Compute silhouette scores

### FR-4: Statistical Validation
- Permutation test (1000 iterations)
- Cohen's d effect size
- Bootstrap confidence intervals

### FR-5: Visualization & Reporting
- t-SNE visualization of attractors
- Similarity heatmap
- Generate 04_validation.md
