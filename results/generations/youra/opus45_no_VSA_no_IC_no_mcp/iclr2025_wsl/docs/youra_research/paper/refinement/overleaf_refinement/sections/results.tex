\textbf{Backdoor Detection:} All architectures perform at chance level (AUC ~0.48). The synthetic backdoor signal (localized row perturbation in one layer) was not learnable by any architecture. Possible causes include:
\begin{itemize}
\item Signal absorbed by z-score normalization
\item Random layer/row selection provides no consistent spatial pattern
\item Perturbation does not mimic real backdoor signatures
\end{itemize}

\textbf{Accuracy Prediction:} NFT achieves RMSE 82.9 compared to DWS 94.5 and MLP 90.1. The 12.3\% improvement of NFT over DWS is consistent with the hypothesis that global attention captures aggregate statistics more effectively.

\textbf{Interaction Effect:} Two-way ANOVA yields F=45616.06, p<0.001. The interaction effect is statistically significant, but the observed pattern is partial: NFT advantage on accuracy is confirmed, while the hypothesized DWS advantage on backdoor detection is not observed (all architectures at chance).
