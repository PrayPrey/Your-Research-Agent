\section{Experimental Setup}

We design experiments to answer the following questions:

\textbf{RQ1:} Do DWS and NFT architectures encode measurably different inductive biases?

\textbf{RQ2:} Does this inductive bias difference translate to task-dependent performance advantages?

\textbf{RQ3:} Is there a statistically significant interaction effect between architecture and task type?

\subsection{Datasets}

\textbf{MNIST-INR Dataset:} Implicit Neural Representation networks trained on MNIST digits. 600 training samples, 200 test samples, $\sim$40K weights per model.

\textbf{Synthetic Property Prediction Dataset:} Two-task dataset with backdoor (local perturbation) and accuracy (global statistic) targets.

\subsection{Evaluation Metrics}

\begin{itemize}
    \item \textbf{CoV:} Coefficient of variation for inductive bias measurement
    \item \textbf{AUC:} Backdoor detection performance
    \item \textbf{RMSE:} Accuracy prediction performance
    \item \textbf{Two-way ANOVA:} Interaction effect testing
\end{itemize}
