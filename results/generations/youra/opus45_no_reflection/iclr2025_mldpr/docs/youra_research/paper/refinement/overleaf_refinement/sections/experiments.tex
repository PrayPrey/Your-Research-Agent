
\subsubsection{Research Questions}

\begin{itemize}
\item \textbf{RQ1:} Does aggregate Gini exhibit structural breaks within 2019--2022?
\item \textbf{RQ2:} Did foundation papers achieve exceptional citation impact?
\item \textbf{RQ3:} Did emergent benchmark creation accelerate post-2020?
\item \textbf{RQ4:} Did attention shift from traditional to emergent benchmarks?
\item \textbf{RQ5:} Did modality dynamics diverge after foundation model emergence?
\end{itemize}

\subsubsection{Dataset}

Papers With Code benchmark data: January 2018 -- December 2024 (84 months, 5,858 datasets, 48,963 evaluation records).

\subsubsection{Baselines}

\begin{itemize}
\item \textbf{Monotonic Trend (Null):} Single trend without structural breaks ($R^2$ = 0.30, BIC = $-480.49)$
\item \textbf{Koch et al. (2021):} Gini 0.6--0.7 for 2015--2020 as baseline concentration reference
\end{itemize}
