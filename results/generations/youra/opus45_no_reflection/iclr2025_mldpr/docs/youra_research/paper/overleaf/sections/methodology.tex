\section{Methodology}
\label{sec:methodology}

\subsection{Data Source}

We use Papers With Code (PWC) as our primary data source, covering 2018--2024 with monthly resolution. PWC provides task-dataset-metric triplets for ML benchmark evaluations, enabling precise measurement of benchmark usage.

\subsection{Concentration Metrics}

We measure benchmark concentration using the Gini coefficient, following Koch et al.\ (2021). Gini ranges from 0 (perfect equality) to 1 (perfect concentration). We compute monthly aggregate Gini across all task-dataset-metric triplets.

\subsection{Change-Point Detection}

To detect structural breaks, we apply the Pruned Exact Linear Time (PELT) algorithm \cite{killick2012optimal}. PELT identifies an unknown number of change points by minimizing a penalized cost function.

\textbf{Key parameters:}
\begin{itemize}
    \item Model: RBF kernel
    \item Minimum segment size: 3 months
    \item Penalty: BIC-derived ($\beta = 1.87$)
\end{itemize}

\textbf{Baseline comparison:} We compare against a monotonic trend null hypothesis. We acknowledge this is the only baseline tested; comparison with alternative change-point methods (e.g., Bayesian change-point detection, CUSUM) remains for future work.

\subsection{Model Comparison}

We compare two models using Bayesian Information Criterion (BIC):
\begin{enumerate}
    \item \textbf{Null (Monotonic):} Single monotonic trend over 2018--2024
    \item \textbf{Alternative (Segmented):} Multiple segments separated by PELT-detected change points
\end{enumerate}
