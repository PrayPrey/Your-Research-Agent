## Methodology

### Data Source
- Papers With Code dataset (`pwc-archive/datasets`) via HuggingFace
- 15,008 benchmarks with `introduced_date` field

### Classification Rules
Benchmarks classified as "emergent-capability" if:
1. Name matches known emergent benchmarks (MMLU, HumanEval, BIG-Bench, etc.)
2. Description contains emergent keywords (reasoning, capability, understanding, etc.)
3. Task type is emergent-focused (question-answering, code-generation, math-word-problems)

### Date Extraction
- Primary: `introduced_date` field from PWC metadata
- 507 emergent benchmarks without dates excluded from ratio calculation
