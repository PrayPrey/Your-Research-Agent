\section{Experimental Setup}

We evaluate the core hypothesis (H-E1): \emph{CV of probe accuracy trajectories distinguishes spurious from core features with AUC $\geq$ 0.75}.

\subsection{Dataset}

\textbf{Waterbirds} \citep{sagawa2020distributionally}: Train split has 4,795 samples with 95\% correlation between background and label.

\subsection{Research Questions}

\begin{enumerate}
    \item Can CV distinguish feature types?
    \item What classification performance does CV achieve?
    \item Are probe trajectories informative?
\end{enumerate}
