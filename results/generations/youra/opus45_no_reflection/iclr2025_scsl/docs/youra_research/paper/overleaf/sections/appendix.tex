\subsection{Dataset Statistics}

Waterbirds dataset statistics:
\begin{itemize}
    \item Training samples: 4,795
    \item Spurious correlation: 95\% between background and label
    \item Feature dimension: 512 (CLIP ViT-B/16)
\end{itemize}

\subsection{Compute Resources}

All experiments were conducted on a single GPU with CLIP feature extraction taking approximately 5 minutes for the full dataset.
