\subsubsection{5.5 Per-Condition Analysis}

Examining the raw results data (600 signals), conditions C1--C3 achieve AS\_loc=1 for problems with traceback-rich errors, while C4--C6 consistently show AS\_loc=0. This pattern holds across error types, but assertion errors show AS\_loc=1 only for C1--C3 with minimal causal and state information.
