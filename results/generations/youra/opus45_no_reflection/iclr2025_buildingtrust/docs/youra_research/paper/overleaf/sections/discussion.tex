\section{Discussion}

\subsection{Summary}

The methodology for testing calibration-mediated factuality-robustness correlation is validated. Full results await real experimental data.

\subsection{Critical Limitations}

\begin{enumerate}
    \item \textbf{Mock ASR data}: TextFooler ASR simulated, invalidating all correlation findings
    \item \textbf{Sample size}: 3/12 models evaluated, insufficient for statistical inference
\end{enumerate}

\subsection{Acceptable Limitations}

\begin{enumerate}
    \item Correlational design (temperature scaling provides quasi-causal evidence)
    \item Word-level perturbations only
    \item Open-weight models only
\end{enumerate}

\subsection{Future Work}

\begin{enumerate}
    \item Run real TextFooler attacks
    \item Complete 12-model evaluation
    \item Execute ECE-based mediation analysis
\end{enumerate}
