
\subsubsection{Summary}

This paper presents a methodology for testing whether calibration quality mediates the correlation between LLM factuality and adversarial robustness. The experimental pipeline is validated and executes successfully. However, experimental results are incomplete and cannot support or refute the hypothesis.

\subsubsection{Critical Limitations}

\begin{enumerate}
\item \textbf{Simulated ASR Data}: TextFooler Attack Success Rates were generated via simulation formula rather than actual adversarial attacks. All correlation values are artifacts. The simulation formula \texttt{asr = 0.35 + random(0, 0.1) - 0.3*mc1} creates artificial negative correlation with MC1.
\end{enumerate}

\begin{enumerate}
\item \textbf{Insufficient Sample Size}: Only 3 of 12 planned models were evaluated. Statistical inference requires the full model set. Bootstrap confidence intervals could not be computed.
\end{enumerate}

\begin{enumerate}
\item \textbf{Missing Mechanism Tests}: Sub-hypotheses H-M1 (ECE variance), H-M2 (ECE-MC1 relationship), and H-M3 (mediation analysis) were not executed.
\end{enumerate}

\subsubsection{Technical Issues Encountered}

\textbf{Tokenizer Padding}: Llama and Mistral models required explicit padding token assignment (\texttt{tokenizer.pad\textbackslash \_token = tokenizer.eos\textbackslash \_token}) for TextFooler compatibility.

\textbf{Memory Constraints}: 70B parameter models exceeded single GPU memory (78.59 GiB used on 93 GiB GPU). Multi-GPU distribution or quantization required.

\textbf{Architecture Incompatibility}: FLAN-T5 encoder-decoder architecture incompatible with TextFooler's classification attack format.

\subsubsection{Acceptable Limitations}

\begin{enumerate}
\item \textbf{Correlational Design}: The study is fundamentally correlational. Temperature scaling provides quasi-causal evidence but cannot establish causation.
\end{enumerate}

\begin{enumerate}
\item \textbf{Word-Level Perturbations}: TextFooler tests word-level robustness only. Findings may not generalize to character-level, sentence-level, or semantic perturbations.
\end{enumerate}

\begin{enumerate}
\item \textbf{Open-Weight Models Only}: Proprietary models (GPT-4, Claude) excluded. Findings may not generalize to closed-source systems.
\end{enumerate}

\subsubsection{What Would Be Required to Complete This Study}

\begin{enumerate}
\item Execute real TextFooler attacks on all 12 models (500+ examples each)
\item Extract ECE from TruthfulQA logit predictions
\item Compute valid Pearson correlation with bootstrap CI
\item Run partial correlation controlling for log(parameters)
\item Execute Baron-Kenny mediation analysis
\item Apply temperature scaling intervention
\end{enumerate}

\subsubsection{Estimated Resources}

\begin{itemize}
\item Multi-GPU setup for 70B models or quantization fallback
\item 4-8 hours compute time for full 12-model evaluation
\item Real TextFooler attacks (approximately 500 examples $\times$ 12 models)
\end{itemize}
