
\subsubsection{Implementation}

The evaluation pipeline consists of four modules:

\textbf{TruthfulQA Evaluation}: EleutherAI lm-evaluation-harness with task \texttt{truthfulqa\textbackslash \_mc1}, batch size 4, full validation set (817 questions).

\textbf{TextFooler Attack}: QData TextAttack framework with \texttt{textfooler} recipe on SST-2 validation set (target 500-1000 examples per model).

\textbf{ECE Computation}: 10 equal-frequency bins from TruthfulQA prediction logits.

\subsubsection{Success Criteria}

\textbf{Primary (P1)}: Pearson r > 0.5 with p < 0.05 between MC1 and (1-ASR)

\textbf{Secondary (P2)}: Mediation percentage > 30\% of total effect via ECE

\textbf{Tertiary (P3)}: Temperature scaling improves both metrics in $\geq 2/3$ models tested

\subsubsection{Failure Conditions}

\begin{itemize}
\item If r < 0.3 after controlling for scale: ABANDON hypothesis
\item If 0.3 < r < 0.5: PIVOT to investigate confounds
\item If ECE variance < 0.001: PIVOT to alternative calibration metric (Brier score)
\end{itemize}
