
\subsection{Fidelity and Richness: An Orthogonal Framework}

We decompose feedback quality into two independent dimensions:

\textbf{Signal Fidelity}: The probability that feedback is factually correct. Execution feedback achieves near-perfect fidelity. AI feedback has low fidelity ($\sim$39\% correctness).

\textbf{Semantic Richness}: The amount of explanatory content about \emph{why} code is wrong. Execution feedback has minimal richness. AI feedback is maximally rich.

We observe these dimensions are orthogonal. A method can achieve high fidelity \emph{and} high richness if we filter rich signals through a fidelity check.

\subsection{EVAF: Execution-Verified AI Feedback}

EVAF treats execution as a verification layer for AI feedback:

\begin{enumerate}
    \item \textbf{AI Critique Generation}: Given problem description and failing code, generate critique and proposed fix.
    \item \textbf{Code Extraction}: Parse fenced code blocks from AI response.
    \item \textbf{Execution Gating}: Execute extracted fix against unit tests (3.0s timeout, subprocess isolation).
    \item \textbf{Accept/Reject Decision}: Accept if all tests pass; reject otherwise.
\end{enumerate}

\subsection{Accept Rate as Viability Indicator}

\begin{itemize}
    \item \textbf{$<$10\%}: EVAF degenerates to pure execution feedback
    \item \textbf{20--60\%}: AI provides substantive verified feedback (viable)
    \item \textbf{$>$90\%}: Execution gating unnecessary
\end{itemize}

\subsection{Implementation Architecture}

Seven Python modules:
\begin{itemize}
    \item \textbf{config.py}: Fixed configuration constants
    \item \textbf{data.py}: HumanEval loading via HuggingFace
    \item \textbf{model.py}: BaselineModel (CodeT5-770M) + FeedbackModel (CodeLlama-7b-Instruct)
    \item \textbf{gating.py}: Code extraction + sandboxed subprocess test execution
    \item \textbf{metrics.py}: Accept rate, coverage, rejection breakdown
    \item \textbf{visualize.py}: Three required figures
    \item \textbf{train.py}: Pipeline orchestration
\end{itemize}
