
\subsubsection{4.1 Research Question}

Can EVAF produce filtered AI feedback with accept rate in the 20-60\% range on HumanEval?

\subsubsection{4.2 Dataset}

HumanEval: 164 Python programming problems with unit tests, loaded via HuggingFace datasets (\texttt{openai\textbackslash \_humaneval}, test split).

\subsubsection{4.3 Models}

\begin{itemize}
\item \textbf{Baseline Generator}: CodeT5-770M (\texttt{Salesforce/codet5-large}), encoder-decoder architecture, 770M parameters.
\item \textbf{Feedback Generator}: CodeLlama-7b-Instruct (\texttt{codellama/CodeLlama-7b-Instruct-hf}), decoder-only architecture, 7B parameters, loaded in float16 with device\_map=''auto''.
\end{itemize}

\subsubsection{4.5 Evaluation Protocol}

\begin{enumerate}
\item Generate baseline code for all 164 HumanEval problems
\item Execute baseline code against tests; filter to failing problems
\item For each failing problem, run EVAF gating (generate feedback, extract code, execute tests)
\item Compute accept rate and secondary metrics
\item Evaluate gate condition
\end{enumerate}
