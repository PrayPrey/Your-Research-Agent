# BiDPO Paper - Overleaf Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Section files (00-07)
- `figures/` - PNG figures
- `references.bib` - BibTeX references

## Overleaf Upload

Upload entire folder to Overleaf. Set main document to `main.tex`.
