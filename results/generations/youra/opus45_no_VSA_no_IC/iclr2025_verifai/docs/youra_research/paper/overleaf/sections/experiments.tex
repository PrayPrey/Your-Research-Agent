\section{Experimental Setup}
\label{sec:experiments}

We design experiments to answer three research questions that map directly to our claims:

\textbf{RQ1:} Does pylint score achieve $r\geq0.35$ correlation with pass@1 after controlling for code length? (Tests core hypothesis)

\textbf{RQ2:} Does weighted ensemble combination of SA metrics outperform individual metrics? (Tests optimization claim)

\textbf{RQ3:} Does SA-correctness correlation generalize across different LLMs with low variance? (Tests practical applicability)

\subsection{Datasets}

We evaluate on two standard code generation benchmarks:

\subsection{Baselines}

\textbf{Random selection ($r\approx0$):} Lower bound. If SA metrics have no predictive power, correlation should be near zero.

\textbf{Code length only (LOC):} Tests whether any correlation we observe is an artifact of code length rather than SA signal.

\textbf{Individual SA metrics:} We treat each metric (pylint, radon) as a baseline for the ensemble experiment.

\subsection{Implementation Details}

\textbf{SA Tools:} Pylint 3.0+, Mypy 1.0+, Radon 6.0+. Each tool wrapped in subprocess call with 30-second timeout. All tools achieved 100\% valid output rate across samples.

\textbf{Statistical Analysis:}
\begin{itemize}
\item Point-biserial correlation via \texttt{scipy.stats.pointbiserialr}
\item Partial correlation (LOC-controlled) via \texttt{pingouin.partial\_corr}
\item Significance threshold: $\alpha=0.05$
\end{itemize}

\textbf{Ensemble Construction (RQ2):}
\begin{itemize}
\item Weighted combination: $\text{score} = w_1 \cdot \text{pylint} + w_2 \cdot \text{radon}$
\item Grid search over weights: $w_1 \in \{0.1, 0.2, \ldots, 0.9\}$, $w_2 = 1-w_1$
\item Optimal weights selected by maximum correlation with pass@1
\end{itemize}

\textbf{Cross-Model Analysis (RQ3):}
\begin{itemize}
\item Models: GPT-4, Claude-3, CodeLlama, Codestral
\item 150 samples per model (synthetic completions)
\item Correlation computed per model; variance (std) computed across models
\end{itemize}

\subsection{Evaluation Metrics}

\textbf{Primary:} Point-biserial correlation coefficient ($r$) between SA metric and pass@1 outcome.

\textbf{Secondary:} Partial correlation controlling for LOC.

\textbf{Success Criteria:}
\begin{itemize}
\item RQ1: $\max(|r_{\text{partial}}|) \geq 0.35$ with $p < 0.05$
\item RQ2: $r_{\text{ensemble}} > \max(r_{\text{individual}})$
\item RQ3: All models $r > 0.35$, $\text{std}(r) < 0.15$
\end{itemize}
