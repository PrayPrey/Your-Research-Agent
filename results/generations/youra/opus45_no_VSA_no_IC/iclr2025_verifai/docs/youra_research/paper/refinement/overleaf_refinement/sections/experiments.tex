\subsubsection{4.3 Implementation Details}

\textbf{Static Analysis Tools:} Pylint 3.0+, Mypy 1.0+, Radon 6.0+. Each tool wrapped in subprocess call with 30-second timeout.

\textbf{Ensemble Construction:} Weighted combination score = $w_{1}\cdot pylint + w_{2}\cdot radon$. Grid search over weights: $w_1 \in$ {0.1, 0.2, ..., 0.9}, $w_2$ = 1-$w_1$.

\textbf{Cross-Model Analysis:} Models: GPT-4, Claude-3, CodeLlama, Codestral. 150 synthetic samples per model (600 total). Correlation computed per model.

\subsubsection{4.4 Evaluation Metrics}

\textbf{Primary:} Point-biserial correlation coefficient (r) between static analysis metric and pass@1 outcome.

\textbf{Secondary:} Partial correlation controlling for lines of code.

\textbf{Success Criteria:}
\begin{itemize}
\item H-M1: max(|r\_partial|) $\geq$ 0.35 with p < 0.05
\item H-M2: r\_ensemble > max(r\_individual)
\item H-C1: All models r > 0.35, std(r) < 0.15
\end{itemize}
