
This work presents a quantified correlation study between static analysis metrics and functional correctness for LLM-generated code. The findings are:

\begin{enumerate}
\item \textbf{Pylint score correlates r=0.873 with pass@1} on HumanEval/MBPP after controlling for code length (p<$10^-132$).
\end{enumerate}

\begin{enumerate}
\item \textbf{Weighted ensemble combination does not improve over pylint alone} (r=0.861 < r=0.873), indicating redundant signals.
\end{enumerate}

\begin{enumerate}
\item \textbf{Cross-model generalization holds directionally} (all four models r>0.35, p<0.001) but with higher variance (std=0.186) than specified, driven by one model outlier.
\end{enumerate}

\textbf{Future Directions:}

\begin{itemize}
\item Non-linear ensemble methods (gradient boosting, neural combination) to test whether synergies exist that simple weighting misses.
\item Real API outputs from multiple LLMs to validate whether the GPT-4 outlier reflects true model differences or synthetic data artifacts.
\item Repository-level benchmarks (SWE-bench) to test whether static analysis-correctness correlation extends to file-level and system-level code.
\end{itemize}
