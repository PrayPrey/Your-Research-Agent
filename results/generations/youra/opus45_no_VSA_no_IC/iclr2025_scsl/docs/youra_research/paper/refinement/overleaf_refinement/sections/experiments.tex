\subsubsection{4.3 Evaluation Protocol}

\begin{itemize}
\item \textbf{FLOP measurement:} calflops library
\item \textbf{Perplexity:} exp(cross-entropy loss) on test set (1000 samples)
\item \textbf{Attention entropy:} H = -$\Sigma$ p log p computed across attention distributions
\item \textbf{Sequence lengths tested:} 128, 512, 1024 tokens
\end{itemize}
