
\subsubsection{4.1 Experiment 1: Mode 3 Existence (H-E1)}

\textbf{Objective}: Determine whether Mode 3 constitutes a substantial proportion of preference battles.

\textbf{Setup}: 57,477 battles processed. Entropy and variance computed per battle. Median-split classification applied to both dimensions.

\textbf{Success Criterion}: Mode 3 proportion statistically greater than 10\% (p < 0.05).

\subsubsection{4.2 Experiment 2: Semantic Similarity (H-M1)}

\textbf{Objective}: Test whether Mode 3 arises from semantic divergence between response pairs.

\textbf{Setup}: Sentence embeddings computed using all-MiniLM-L6-v2. Cosine similarity calculated between response\_a and response\_b for each battle. Mode 1 (n = 15,107) and Mode 3 (n = 13,632) compared.

\textbf{Prediction}: Mode 3 similarity lower than Mode 1, Cohen's d > 0.3.

\subsubsection{4.3 Experiment 3: Prompt Type (H-C1)}

\textbf{Objective}: Test whether Mode 3 concentrates in subjective tasks.

\textbf{Setup}: Keyword-based prompt classification. Subjective keywords: ''story'', ''creative'', ''write'', ''poem'', ''essay''. Objective keywords: ''code'', ''math'', ''calculate'', ''solve'', ''algorithm''. Battles not matching either category (75\%) excluded.

\textbf{Prediction}: Subjective/Objective Mode 3 ratio > 1.5.
