\section{Methodology}

\subsection{Dataset}

We use the LMSYS Chatbot Arena dataset \cite{zheng2024judging} (57,477 pairwise battles). Each battle includes a prompt, two model responses, and human preference votes.

\subsection{Human Vote Entropy}

For each model pair, we compute Shannon entropy over the vote distribution:
\begin{equation}
H = -\sum_{i \in \{A, B, \text{tie}\}} p_i \log_2 p_i
\end{equation}
We binarize entropy using median split: above median = ``high entropy'' (disagreement).

\subsection{Reward Model Variance Proxy}

We use OpenAssistant reward model and compute absolute score difference:
\begin{equation}
\text{variance\_proxy} = |RM(A) - RM(B)|
\end{equation}
Low difference $\rightarrow$ high variance (uncertainty). Median split binarizes.

\subsection{Hypothesis Tests}

\begin{itemize}
    \item \textbf{H-E1}: Mode~3 $>$ 10\% (binomial test, MUST\_WORK)
    \item \textbf{H-M1}: Mode~3 similarity $<$ Mode~1 (t-test, Cohen's $d > 0.3$)
    \item \textbf{H-C1}: Subjective/Objective Mode~3 ratio $> 1.5$
\end{itemize}
