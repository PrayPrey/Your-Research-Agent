\section{Methodology}

\subsection{Task Definition}

Given a neural network's weight matrices $W = \{W_1, W_2, \ldots, W_L\}$, predict its test accuracy $a \in [0, 1]$. The challenge: hidden unit permutations within each layer create equivalent weight configurations.

\subsection{Dataset}

We use a synthetic ResNet-20/CIFAR-10 model zoo of 6,000 models ($\sim$270K parameters, 21 weight layers). Accuracy ranges 70--95\%. Train sizes $N \in \{100, 250, 500, 1000, 2500, 5000\}$, test size 500 (fixed). All experiments use 10 random seeds.

\subsection{Methods}

\textbf{Statistics Baseline}: 7 statistics per layer (mean, std, min, max, L1/L2/spectral norm) $\rightarrow$ 63 features $\rightarrow$ RidgeCV.

\textbf{MLP Baseline}: Flattened $\sim$270K weights $\rightarrow$ 2-layer MLP (256 units, ReLU, BatchNorm, Dropout=0.3).

\textbf{NFN Model}: DeepSets-style equivariant predictor---per-neuron encoding $\rightarrow$ 2 equivariant layers $\rightarrow$ mean pooling $\rightarrow$ prediction head. Architecture guarantees permutation invariance.

\subsection{Evaluation}

Primary metric: $R^2$ on held-out 500 models. $R^2 < 0$ indicates predictions worse than mean baseline. Secondary: equivariance error ($\max|f(\text{Perm}(W)) - f(W)|$), statistical significance via $t$-test.
