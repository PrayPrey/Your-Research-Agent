
\subsubsection{3.1 Experimental Design}

The experiments test whether optimal LoRA rank $r_{\text{opt}}$ scales sub-linearly with model size $N$, following the relationship $r_{\text{opt}} \propto N^{\alpha}$ where $\alpha < 1$.

\paragraph{Model Selection}

The Pythia model family \citep{biderman2023pythia} spans four scales: 1B, 2.8B, 6.9B, and 12B parameters. Pythia provides identical architecture (GPT-style autoregressive transformer) across scales, eliminating architecture confounds. All models use the same vocabulary, tokenizer, and pre-training corpus (The Pile).

\paragraph{LoRA Configuration}

Following standard practice, LoRA is applied to query and value projection matrices with:
\begin{itemize}
\item \textbf{Ranks}: $r \in \{4, 8, 16, 32, 64, 128\}$
\item \textbf{Scaling}: $\alpha = 2r$ (rsLoRA convention)
\item \textbf{Target modules}: query\_key\_value (Pythia's fused QKV)
\item \textbf{Dropout}: 0.05
\end{itemize}

\paragraph{Task Selection}

Two QA task types were selected to test cross-task consistency:
\begin{itemize}
\item \textbf{SQuAD-v2} \citep{rajpurkar2018squad}: Single-hop extractive QA, 11,873 validation examples
\item \textbf{HotpotQA} \citep{yang2018hotpotqa}: Multi-hop reasoning, 7,405 validation examples
\end{itemize}

\paragraph{Training Protocol}

\begin{itemize}
\item \textbf{Optimizer}: AdamW with $\beta _{1}=0.9, \beta _{2}=0.999$
\item \textbf{Learning rate}: $10^{-4}$ with linear warmup (6\% of steps)
\item \textbf{Epochs}: 3
\item \textbf{Batch size}: 16 (gradient accumulation as needed)
\item \textbf{Seeds}: 3 per configuration (42, 1337, 2024)
\end{itemize}

\subsubsection{3.2 Sub-Hypotheses}

Four testable sub-hypotheses were defined:

\textbf{h-e1 (Existence)}: Log-linear regression of $r_{\text{opt}}$ vs $N$ yields scaling exponent $\alpha$ with 95\% CI excluding both 0 and 1.

\textbf{h-m1 (Mechanism)}: Attention entropy at optimal rank correlates positively with model size (Pearson $r > 0.6$, $p < 0.05$).

\textbf{h-m2 (Phase Transition)}: Rank sensitivity ($\partial \text{accuracy}/\partial \log r$) is $>2\times$ higher at 12B vs 1B.

\textbf{h-c1 (Consistency)}: Scaling exponent $\alpha$ is consistent across single-hop and multi-hop QA: $|\Delta \alpha| \leq 0.15$.

\subsubsection{3.3 Optimal Rank Determination}

Optimal rank is defined as the smallest rank achieving 99\% of rank-128 performance:

$r_{\text{opt}} = \min\{r : \text{F1}(r) \geq 0.99 \cdot \text{F1}(128)\}$

\subsubsection{3.4 Scaling Law Estimation}

The log-linear relationship is fit via:

$\log(r_{\text{opt}}) = \alpha \cdot \log(N) + \beta$

using ordinary least squares with bootstrap confidence intervals (B=1000 resamples).
