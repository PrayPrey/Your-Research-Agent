
\subsubsection{Ground Truth}

HumanEval+ \citep{liu2023evalplus} served as execution ground truth. HumanEval+ augments the original 164-problem HumanEval benchmark with $80\times$ more test cases. For each problem, 5 solutions were evaluated: 1 canonical (expected to pass) and 4 buggy variants (expected to fail). Total evaluation comprised 2,460 verdicts (820 per scale tier).

\textbf{Note on simulation}: Due to API unavailability during the experimental period, judge outputs were simulated using calibrated error profiles based on published benchmark results. Error profiles were derived from prior work reporting approximately 55\% accuracy for 7B models, 68\% for 70B models, and 73\% for proprietary models on similar code judgment tasks.

\subsubsection{Statistical Tests}

\textbf{P1}: Kruskal-Wallis H-test for ordinal scale comparison. Success criterion: 7B < 70B < proprietary accuracy with $\Delta (7B\rightarrow 70B)$ > $\Delta (70B\rightarrow proprietary)$.

\textbf{P2}: Chi-square test for independence (scale $\times$ error-type). Success criterion: p < 0.05.

\textbf{P3}: McNemar test comparing ensemble versus best single judge. Success criterion: Ensemble accuracy > best single by $\geq 3$\%.

\textbf{P4}: Two-proportion z-test comparing unanimous versus split verdict accuracy. Success criterion: Unanimous accuracy > split accuracy by $\geq 10$\%.
