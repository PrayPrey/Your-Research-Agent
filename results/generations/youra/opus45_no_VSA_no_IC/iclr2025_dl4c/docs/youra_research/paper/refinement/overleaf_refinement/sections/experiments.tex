
\subsubsection{Dataset}

HumanEval+ comprising 164 Python problems with augmented test suites. Ground truth: canonical solutions marked as passing, mutated variants as failing.

\subsubsection{Ensemble Methods}

Four ensemble configurations were tested:

\begin{enumerate}
\item \textbf{AB1 (Simple majority vote)}: 2-of-3 agreement determines verdict
\item \textbf{AB2 (Weighted majority)}: Votes weighted by observed per-scale accuracy
\item \textbf{AB3 (Two-tier)}: 70B + proprietary only (excludes 7B)
\item \textbf{AB4 (Random baseline)}: Random selection among judge verdicts
\end{enumerate}
