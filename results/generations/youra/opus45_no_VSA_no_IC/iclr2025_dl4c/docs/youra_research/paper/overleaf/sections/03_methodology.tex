\section{Methodology}

Our methodology isolates the effect of model scale on judge error patterns through controlled experimental design.

\subsection{Ground Truth}

We use HumanEval+ \cite{liu2023evalplus} as execution ground truth. HumanEval+ augments the original 164-problem HumanEval benchmark with 80$\times$ more test cases, enabling rigorous correctness assessment.

\subsection{Controlled Variables}

\begin{itemize}
    \item \textbf{Prompt template}: Fixed zero-shot correctness judgment prompt
    \item \textbf{Temperature}: 0 for reproducibility
    \item \textbf{Benchmark}: HumanEval+ (164 problems)
\end{itemize}

\subsection{Predictions and Statistical Tests}

\textbf{P1 (Scale ordering)}: Kruskal-Wallis H-test. Success: 7B $<$ 70B $<$ proprietary with diminishing returns.

\textbf{P2 (Error patterns)}: Chi-square test. Success: $p < 0.05$ for scale $\times$ error-type association.

\textbf{P3 (Ensemble benefit)}: McNemar test. Success: Ensemble accuracy $>$ best single by $\geq$3\%.

\textbf{P4 (Unanimous reliability)}: Two-proportion z-test. Success: Unanimous accuracy $>$ split by $\geq$10\%.
