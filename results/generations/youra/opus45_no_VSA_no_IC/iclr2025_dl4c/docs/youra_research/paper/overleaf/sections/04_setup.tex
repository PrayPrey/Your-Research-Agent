\section{Experimental Setup}

\subsection{Dataset}

HumanEval+ comprising 164 Python problems with augmented test suites. Total evaluation: 2,460 verdicts (820 per scale tier).

\subsection{Ensemble Methods}

\begin{enumerate}
    \item \textbf{AB1: Simple majority vote}
    \item \textbf{AB2: Weighted majority} (by observed accuracy)
    \item \textbf{AB3: Two-tier} (70B + proprietary only)
\end{enumerate}
