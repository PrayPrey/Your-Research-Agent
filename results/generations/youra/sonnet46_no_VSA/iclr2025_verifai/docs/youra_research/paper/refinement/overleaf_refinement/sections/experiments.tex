\end{itemize}

\subsubsection{4.3 Baselines}

\textbf{EvalPlus differential oracle:} 764-test ground-truth equality --- the strongest available test-based evaluation baseline.  
\textbf{Static CVT contract oracle (Experiment A):} Same CVT inputs; differential vs. contract oracle comparison on identical inputs.  
\textbf{Adaptive PBT oracle (Experiment B):} icontract-hypothesis with 5,000 examples per triple --- measures the contribution of adaptive search beyond static CVT coverage.

\subsubsection{4.4 Implementation Details}

\begin{itemize}
\item Oracle evaluation: 8-process multiprocessing pool; 5 s per-input / 10 s per-program timeouts.
\item Adaptive PBT: icontract-hypothesis; 5,000 examples; 30 s SIGALRM per triple.
\item Statistical analysis: Wilcoxon signed-rank test with Holm correction; 10,000-sample bootstrap CI; MixedLM with powell convergence.
\end{itemize}
