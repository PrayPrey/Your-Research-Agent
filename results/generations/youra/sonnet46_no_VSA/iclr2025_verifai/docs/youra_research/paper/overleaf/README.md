# Overleaf LaTeX Project

**Paper:** Contracts Catch What Tests Miss: Measuring Execution-Based Oracle Strength for LLM-Generated Code

## Compilation Instructions

### Local (pdflatex)
```bash
cd overleaf/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

### Overleaf
1. Upload this entire folder as a zip
2. Download `icml2025.sty` from https://icml.cc/Conferences/2025/StyleAuthorInstructions
3. Upload `icml2025.sty` to the project root
4. In `main.tex`: uncomment `\usepackage{icml2025}` and remove the geometry fallback
5. Set compiler to pdfLaTeX, compile
