## Compilation (Overleaf)

1. Upload this entire folder to a new Overleaf project
2. Download `icml2025.sty` from https://icml.cc/Conferences/2025/StyleAuthorInstructions
3. Upload `icml2025.sty` to the project root
4. Set compiler to **pdfLaTeX**
5. Click Compile

## Compilation (Local)

```bash
cd overleaf/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Requires: `texlive-full` or equivalent. Without `icml2025.sty`, falls back to standard `article` class.
