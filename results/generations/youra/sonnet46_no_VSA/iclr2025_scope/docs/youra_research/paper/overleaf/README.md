## Compilation Instructions

### On Overleaf
1. Upload this entire folder to Overleaf (drag-and-drop zip)
2. Download `icml2025.sty` from https://icml.cc/Conferences/2025/StyleAuthorInstructions and add to root
3. Set compiler to **pdfLaTeX**
4. Compile `main.tex`

### Locally
```bash
cd overleaf/
# Download icml2025.sty first
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
