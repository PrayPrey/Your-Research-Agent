# Conclusion

We opened this paper with a question: do Semantic Entropy (SE\_N5) and minimum token log-probability (min\_logprob) measure the same thing about a language model's uncertainty, or genuinely different things? The answer, at least on TriviaQA short-answer QA with Llama-3.1-8B-Instruct, is unambiguous: **they measure genuinely different things**, with Pearson $|r| = 0.049$ — far below both the independence threshold (0.70) and the reparameterization threshold (0.85).

This near-zero correlation empirically confirms what algebraic analysis suggested \citep{kuhn2023semantic}: entropy over NLI-cluster semantic class masses (SE) and minimum token-prediction confidence along a greedy decoding path (min\_logprob) are independent aggregations of different aspects of model uncertainty. SE captures whether the model *agrees with itself* across stochastic samples at the semantic level; min\_logprob captures whether the model was *confident at every token step* in a single deterministic generation. These are different questions, and their answers are near-orthogonal.

Three contributions follow from this finding. First, the independence result provides a **mechanistic justification for ensemble combination**: combining SE and min\_logprob is not information compression but genuine signal integration. Second, the **cross-model LM-judge design** (Qwen-2.5-7B judging Llama-3.1-8B outputs) achieves Spearman $\rho(\text{SE}, \text{correctness}) = -0.081$, validating cross-model separation as a practical tool for suppressing NLI-based circularity in UQ benchmarking. Third, the **PoC at N=300** reveals the statistical power boundary for partial $R^2$ tests in this setting, calibrating experiment sizing for future conditional independence tests.

The partial $R^2 = 0.0101$ (below the 0.02 threshold) is the open thread: it is directionally confirmed but underpowered at $N=300$. The full-scale run at $N=2{,}500$ (h-e1-v2) will resolve this, enable ensemble AUROC evaluation ($\Delta$AUROC $\geq 0.025$ on a length-matched subset), and test cross-model transfer (Llama$\to$Qwen gap $< 0.05$ on TruthfulQA). The pipeline is production-ready and reusable without modification.

The simplest lesson from this work: before combining uncertainty signals in an ensemble, check whether they are actually independent. On TriviaQA with open-weight 7–8B models, SE and min\_logprob pass that check emphatically. The ensemble is justified.
