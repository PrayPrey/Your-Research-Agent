# Experimental Setup

We design our experiments to answer three concrete research questions that map directly to the contributions claimed in Section 1.

**RQ1: Are SE\_N5 and min\_logprob statistically independent uncertainty signals?** We measure Pearson |r|(SE\_N5, min\_logprob) and test against the pre-registered independence threshold of 0.70 and the reparameterization boundary of 0.85.

**RQ2: Does SE contribute predictive signal for correctness beyond min\_logprob?** We test the partial R² for SE in a conditional logistic regression controlling for min\_logprob, response length, and their interaction, against the threshold of 0.02.

**RQ3: Does the cross-model judge design produce low circularity?** We measure Spearman ρ(SE, judge\_correctness) against the circularity threshold of 0.40, validating the evaluation protocol.

## Dataset

**TriviaQA dev (rc.nocontext).** We use the closed-book (no-context) variant of TriviaQA dev, accessed via HuggingFace (`mandarjoshi/trivia_qa`, `rc.nocontext`, `validation` split). TriviaQA is a challenging factual QA benchmark requiring parametric knowledge recall — a setting where hallucination is frequent and meaningful, providing sufficient error diversity for UQ evaluation (34.8% correct answers in our sample at N=2500). The no-context variant was selected to isolate the model's parametric knowledge from retrieval artifacts, matching the experimental configuration of our prior baseline (h-m1, AUROC ~0.825 for min\_logprob on the same split; that figure is from prior pipeline runs and is not replicated in the present evaluation).

We evaluate on the first N=2500 prompts (seed=42). Answers are evaluated against the TriviaQA alias set (gold answers include all acceptable surface forms).

| Property | Value |
|----------|-------|
| Dataset | TriviaQA dev, rc.nocontext |
| N samples | 2500, seed=42 |
| Task type | Closed-book short-answer factual QA |
| Answer format | Free-form, ≤50 tokens |
| Correctness rate (LM-judge) | 34.8% (870/2500) |

## Models

**Generator — Llama-3.1-8B-Instruct.** We use Llama-3.1-8B-Instruct as the primary generator (bfloat16, device\_map="auto"). For SE\_N5, we sample N=5 responses per prompt (temperature=0.7, top\_p=0.95, max\_new\_tokens=50). For min\_logprob, we generate one greedy decode per prompt (temperature=0, max\_new\_tokens=50) with `output_scores=True` to access token log-probabilities.

**NLI Backbone — DeBERTa-MNLI.** SE clustering uses `cross-encoder/nli-deberta-v3-small` for bidirectional NLI entailment, following Kuhn et al. [2023]'s clustering protocol. Batch size 32.

**LM-Judge — Qwen-2.5-7B-Instruct.** Correctness labels are generated by Qwen-2.5-7B-Instruct (cross-model judge; Llama outputs evaluated by a different model family). A structured prompt presents the question, the model's greedy answer, and the gold answer, requesting a binary correctness judgment. Batch size 16. The cross-model design is specifically chosen to prevent circularity between the NLI-based SE signal and the judge.

## Baselines

**min\_logprob (standalone).** The minimum token log-probability from a single greedy decode pass. This is our primary baseline — the strongest single-signal log-prob UQ method established in prior work on this pipeline (AUROC ~0.825 on TriviaQA dev). We include it as the reference for the conditional LR comparison (RQ2) and as the "naive signal" against which independence is measured (RQ1).

**SE\_N5 (standalone).** Semantic Entropy computed from N=5 stochastic samples per the Kuhn et al. [2023] formulation. Included as the alternative standalone signal; also the focus of the independence test against min\_logprob.

**Note:** Ensemble AUROC (SE\_N5 + min\_logprob vs. min\_logprob alone) is not evaluated in this work. The experiment tests independence preconditions (RQ1, RQ2) rather than ensemble AUROC. Given the null result for RQ2 (partial R²=0.0005), ensemble AUROC improvement is not predicted; follow-up work (h-e1-v2) will test whether a nonlinear ensemble benefits from the orthogonal signal space despite the linear null result.

## Evaluation Metrics

**Pearson |r|(SE\_N5, min\_logprob).** Primary independence metric. Pre-registered threshold: |r| < 0.70 for independence confirmation; |r| > 0.85 for ABANDON (SE is a reparameterization of min\_logprob).

**Partial R²(SE) in conditional LR.** McFadden pseudo-R²(full) − McFadden pseudo-R²(reduced) for the SE + interaction terms. Tests whether SE adds independent predictive signal for correctness beyond min\_logprob and length. Pre-registered threshold: ≥ 0.02, LRT p < 0.05.

**Spearman ρ(SE, judge\_correctness).** Circularity diagnostic. Pre-registered threshold: |ρ| < 0.40 for acceptable circularity. Values above this threshold indicate that SE scores systematically predict judge labels through shared NLI-based reasoning rather than genuinely measuring a different uncertainty dimension.

**SE variance and fraction\_degenerate.** Mechanism reality checks validating that SE is a discriminative, non-degenerate signal at this operating point (SE\_var > 0.01; fraction\_degenerate = 0).

## Implementation Details

All code is implemented in Python with PyTorch and Hugging Face Transformers. Generation uses checkpoint-aware pipeline with intermediate results saved to `results/signals.pkl`, enabling restart without re-running the 8B generator. GPU memory is explicitly managed between generator and judge model loads (`del model; torch.cuda.empty_cache()`). Statistical analysis uses scipy (Pearson r, Spearman ρ), statsmodels (logistic regression, LRT, McFadden R²). All experiments run on a single GPU node with ≥48GB VRAM.

|---------------|-------|
| N stochastic samples | 5 |
| Temperature (stochastic) | 0.7 |
| Top-p | 0.95 |
| Max new tokens | 50 |
| NLI batch size | 32 |
| Judge batch size | 16 |
| Pearson r threshold | 0.70 |
| Partial R² threshold | 0.02 |
| Circularity threshold (ρ) | 0.40 |
| ABANDON threshold | 0.85 |
