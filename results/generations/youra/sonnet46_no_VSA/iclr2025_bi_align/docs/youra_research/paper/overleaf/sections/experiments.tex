\section{Experimental Setup}
\label{sec:experiments}

\subsection{Experimental Questions}

Our experimental design is structured around four sub-hypotheses, each addressing a distinct verification question in a sequential pipeline:

\textbf{EQ1 (H-E1):} Is the data infrastructure valid for cross-dataset correlation analysis? Does fuzzy joining yield $N \geq 30$ complete rows?

\textbf{EQ2 (H-M1):} Does MMLU function as a substantive scale covariate for both alignment benchmarks? We require $R^2(\text{MMLU} \times \text{TruthfulQA}) > 0.05$ and $R^2(\text{MMLU} \times \text{BBQ-proxy}) > 0.05$.

\textbf{EQ3 (H-M2):} Is the reduction from raw to partial Spearman $\rho$ statistically significant? (Primary hypothesis.)

\textbf{EQ4 (H-M3):} Can the residual $\rho_{\text{partial}}$ be assigned to a pre-specified structural scenario?

\subsection{Datasets}

\textbf{Open LLM Leaderboard v1.} ${\sim}500$ open-weight LLM records with MMLU, TruthfulQA MC2, and ARC Challenge accuracy. Publicly available via HuggingFace.

\textbf{Analysis Dataset.} $N{=}296$ models after inner join and dropna (TruthfulQA, BBQ-proxy, MMLU complete).

\subsection{Implementation}

All analyses implemented in Python 3.11. Core libraries: \texttt{scipy} $\geq$ 1.10, \texttt{pingouin} $\geq$ 0.5, \texttt{pandas} $\geq$ 1.5, \texttt{numpy} $\geq$ 1.23. Total: 57/57 test cases pass across all sub-hypotheses.
