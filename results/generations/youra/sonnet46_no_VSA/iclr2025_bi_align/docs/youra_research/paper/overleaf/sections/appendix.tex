\subsection*{A. Verification Pipeline Test Cases}

The four-step verification pipeline (H-E1, H-M1, H-M2, H-M3) totals 57/57 passing test cases. All gate criteria are pre-registered; results are reported verbatim in Section~\ref{sec:results}.

\subsection*{B. Fuzzy Join Sensitivity}

Threshold sweep (65, 70, 75, 80): $N{=}297$ complete rows at all thresholds. Match rate $= 1.000$ at threshold=75.

\subsection*{C. Bootstrap Parameters}

BCa bootstrap: $B{=}5000$ resamples, seed=42, clustered by model family (51 families; 30 with $\geq 3$ models). Bootstrap was applied to both raw and partial Spearman estimates simultaneously.
