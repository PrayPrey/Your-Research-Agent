\section{Experimental Setup}
\label{sec:experiments}

We design experiments to test whether heavy-tailed self-regularization theory extends to Vision Transformer architectures and whether cross-model measurements achieve bounded variance.

\subsection{Research Questions}

\textbf{RQ1:} Can heavy-tailed exponents $\alpha$ be reliably computed for ViT attention weight matrices using the Hill estimator?

\textbf{RQ2:} Is the variance of $\alpha$ bounded ($\sigma < 0.5$) across heterogeneous ViT models, enabling cross-model comparison?

\textbf{RQ3:} Does controlling for model family (training origin) reduce variance?
