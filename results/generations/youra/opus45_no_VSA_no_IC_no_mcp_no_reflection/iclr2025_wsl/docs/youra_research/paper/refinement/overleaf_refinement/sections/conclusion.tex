
This work conducted systematic measurement of heavy-tailed exponents on 53 Vision Transformer models from HuggingFace Model Hub. The primary hypothesis---that $\alpha$ variance would be bounded ($\sigma$ < 0.5)---was not supported at the global level ($\sigma$ = 2.868).

However, the results reveal a more nuanced picture:

\begin{enumerate}
\item \textbf{HT-SR extends to ViT.} Heavy-tailed exponents can be computed for attention weight matrices ($\alpha \in$ [2.20, 18.92]).
\end{enumerate}

\begin{enumerate}
\item \textbf{Family stratification reduces variance.} Within the google/vit-* family (n=6), variance dropped to $\sigma$ = 0.24, suggesting training provenance dominates cross-model variance.
\end{enumerate}

\begin{enumerate}
\item \textbf{Cross-architecture comparison requires controls.} Weight-based model selection for diverse hubs may need to incorporate training origin metadata.
\end{enumerate}

\subsubsection{Future Directions}

\begin{itemize}
\item Extend family analysis to additional model families (ResNet, ConvNeXt, Swin) with sufficient sample sizes
\item Investigate whether task-specific fine-tuning systematically shifts $\alpha$ distributions
\item Test whether within-family $\alpha$ correlates with downstream task performance
\end{itemize}
