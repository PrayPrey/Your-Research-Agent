# Overleaf LaTeX Project

Heavy-Tailed Self-Regularization in Vision Transformers: A Cross-Model Variance Analysis

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `references.bib` - Bibliography
- `sections/` - Paper sections (00-08)
- `figures/` - PNG figures

## Overleaf Upload

1. Create new project on Overleaf
2. Upload all files preserving folder structure
3. Set main document to `main.tex`
4. Compile
