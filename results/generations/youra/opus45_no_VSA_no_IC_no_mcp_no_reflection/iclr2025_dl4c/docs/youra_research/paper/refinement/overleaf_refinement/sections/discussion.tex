
\subsubsection{6.1 Key Findings}

\begin{enumerate}
\item \textbf{This configuration failed.} Approximately 94 gradient steps with REINFORCE on CodeLlama-7B-Instruct/MBPP produced no measurable learning as evaluated by pass@1.
\end{enumerate}

\begin{enumerate}
\item \textbf{Hypothesis remains untested.} A null result at insufficient scale is not falsification. The theoretical mechanism (higher bandwidth enables more precise gradient directions) remains intact.
\end{enumerate}

\begin{enumerate}
\item \textbf{Critical diagnostic gap.} Without training curves, loss plots, or intermediate checkpoints, the failure mode cannot be determined.
\end{enumerate}

\subsubsection{6.2 Theoretical Interpretation}

The 0.0\% pass@1 across all conditions indicates proof-of-concept scale training provides insufficient signal for policy gradient methods to learn code generation in this configuration. This is consistent with prior work---CodeRL and PPOCoder trained for multiple epochs and used different algorithmic approaches.

The theoretical mechanism remains valid:
\begin{itemize}
\item Binary rewards provide approximately 1 bit per feedback
\item Categorical error-type scoring provides ordered feedback (syntax < runtime < assertion < pass)
\item Higher bandwidth should enable more informative gradient directions
\end{itemize}

The failure is experimental (insufficient scale and/or unsuitable algorithm), not theoretical.

\subsubsection{6.3 Limitations}

\textbf{Decisive limitations:}
\begin{itemize}
\item 1 epoch: approximately 94 gradient updates, insufficient for PPO-style policy improvement
\item REINFORCE algorithm: higher variance than PPO, may require more samples
\item No training diagnostics: cannot verify whether policy updates occurred
\item No zero-shot baseline: cannot rule out catastrophic forgetting
\end{itemize}

\textbf{Acknowledged limitations:}
\begin{itemize}
\item 3 seeds: insufficient for robust variance estimation (design specified 5)
\item Heuristic weighting (0.5/0.3/0.2): not validated
\item Bit estimates: approximate, not rigorously calculated
\item Single model size (7B)
\item No hyperparameter search
\end{itemize}

\subsubsection{6.4 Requirements for Valid Test}

A conclusive test of the information bandwidth hypothesis would require:
\begin{itemize}
\item At least 3 epochs or training until validation plateau
\item PPO or lower-variance algorithm
\item Training curves showing policy improvement (or lack thereof)
\item Zero-shot baseline verified in same evaluation setup
\item At least 5 seeds per condition
\item Intermediate checkpoints for failure mode diagnosis
\end{itemize}
