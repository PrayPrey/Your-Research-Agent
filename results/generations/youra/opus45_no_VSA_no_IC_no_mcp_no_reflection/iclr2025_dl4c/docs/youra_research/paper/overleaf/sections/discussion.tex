\section{Discussion}
\label{sec:discussion}

\subsection{Key Findings}

\begin{enumerate}
    \item \textbf{This configuration failed.} $\sim$94 gradient steps with REINFORCE on CodeLlama-7B/MBPP produced no learning.
    \item \textbf{Hypothesis remains untested.} Null result $\neq$ falsification.
    \item \textbf{Critical diagnostic gap.} Without training curves, we cannot determine failure mode.
\end{enumerate}

\subsection{Limitations}

\textbf{Decisive:}
\begin{itemize}
    \item 1 epoch: insufficient gradient updates ($\sim$94 steps)
    \item REINFORCE algorithm: high variance, may require more samples than PPO
    \item No training diagnostics: cannot verify policy updates occurred
    \item No zero-shot baseline in our setup: cannot rule out catastrophic forgetting
\end{itemize}

\textbf{Acknowledged:}
\begin{itemize}
    \item 3 seeds: insufficient for variance estimation
    \item 0.5/0.5 weighting: heuristic, not tested
    \item Bit estimates: approximate, not rigorously calculated
    \item Single model size (7B)
    \item No hyperparameter search
\end{itemize}

\subsection{What Would Make This Conclusive}

A valid test would require:
\begin{itemize}
    \item $\geq$3 epochs or until validation plateau
    \item PPO or lower-variance algorithm
    \item Training curves showing policy improvement (or lack thereof)
    \item Zero-shot baseline verified in same evaluation setup
    \item $\geq$5 seeds per condition
\end{itemize}
