\subsubsection{5.2 Statistical Analysis}

With all values at zero and no variance, statistical comparison was mathematically undefined:

\begin{itemize}
\item t-statistic: NaN (undefined due to zero variance)
\item p-value: NaN
\item Cohen's d: NaN
\item Significant (p < 0.05): False
\end{itemize}

The gate evaluation failed: pass@1 for high\_bandwidth (0.0000) was not greater than binary (0.0000).

\subsubsection{5.3 Reward Signal Patterns}

Examination of raw reward trajectories from results.json shows:
\begin{itemize}
\item \textbf{Binary:} All 0.0 rewards across all 120 samples per seed
\item \textbf{Categorical:} Some non-zero rewards (0.25) appeared after approximately 20-40 steps, increasing frequency toward end of training
\item \textbf{High-bandwidth:} Some non-zero rewards (0.125) appeared with similar pattern to categorical
\end{itemize}

This suggests the model was generating some partially-correct code (runtime errors rather than syntax errors), but this did not translate to pass@1 improvement on the validation set.

\subsubsection{5.4 Interpretation}

The experiment cannot distinguish between:
\begin{enumerate}
\item Insufficient training scale (primary hypothesis)
\item Catastrophic forgetting (plausible given CodeLlama-7B-Instruct achieves approximately 30-40\% pass@1 zero-shot on MBPP)
\item Implementation error (not ruled out)
\item Algorithm unsuitability (REINFORCE vs PPO)
\end{enumerate}
