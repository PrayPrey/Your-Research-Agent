\section{Related Work}
\label{sec:related_work}

We review execution-based reward design for code LLMs and multi-granularity feedback approaches.

\subsection{Execution Feedback for Code LLMs}

CodeRL~\cite{le2022coderl} established the RLEF paradigm using binary execution rewards. PPOCoder~\cite{shojaee2023ppocoder} adapted Proximal Policy Optimization for code generation. Both works trained for multiple epochs and report final accuracy but not samples-to-threshold or learning curves.

\subsection{Multi-Granularity Feedback}

RLTF~\cite{liu2023rltf} introduced fine-grained feedback incorporating test pass rates and error type information, comparing it to binary rewards. Their results suggested that richer feedback improves performance. Our work builds on RLTF's multi-granularity concept but uses the ``information bandwidth'' framing and different infrastructure.

\subsection{Process Supervision}

Process reward models~\cite{lightman2023verify} demonstrated that step-by-step supervision outperforms outcome-only supervision for mathematical reasoning.
