We investigate whether reward information bandwidth---the amount of feedback conveyed per gradient update---affects reinforcement learning convergence for code generation. We compare three reward functions: binary pass/fail (1 bit), continuous test pass rate ($\sim$1.5 bits), and high-bandwidth combining pass rate with categorical error type ($\sim$2 bits). At proof-of-concept scale (1 epoch, 3 seeds per condition on CodeLlama-7B), all conditions produce 0\% pass@1, preventing meaningful comparison. This null result establishes a lower bound for our experimental setup: PoC-scale experiments with REINFORCE on this model/dataset combination are insufficient for reward ablation studies. We report this negative finding to provide scale guidance for future work and document the methodology for adequate-scale replication.
