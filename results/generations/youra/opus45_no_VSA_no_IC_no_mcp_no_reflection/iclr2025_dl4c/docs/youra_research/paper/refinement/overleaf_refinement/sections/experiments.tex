
\subsubsection{4.1 Research Questions}

\begin{itemize}
\item RQ1: Does the high-bandwidth condition reach pass@1 > 0.3 in fewer training samples than binary?
\item RQ2: Does the categorical condition outperform binary?
\item RQ3: Does error-type distribution differ across conditions?
\end{itemize}

\subsubsection{4.2 Conditions}

Three conditions were evaluated:

\begin{enumerate}
\item \textbf{Binary:} reward = 1.0 if all tests pass, else 0.0
\item \textbf{Categorical:} reward = score based on worst error type (passed=1.0, assertion=0.5, runtime=0.25, syntax=0.0)
\item \textbf{High-bandwidth:} reward = 0.5 $\times$ categorical + 0.3 $\times$ pass\_ratio + 0.2 $\times$ partial\_credit
\end{enumerate}

\subsubsection{4.3 Evaluation Metrics}

\begin{itemize}
\item \textbf{Primary:} pass@1 on MBPP validation subset (50 problems)
\item \textbf{Statistical:} Independent t-test, Cohen's d, significance at p < 0.05
\item \textbf{Threshold:} pass@1 > 0.3 for convergence analysis
\end{itemize}

\subsubsection{4.4 Missing Diagnostics}

The following diagnostics were not recorded:
\begin{itemize}
\item Training loss curves
\item KL divergence or entropy monitoring
\item Intermediate checkpoints
\item Zero-shot baseline verification in the evaluation setup
\end{itemize}
