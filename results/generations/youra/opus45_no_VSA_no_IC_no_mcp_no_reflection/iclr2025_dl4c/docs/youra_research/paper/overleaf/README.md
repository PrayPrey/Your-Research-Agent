# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Section files (00-08)
- `references.bib` - Bibliography
- `figures/` - Figures (if any)

## Upload to Overleaf

1. Zip this folder
2. Upload to Overleaf as new project
3. Set main document to `main.tex`
