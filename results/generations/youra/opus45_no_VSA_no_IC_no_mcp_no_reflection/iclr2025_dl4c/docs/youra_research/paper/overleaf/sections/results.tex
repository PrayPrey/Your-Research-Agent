No condition reached the 30\% threshold required for samples-to-threshold comparison.

\subsection{Statistical Analysis}

With all values at zero and no variance, statistical comparison was mathematically impossible:
\begin{itemize}
    \item t-statistic: undefined (division by zero variance)
    \item p-value: undefined
    \item Cohen's d: undefined
\end{itemize}

\subsection{Missing Evidence}

We cannot distinguish between:
\begin{enumerate}
    \item Insufficient training scale (hypothesis)
    \item Catastrophic forgetting (plausible given 0\% vs $\sim$30\% zero-shot)
    \item Implementation error (not ruled out)
    \item Algorithm unsuitability (REINFORCE vs PPO)
\end{enumerate}
