\section{Discussion}
\label{sec:discussion}

\subsection{Mechanism Interpretation}

We favor the hypothesis that explicit constraint training builds \textbf{general constraint-following capacity} that transfers to implicit safety constraints, analogous to Constitutional AI's finding that explicit safety rules improve implicit harmlessness.

\subsection{Limitations}

\begin{enumerate}
    \item \textbf{PoC scale only} (50--1000 PPO steps)
    \item \textbf{Single seed evaluation} (no variance estimates)
    \item \textbf{Marginal significance} on transfer correlation ($p=0.056$ with $N=4$)
    \item \textbf{8B parameter scale} only
    \item \textbf{Evaluation variance:} Different evaluation configurations (H-C1 vs H-M4) showed minor numerical variance ($\pm$0.5--1pp) while confirming consistent directional findings. Reported values use the primary H-M4 evaluation run.
\end{enumerate}

\subsection{Deployment Recommendations}

\begin{itemize}
    \item \textbf{Safety-critical:} T1/T2 for maximum controllability and safety transfer
    \item \textbf{General assistants:} T4 for near-baseline helpfulness with modest gains
    \item \textbf{Balanced:} T3 for intermediate performance
\end{itemize}
