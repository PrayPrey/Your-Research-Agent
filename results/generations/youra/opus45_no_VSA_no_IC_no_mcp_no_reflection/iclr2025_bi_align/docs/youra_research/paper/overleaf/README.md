# Bidirectional Alignment - Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Individual section files (00-07)
- `figures/` - Figures directory
- `references.bib` - BibTeX references

## Overleaf Upload

Upload entire folder to Overleaf. Set `main.tex` as main document.
