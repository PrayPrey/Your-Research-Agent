# Ranking Stability Under Distribution Shift - LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Paper sections (00-08)
- `figures/` - PNG figures
- `references.bib` - BibTeX references

## Requirements

- pdflatex
- bibtex
- ICML 2025 style files (icml2025.sty, icml2025.bst)
