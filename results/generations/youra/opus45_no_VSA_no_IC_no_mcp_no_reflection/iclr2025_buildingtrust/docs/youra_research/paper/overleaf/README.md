# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `references.bib` - Bibliography
- `sections/` - Section files (00-08)
- `figures/` - PNG figures

## Upload to Overleaf

1. Zip this folder
2. Upload to Overleaf as new project
3. Compile with pdfLaTeX
