\subsection{Implementation Details}

\textbf{Model:} Meta-Llama-3-8B-Instruct serves as the base language model.

\textbf{NLI Model:} DeBERTa-large-mnli for semantic clustering in the semantic entropy method.

\textbf{Similarity Model:} BERTScore with roberta-large backbone for self-consistency computation.

\textbf{Pilot Mode:} $N=20$ samples per dataset for pipeline validation, with a single random seed (42).
