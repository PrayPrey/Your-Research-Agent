## Final Hypothesis

### Title
Embedding-Based Domain Mixing Prediction (EDMP)

### Core Claim
Under standard LLM pretraining conditions with multi-domain corpora, if domain mixing is guided by embedding-based similarity + diversity scores computed from a mid-scale embedder (E5-large) against downstream task exemplars, then downstream task performance will improve by ≥3% on average compared to heuristic methods (perplexity-based, random selection), because embedding geometry captures task-relevant information content that correlates with transfer utility.

### Mechanism
1. **Embedding extraction**: Sample tokens from each domain, embed with mid-scale model (E5-large)
2. **Scoring**: Compute similarity to task exemplar embeddings + diversity contribution via coverage
3. **Ranking**: Rank domains by combined score, select top-K for training

## Novelty

**Key Innovation**: First training-free, principled method for domain mixing optimization via embedding geometry.

**Differentiation**:
- vs. DoReMi: No proxy training required; uses frozen embeddings only
- vs. DSIR: Multi-task ranking via benchmark exemplars, not single-task importance sampling
- vs. Perplexity-based: Task-grounded embeddings, not model-dependent perplexity scores

## Limitations

- Requires domain-labeled corpora (doesn't help with unlabeled web crawl)
- Task exemplars needed (limited for truly novel tasks)
- Embedding quality depends on embedder choice
- Predicts rankings, not absolute performance
- Validated at 1B-7B scale; larger scales not tested
