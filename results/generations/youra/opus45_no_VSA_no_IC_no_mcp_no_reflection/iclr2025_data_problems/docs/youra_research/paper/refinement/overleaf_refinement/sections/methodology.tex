
\subsubsection{3.1 Overview}

EDMP scores each pretraining domain by computing the average cosine similarity between domain sample embeddings and downstream task exemplar embeddings.

\textbf{Scoring Function:}

$$\text{EDMP}(d) = \frac{1}{|S_d|} \sum_{s \in S_d} \frac{1}{|T|} \sum_{t \in T} \cos(E(s), E(t))$$

where $S_d$ is the set of samples from domain $d, T$ is the set of task exemplars, and $E(\cdot)$ is the embedding function.

\subsubsection{3.2 Embedding Model Selection}

We select E5-large-v2 as the embedder. E5-large is a sentence transformer trained on a broad mixture of retrieval tasks, producing semantically meaningful embeddings across diverse text domains. The 1024-dimensional embedding space provides capacity for capturing semantic distinctions between domains.

\subsubsection{3.3 Task Exemplar Selection}

We use the MMLU validation set as task exemplars. MMLU spans 57 subjects across STEM, humanities, and social sciences. The validation set contains 1,531 questions, providing broad coverage while remaining computationally tractable.

\subsubsection{3.4 Scoring Pipeline}

\begin{enumerate}
\item \textbf{Domain Embedding:} Embed domain samples using E5-large with ''passage: '' prefix. Normalize to unit length.
\item \textbf{Task Embedding:} Embed task exemplars using E5-large with ''query: '' prefix. Normalize to unit length.
\item \textbf{Similarity Computation:} Compute cosine similarity matrix between domain and task embeddings.
\item \textbf{Aggregation:} For each domain, compute mean similarity across samples and exemplars.
\item \textbf{Ranking:} Rank domains by EDMP score in descending order.
\end{enumerate}

\textbf{Computational Cost:} Embedding 8 domains $\times$ 1,000 samples completes in under 30 minutes on a single A100 GPU.

\subsubsection{3.5 Validation Criteria}

\begin{enumerate}
\item \textbf{Score Computability:} All domains must produce valid similarity scores.
\item \textbf{Non-Trivial Variance:} Cross-domain score variance must exceed 0.05 to enable discrimination.
\item \textbf{Statistical Significance:} Domain scores must be statistically distinguishable (ANOVA p < 0.05).
\item \textbf{Reproducibility:} Scores must be consistent across random seeds (variance < 0.05).
\end{enumerate}
