
\subsubsection{4.1 Research Questions}

\textbf{RQ1:} Can EDMP scores be reliably computed for all domains in a multi-domain corpus?

\textbf{RQ2:} Do EDMP scores show sufficient cross-domain variance to discriminate between domains?

\textbf{RQ3:} Are EDMP scores reproducible across random seeds?

\subsubsection{4.2 Datasets}

We target 8 domains from The Pile: Pile-CC, Wikipedia, GitHub, ArXiv, StackExchange, PubMed, Books3, and OpenWebText2.

\textbf{Data Note:} Due to data access constraints (zstd library dependency), we used synthetic domain-distinguishable text for this experiment. Synthetic samples were generated with approximately 30\% domain-specific vocabulary and 70\% shared vocabulary to simulate domain structure.

We use the MMLU validation set (1,531 questions across 57 subjects) as task exemplars.

\subsubsection{4.3 Baselines}

\textbf{Random Embeddings:} Domain samples embedded with random unit vectors instead of E5-large, to verify that E5 embeddings carry semantic content.

\subsubsection{4.4 Implementation Details}

\begin{itemize}
\item \textbf{Embedding Model:} E5-large-v2 (intfloat/e5-large-v2), 1024 dimensions
\item \textbf{Hardware:} Single NVIDIA A100
\item \textbf{Compute Time:} Under 30 minutes for full pipeline
\item \textbf{Seeds Tested:} 42, 43, 44
\item \textbf{Samples per Domain:} 1,000
\end{itemize}
