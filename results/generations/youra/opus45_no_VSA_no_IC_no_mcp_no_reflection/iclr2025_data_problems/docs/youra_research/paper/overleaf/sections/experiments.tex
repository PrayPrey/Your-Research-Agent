\section{Experimental Setup}
\label{sec:experiments}

We design experiments to validate the EDMP scoring pipeline before testing its predictive power for downstream performance.

\subsection{Research Questions}

Our experiments address the following questions:

\textbf{RQ1:} Can EDMP scores be reliably computed for all domains in a multi-domain corpus?

\textbf{RQ2:} Do EDMP scores show sufficient cross-domain variance to discriminate between domains?

\textbf{RQ3:} Are EDMP scores reproducible across random seeds?

\subsection{Datasets}

We evaluate on a subset of The Pile \citep{gao2020pile}, selecting 8 representative domains: Pile-CC, Wikipedia, GitHub, ArXiv, StackExchange, PubMed, Books3, and OpenWebText2.

\textbf{Sampling:} 1,000 samples per domain (8,000 total), truncated to 512 tokens.

\textbf{Note:} Due to data access constraints, we use synthetic domain-distinguishable text for this validation experiment. Synthetic samples are generated with $\sim$30\% domain-specific vocabulary and $\sim$70\% shared vocabulary to simulate domain structure.

We use the MMLU validation set \citep{hendrycks2021measuring} as task exemplars (1,531 questions across 57 subjects).

\subsection{Baselines}

\textbf{Random Embeddings:} Domain samples embedded with random unit vectors instead of E5-large, to establish that E5 embeddings carry semantic content.

\subsection{Implementation Details}

\begin{itemize}
    \item \textbf{Embedding Model:} E5-large-v2 (intfloat/e5-large-v2), 1024 dimensions
    \item \textbf{Hardware:} Single NVIDIA A100
    \item \textbf{Compute time:} $<$30 minutes for full pipeline
    \item \textbf{Seeds tested:} [42, 43, 44]
\end{itemize}
