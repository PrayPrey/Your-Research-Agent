# Product Requirements Document: h-e1

**Date:** 2026-08-29
**Hypothesis:** Static analyzers (pylint) produce meaningful, actionable warnings on LLM-generated code for at least 30% of HumanEval problems.
**Type:** EXISTENCE (PoC)

---

## Executive Summary

Validate whether static analysis tools can detect meaningful issues in LLM-generated code. This existence proof determines if pylint produces actionable warnings on code generated by LLMs for the HumanEval benchmark, establishing foundation for subsequent verification-feedback hypotheses.

---

## Problem Statement

LLM-generated code may contain bugs, undefined variables, missing imports, and other issues that static analyzers can detect before execution. This experiment quantifies the rate at which pylint produces actionable warnings on LLM outputs.

---

## Functional Requirements

### FR-1: Data Pipeline
- Load HumanEval dataset (164 problems) via HuggingFace `openai_humaneval`
- Extract: task_id, prompt, canonical_solution, test, entry_point

### FR-2: Code Generation
- Generate solutions using CodeLlama-7B-Instruct or GPT-3.5-turbo API
- One solution per problem (pass@1 setup)
- Store generated code with problem metadata

### FR-3: Static Analysis
- Run pylint on each generated solution
- Configuration: `--output-format=json --disable=C,R` (errors and warnings only)
- Parse JSON output to extract actionable warnings (type E or W)
- Timeout: 30 seconds per analysis

### FR-4: Metrics Computation
- Primary: warning_rate = (problems with ≥1 actionable warning) / 164
- Secondary: avg_warnings_per_problem, warning_type_distribution, top_10_warning_codes

### FR-5: Gate Evaluation
- PASS: warning_rate ≥ 0.30 (30%)
- FAIL: warning_rate < 0.30

### FR-6: Visualization
- Gate metrics bar chart (target vs actual)
- Warning distribution histogram
- Warning type breakdown
- Top 10 warning codes

---

## Non-Functional Requirements

- NFR-1: Complete analysis in <30 minutes for full dataset
- NFR-2: Deterministic results (temperature=0 for LLM)
- NFR-3: All outputs saved to hypothesis folder

---

## Success Criteria

| Criterion | Target |
|-----------|--------|
| Warning Rate | ≥ 30% |
| Code Execution | No runtime errors in pipeline |
| Reproducibility | Same results on re-run |

---

## Dependencies

- Dataset: HumanEval (openai_humaneval on HuggingFace)
- Model: CodeLlama-7B-Instruct or GPT-3.5-turbo
- Tool: pylint (pip install pylint)

---

## Out of Scope

- Training or fine-tuning models
- Fixing detected issues (that's for dependent hypotheses)
- Comparing multiple LLMs (single model sufficient for existence proof)
