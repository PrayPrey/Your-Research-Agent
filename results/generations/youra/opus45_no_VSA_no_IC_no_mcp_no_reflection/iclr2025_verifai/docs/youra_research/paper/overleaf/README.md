# Overleaf LaTeX Project

## Compilation

```bash
cd overleaf
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `references.bib` - Bibliography
- `sections/` - Section files (00-08)
- `figures/` - Figure files (if any)

## Upload to Overleaf

1. Zip this folder
2. Upload to Overleaf as new project
3. Compile with pdflatex
