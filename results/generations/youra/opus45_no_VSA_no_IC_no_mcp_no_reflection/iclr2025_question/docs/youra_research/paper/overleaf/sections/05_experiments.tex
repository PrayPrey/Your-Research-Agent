\section{Experimental Setup}
\label{sec:experiments}

We design experiments to answer the following research questions:

\textbf{RQ1:} Do uncertainty quantification methods discriminate hallucinations better than random chance?

\textbf{RQ2:} Does semantic entropy achieve the expected AUROC $\geq$ 0.70 based on prior work?

\textbf{RQ3:} Does semantic entropy's clustering mechanism function correctly on MC-format tasks?

\subsection{Evaluation Protocol}

\textbf{Primary Metric:} AUROC for hallucination detection

\textbf{Success Thresholds:}
\begin{itemize}
    \item AUROC $> 0.55$ indicates better-than-random discrimination (h-e1)
    \item AUROC $\geq 0.70$ indicates strong discrimination (h-m1)
\end{itemize}
