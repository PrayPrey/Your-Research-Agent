## Findings

### Key Finding 1: UQ Methods Discriminate Hallucinations

Choice-level uncertainty (entropy over A/B/C/D logits) achieves strong discrimination (AUROC > 0.77). This validates h-e1: UQ signals correlate with correctness.

### Key Finding 2: Max Probability Outperforms Entropy

Simple confidence (1 - max_prob) slightly outperforms entropy-based uncertainty (0.81 vs 0.77). Simpler methods may suffice for hallucination detection.

### Key Finding 3: MC Format Enables Clean Evaluation

Multiple-choice format provides ground truth labels without manual annotation. Model achieves 56% accuracy, giving balanced label distribution for AUROC calculation.
