# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Section files (00-08)
- `figures/` - Figure files
- `references.bib` - Bibliography

## Output

- `main.pdf` - Compiled paper
