\section{Conclusion}

We asked: when RL agents learn to generate code, how much of each generated token actually matters? Our answer: \textbf{those that execute.}

By decomposing FGO into three testable components and verifying each with explicit falsification criteria, we establish that:

\begin{enumerate}
    \item Trace collection is reliable (100\% capture rate)
    \item Gradient exclusion is correct (zero gradient for masked tokens)
    \item The mechanism improves performance (+10\% pass@1, 1.78$\times$ signal concentration)
\end{enumerate}

This mechanism validation approach provides a template for rigorous evaluation of credit assignment methods in code RL.
