# Experiments

## Research Questions

Our experimental design addresses three core questions regarding benchmark dataset concentration in machine learning research:

1. **Measurability**: Can we reliably quantify benchmark concentration across major ML venues using standard concentration metrics?
2. **Predictive Power**: Does concentration at the venue level predict individual paper adoption of standard benchmarks?
3. **Temporal Dynamics**: Is there evidence for temporal lock-in, where concentration self-reinforces over time?

## Dataset

We constructed our dataset from Papers with Code (PWC), which provides structured metadata linking ML papers to their associated datasets. Our corpus comprises papers from three premier ML venues---NeurIPS, ICML, and ICLR---spanning 2018 to 2024, yielding 21 venue-year observations. For each paper, we extracted all associated dataset references, enabling both cross-sectional and longitudinal analysis of benchmark usage patterns.

The dataset encompasses 10,636 papers with valid dataset annotations. Citation relationships were obtained from Semantic Scholar, providing 77,963 citing-cited paper pairs where both papers appear in our corpus with dataset information.

## Experimental Design

### Concentration Measurement (H-E1)

We compute the Herfindahl-Hirschman Index (HHI) for each venue-year combination. Given a venue-year with $N$ papers using datasets from a pool of $D$ unique datasets, we calculate dataset shares $s_i = n_i / \sum_j n_j$ where $n_i$ is the count of papers using dataset $i$. The HHI is then:

$$\text{HHI} = \sum_{i=1}^{D} s_i^2$$

Values range from $1/D$ (perfect dispersion) to 1 (monopoly). We validate that HHI can be computed for all venue-years and examine the distribution of concentration values.

### Cross-Sectional Analysis (H-M1, H-M2)

To test whether concentration correlates with standard adoption, we partition venue-years into high-HHI and low-HHI groups by median split. For each group, we compute the mean top-5 dataset share---the fraction of dataset usage accounted for by the five most common datasets. We apply the Mann-Whitney U test for group differences and Spearman correlation for the continuous relationship.

For individual paper prediction (H-M2), we estimate a logistic regression:

$$\text{logit}(P(\text{uses standard})) = \beta_0 + \beta_1 \cdot \text{HHI}_{v,t-1}$$

where "uses standard" indicates whether a paper employs at least one of the top-5 datasets from the previous year in its venue. This design ensures temporal precedence---prior concentration predicts current adoption.

### Citation Network Analysis (H-M3)

We test whether citation relationships propagate benchmark choices. For each citing-cited pair in our corpus, we compute the Jaccard similarity of their dataset sets:

$$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$

We compare this to a null distribution generated by random pairing of papers within the same venue-year, controlling for baseline similarity. Effect size is quantified using Cohen's $d$.

### Entropy-Variance Correlation (H-M4)

Normalized entropy provides an alternative concentration measure:

$$H_{\text{norm}} = -\frac{1}{\log D} \sum_{i=1}^{D} s_i \log s_i$$

We examine the correlation between normalized entropy and variance in dataset counts across venue-years, testing whether methodological diversity (high entropy) associates with heterogeneous adoption patterns.

### Temporal Lock-in Analysis (H-M5)

The central test for lock-in employs panel regression with venue fixed effects:

$$\text{Entropy}_{v,t} = \alpha_v + \beta \cdot \text{HHI}_{v,t-1} + \epsilon_{v,t}$$

Under the lock-in hypothesis, $\beta < 0$: high concentration in period $t-1$ should reduce entropy (increase concentration) in period $t$. We supplement this with Granger causality tests for each venue, examining whether lagged HHI improves entropy prediction beyond autoregressive terms.

## Baselines and Comparisons

We compare our findings against two baselines:

1. **Null model (cross-sectional only)**: The hypothesis that concentration and adoption are unrelated across venue-years. Rejection of this null via significant correlations in H-M1 establishes the basic concentration-adoption relationship.

2. **Citation-independent adoption**: The hypothesis that papers adopt benchmarks independent of what they cite. The random-pair Jaccard distribution serves as this null for H-M3.

## Implementation

All statistical analyses were implemented using Python with statsmodels for regression, scipy for non-parametric tests, and linearmodels for panel data estimation. HHI and entropy calculations use standard formulations with appropriate handling of zero counts. Granger causality tests employ F-statistics with lag order selected by AIC.

Code and processed data will be released upon publication to enable reproducibility. The analysis pipeline processes raw PWC metadata through venue filtering, dataset aggregation, concentration metric computation, and statistical testing.
