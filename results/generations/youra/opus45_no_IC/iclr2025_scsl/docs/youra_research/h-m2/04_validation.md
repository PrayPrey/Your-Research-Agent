# Phase 4 Validation Report: H-M2

**Hypothesis:** Spurious features are easier to learn than core features
**Type:** MECHANISM
**Date:** 2026-08-12
**Gate Type:** SHOULD_WORK

---

## Executive Summary

H-M2 tests whether spurious features peak earlier than core features during training, which would indicate they are "easier" to learn. Using epoch-wise linear probe analysis on ResNet-18 representations, we tracked when each feature type reaches peak accuracy over 100 training epochs.

**GATE RESULT: FAILED** (SHOULD_WORK - proceed with limitation note)

Both feature types peaked at the same epoch (81), meaning spurious features did not demonstrably peak earlier. However, spurious accuracy was consistently ~10% higher throughout training.

## Gate Evaluation

### SHOULD_WORK Gate Criteria

| Criterion | Expected | Observed | Status |
|-----------|----------|----------|--------|
| spurious_peak < core_peak | True | False (81 = 81) | FAILED |
| Peak difference >= 10 epochs | >= 10 | 0 | FAILED |
| Wilcoxon p < 0.05 | True | True (3.88e-18) | PASSED |

### Gate Verdict: FAILED

The primary gate condition (spurious peak before core peak) was not satisfied. Both feature types reach their peak accuracy at the same epoch.

### Interpretation

While the gate technically failed, the results still support the broader "simplicity bias" narrative:

1. **Magnitude gap confirmed:** Spurious accuracy is consistently ~10% higher than core throughout training (confirming H-M1)
2. **Early epochs:** At epoch 1, spurious already at 89.7% vs core at 78.2%
3. **Convergence pattern:** Both curves plateau similarly, suggesting the pretrained ImageNet features already encode both patterns

The hypothesis as stated (temporal ordering) may need revision - the simplicity bias manifests as a magnitude gap rather than a timing difference when using pretrained features.
