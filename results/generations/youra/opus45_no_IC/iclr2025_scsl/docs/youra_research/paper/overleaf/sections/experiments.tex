\section{Experimental Setup}

\subsection{Dataset}

We use \textbf{Waterbirds} \citep{sagawa2019distributionally}: 4,795 training samples with 5\% minority rate (waterbirds on land, landbirds on water). The spurious correlation is 95\%: birds appear on ``expected'' backgrounds 95\% of the time.

\subsection{Baselines}

\begin{itemize}
    \item \textbf{Random Selection}: 5\% precision (chance)
    \item \textbf{ERM Misclassification}: JTT-style detection at convergence
\end{itemize}

\subsection{Evaluation Metrics}

\begin{itemize}
    \item \textbf{Precision/Recall}: Detection performance against ground-truth minority labels
    \item \textbf{Mann-Whitney U}: Statistical test for distribution difference
    \item \textbf{Probe accuracy gap}: Spurious accuracy $-$ core accuracy
\end{itemize}
