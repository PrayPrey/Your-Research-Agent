## Analysis

### Primary Finding: Simplicity Bias Confirmed

At epoch 5, the model's representations encode background information (spurious feature) with 91.20% probe accuracy, while bird type (core feature) achieves only 80.50%. This 10.7 percentage point gap demonstrates that simpler spurious features are learned before more complex core features.

### Secondary Finding: Core Features Learned Later

Core probe accuracy improves from 80.50% (epoch 5) to 82.62% (epoch 50), a 2.12 percentage point increase. This confirms that core feature learning continues throughout training while spurious feature encoding remains relatively stable (~91%).

### Implication for H-E1

This mechanism explains the onset delay difference observed in H-E1:
- **Majority samples** (aligned spurious + core features) achieve early convergence via spurious features
- **Minority samples** (conflicting features) require additional training time for core feature learning, resulting in higher onset delay
