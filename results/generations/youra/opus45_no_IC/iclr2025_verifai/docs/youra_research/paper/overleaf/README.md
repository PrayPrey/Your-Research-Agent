# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Paper sections (00-07)
- `references.bib` - Bibliography
- `figures/` - Figures (if any)

## Upload to Overleaf

1. Zip entire folder
2. New Project > Upload Project
3. Compile
