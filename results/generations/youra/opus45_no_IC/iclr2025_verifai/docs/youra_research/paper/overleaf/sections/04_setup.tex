\section{Experimental Setup}
\label{sec:setup}

We design experiments to answer three questions that directly test our hypothesis:

\textbf{RQ1:} Are error classes targeted by grammar constraints, static analysis, and SMT verification largely independent (Jaccard $< 0.30$)?

\textbf{RQ2:} Does grammar-constrained decoding measurably reduce syntax errors?

\textbf{RQ3:} Does static analysis feedback reduce semantic issues when applied iteratively?

\subsection{Datasets}

\textbf{HumanEval}~\cite{chen2021evaluating}: 164 Python programming problems with function signatures and docstrings. Each problem includes test cases for functional correctness evaluation. We use HumanEval because it is the standard benchmark for code generation and enables comparison with prior work.

\textbf{HumanEval-Verus}~\cite{humaneval_verus2024}: 23 problems from HumanEval translated to include formal Verus specifications. This subset enables SMT verification stage evaluation---problems without specifications cannot be verified by SMT solvers.

\subsection{Models}

We evaluate across two models spanning the capability spectrum:

\textbf{CodeLlama-7b-hf} (Meta): 7B parameter open-source model trained on code. Represents accessible, locally-runnable code generation.

\textbf{GPT-4} (OpenAI): Frontier model accessed via API. Represents state-of-the-art capability.

For the grammar constraint experiments (H-M1), we use \textbf{StarCoder2-7b}~\cite{starcoder2_2024} (BigCode) to demonstrate the mechanism. For the static analysis feedback experiments (H-M2), we test \textbf{StarCoder2-3b} (BigCode) to investigate whether model instruction-tuning affects feedback loop effectiveness.

\subsection{Verification Strategy Implementations}

\textbf{Grammar Constraints:} SynCode~\cite{syncode2024} with \texttt{grammar\_strict} mode and Python grammar. Token-level logit masking via DFA ensures syntactic validity during generation.

\textbf{Static Analysis:} Bandit~\cite{bandit2024} v1.7+ for security issues (SQL injection, command injection, hardcoded secrets) and Pylint for reliability issues (undefined variables, type errors).

\textbf{SMT Verification:} Z3 solver~\cite{z3solver} with Verus specification checking. Applied only to HumanEval-Verus subset.

\subsection{Baselines}

For each hypothesis, we compare against appropriate baselines:

\textbf{H-E1 (Independence):} No baseline---we measure absolute Jaccard values.

\textbf{H-M1 (Grammar):} Unconstrained generation with same model, temperature, and sampling.

\textbf{H-M2 (Static):}
\begin{itemize}
    \item Baseline: Code without feedback iterations
    \item Treatment: Code after up to 5 feedback iterations
\end{itemize}

\subsection{Evaluation Metrics}

\textbf{Pass@k:} Proportion of problems solved within $k$ attempts ($k=1$ for our PoC validation).

\textbf{Jaccard Index:} $J(s_1, s_2) = |I_{s_1} \cap I_{s_2}| / |I_{s_1} \cup I_{s_2}|$ for measuring error class overlap.

\textbf{Syntax Error Rate:} Proportion of generated samples that fail to compile.

\textbf{Security Issues:} Count of Bandit findings (high/medium severity).

\textbf{Reliability Issues:} Count of Pylint errors (E-codes).

\subsection{Implementation Details}

\textbf{Generation Parameters:}
\begin{itemize}
    \item Temperature: 0.2 (deterministic) for H-E1, 1.2 (elevated) for H-M1 to induce baseline errors
    \item Max tokens: 64--256 depending on problem
    \item Samples per problem: 10 for pass@k calculation
\end{itemize}

\textbf{Feedback Loop (H-M2):}
\begin{itemize}
    \item Maximum iterations: 5
    \item Prompt format: Original prompt + generated code + static analysis issues
    \item Early termination: No remaining issues
\end{itemize}

\textbf{Compute Resources:}
\begin{itemize}
    \item H-M1/H-M2: Single NVIDIA GPU with 8-bit quantization
    \item H-E1: Simulated data for PoC (full execution deferred to Phase 5)
\end{itemize}

\textbf{PoC Scope:} Due to resource constraints, H-M1 validates on 5 prompts (not full HumanEval) and H-M2 on 8 prompts. This demonstrates mechanism effectiveness; full-scale validation is future work.
