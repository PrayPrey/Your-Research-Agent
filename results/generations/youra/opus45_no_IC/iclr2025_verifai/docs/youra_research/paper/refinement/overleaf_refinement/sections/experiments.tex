
\subsubsection{4.1 Datasets}

\textbf{HumanEval} \citep{chen2021evaluating}: 164 Python programming problems with function signatures and docstrings. Each problem includes test cases for functional correctness evaluation.

\textbf{HumanEval-Verus} (secure-foundations): 23 problems from HumanEval translated to include formal Verus specifications. This subset enables SMT verification stage evaluation.

\subsubsection{4.2 Models}

For error class independence measurement (H-E1):
\begin{itemize}
\item \textbf{CodeLlama-7b-hf} (Meta): 7B parameter open-source model
\item \textbf{GPT-4} (OpenAI): Frontier model accessed via API
\end{itemize}

For grammar constraint experiments (H-M1):
\begin{itemize}
\item \textbf{StarCoder2-7b} (BigCode)
\end{itemize}

For static analysis feedback experiments (H-M2):
\begin{itemize}
\item \textbf{StarCoder2-3b} (BigCode): A completion model, not instruction-tuned
\end{itemize}

\subsubsection{4.3 Verification Strategy Implementations}

\textbf{Grammar Constraints:} SynCode (structuredllm/syncode) with \texttt{grammar\textbackslash \_strict} mode and Python grammar.

\textbf{Static Analysis:} Bandit v1.7+ for security issues (SQL injection, command injection, hardcoded secrets) and Pylint for reliability issues (undefined variables, type errors).

\textbf{SMT Verification:} Z3 solver with Verus specification checking (applied only to HumanEval-Verus subset).

\subsubsection{4.4 Evaluation Metrics}

\begin{itemize}
\item \textbf{Jaccard Index:} $J(s_1, s_2) = |I_{s_1} \cap I_{s_2}| / |I_{s_1} \cup I_{s_2}|$ for measuring error class overlap
\item \textbf{Syntax Error Rate:} Proportion of generated samples that fail to compile
\item \textbf{Security Issues:} Count of Bandit findings (high/medium severity)
\item \textbf{Reliability Issues:} Count of Pylint errors (E-codes)
\end{itemize}

\subsubsection{4.5 Implementation Details}

\textbf{Generation Parameters:}
\begin{itemize}
\item Temperature: 0.2 for H-E1; 1.2 for H-M1 (elevated to induce baseline errors)
\item Samples per problem: 10 for H-E1
\item Seed: 42 for H-E1; 1 for H-M2
\end{itemize}

\textbf{Feedback Loop (H-M2):}
\begin{itemize}
\item Maximum iterations: 5
\item Prompt format: Original prompt + generated code + static analysis issues
\item Early termination: No remaining issues
\end{itemize}

\textbf{Scope:} H-M1 was validated on 5 prompts, H-M2 on 8 prompts. This is proof-of-concept level validation; full-scale validation is future work.
