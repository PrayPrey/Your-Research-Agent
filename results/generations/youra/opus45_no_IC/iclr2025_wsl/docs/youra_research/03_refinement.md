## Final Hypothesis

### Title
Sample Efficiency of Permutation Equivariance in Weight Space Learning

### Core Claim
Under single-architecture CNN model zoos (50K+ models), if permutation-equivariant architecture (NFN) versus matched-capacity non-equivariant baselines, then NFN shows significant R² advantage for accuracy prediction at small data scales (N<5K) that diminishes to non-significance at large scales (N>25K), because equivariance provides implicit symmetry exploitation that MLPs can learn from data diversity at scale.

### Mechanism
1. NFN encodes permutation group structure → predictions invariant to weight ordering
2. MLP has no built-in awareness → must learn from data
3. At small N: insufficient variation for MLP to learn invariance
4. At large N: natural variation provides equivalent symmetry information
5. Result: MLP converges to similar performance AND learns similar representations (probe invariance test)

## Experimental Design

**Dataset**: Model Zoo CIFAR-10 CNN subset (single architecture, 10K-50K models)

**Models**:
- NFN: Permutation-equivariant (correct symmetry)
- MLP-Matched: Same capacity, no equivariance
- NFN-Scrambled: NFN architecture, wrong permutation group

**Baselines**: Simple statistics (mean/std/norm), Random features

**Protocol**: AdamW, 50 epochs, 10 seeds, fixed test set (20%)
