## Mechanism Verification

### Observations

1. **Equivariance Benefit Confirmed:** NFN's built-in permutation equivariance provides strong inductive bias for weight-space learning
2. **Sample Efficiency:** At N=1K, NFN achieves R²=0.95 while MLP achieves only R²=0.35
3. **Generalization:** NFN shows no overfitting gap; MLP severely overfits despite more parameters

### Interpretation

The substantial R² gap (0.60) demonstrates that:
- Permutation symmetry in neural network weights is a strong structural prior
- NFN can exploit this symmetry effectively with limited data
- MLP must learn invariance from data, which requires more samples
