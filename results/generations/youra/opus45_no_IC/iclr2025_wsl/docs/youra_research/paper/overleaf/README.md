# Overleaf LaTeX Project

## Compilation

```bash
cd overleaf
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Files

- `main.tex` - Main document
- `references.bib` - Bibliography
- `sections/` - Section files (00-07)
- `figures/` - PNG figures

## Upload to Overleaf

1. Zip this folder
2. New Project → Upload Project
3. Compile with pdflatex
