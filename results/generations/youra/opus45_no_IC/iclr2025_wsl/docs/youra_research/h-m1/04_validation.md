## Mechanism Verification

### Observations

1. **Perfect Invariance:** All 11 predictions differ only at floating-point precision (~1e-7)
2. **Mathematical Property Confirmed:** NFN's HNPPool layer correctly produces permutation-invariant representations
3. **Architecture Validation:** The NPLinear → HNPPool architecture successfully maintains equivariance through the network

### Technical Details

- Hidden layer neuron permutations were applied to layers 0 and 1
- Each permutation affected:
  - Output rows of layer i
  - Input columns of layer i+1
  - Bias terms of layer i
- Final layer (layer 2) received only input column permutation from layer 1
- All permuted MLPs are functionally equivalent (same computation, different neuron ordering)
