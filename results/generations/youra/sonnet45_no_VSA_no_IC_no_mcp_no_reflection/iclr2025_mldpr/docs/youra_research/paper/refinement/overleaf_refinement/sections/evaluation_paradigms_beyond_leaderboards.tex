
Recent work explores alternatives to static benchmark evaluation: few-shot prompting \citep{Brown2020FewShot}, human-AI collaboration metrics \citep{Bansal2021}, and dynamic evaluation \citep{Nie2020}. While these paradigms avoid saturation by design (no fixed leaderboard), adoption requires replacing existing benchmark infrastructure entirely. The approach presented here enables incremental adoption---saturation detection integrates with existing leaderboard systems (Papers With Code) without disrupting current workflows.
