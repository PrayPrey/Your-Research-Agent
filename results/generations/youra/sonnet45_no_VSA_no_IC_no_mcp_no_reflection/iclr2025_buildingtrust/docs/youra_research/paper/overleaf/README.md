## Compilation

### Local (pdfLaTeX + BibTeX)

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Output: `main.pdf`

### Overleaf

1. Upload entire `overleaf/` folder
2. Optional: Download `icml2025.sty` from https://icml.cc/Conferences/2025/StyleAuthorInstructions
   - Uncomment `\usepackage{icml2025}` and ICML-specific commands in `main.tex`
3. Set compiler to pdfLaTeX
4. Compile (Overleaf handles multi-pass automatically)
