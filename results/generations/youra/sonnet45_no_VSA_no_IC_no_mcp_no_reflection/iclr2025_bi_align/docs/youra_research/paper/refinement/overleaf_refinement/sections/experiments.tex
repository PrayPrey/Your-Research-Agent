
\subsubsection{4.1 H-E1 Implementation}

Implemented preference entropy analyzer as Python script using:
\begin{itemize}
\item Dataset loading: Hugging Face \texttt{datasets} (v2.14.0)
\item Entropy computation: \texttt{scipy.stats.entropy} (v1.11.0) with natural log
\item Numerical operations: NumPy (v1.24.0)
\item Visualization: matplotlib (v3.7.0)
\end{itemize}

\textbf{Code Architecture:}
\begin{itemize}
\item \texttt{PreferenceEntropyAnalyzer} class (248 lines)
\item \texttt{sample\textbackslash \_prompts(seed=1)}: deterministic prompt sampling
\item \texttt{compute\textbackslash \_entropy\textbackslash \_for\textbackslash \_prompt(examples)}: Shannon entropy H = -$\Sigma$ p\_i log(p\_i)
\item \texttt{analyze\textbackslash \_dataset()}: orchestrates sampling $\rightarrow$ computation $\rightarrow$ metrics
\item \texttt{generate\textbackslash \_visualizations()}: produces 4 figures
\end{itemize}

\textbf{Reproducibility:} Fixed random seed (seed=1) ensures deterministic results.

\subsubsection{4.2 Dataset Download and Preprocessing}

\textbf{Anthropic-HH Dataset:}
\begin{itemize}
\item Downloaded via Hugging Face Hub
\item Training split: 160,800 examples
\item Validation performed on training split only
\end{itemize}

\textbf{Prompt Grouping Methodology:}
\begin{itemize}
\item Challenge: Anthropic-HH lacks explicit prompt IDs
\item Solution: Use first 200 characters of \texttt{chosen} response text as grouping key
\item Filtering: Require $\geq 5$ examples per prompt group
\item Sampling: Randomly sample 100 prompt groups (seed=1)
\end{itemize}

\textbf{Group Size Distribution:}
\begin{itemize}
\item Min: 5 comparisons (threshold)
\item Max: 57 comparisons
\item Median: 6 comparisons
\item Mean: 9.6 comparisons
\end{itemize}

\subsubsection{4.3 Entropy Computation}

\textbf{Algorithm:}
For each prompt group with n examples:
\begin{enumerate}
\item Aggregate preference counts: [chosen\_count, rejected\_count]
\item Normalize to probabilities: p = counts / sum(counts)
\item Apply Shannon formula: H = -sum(p * log(p))
\item Validate result: check H $\in$ [0, ln(2)] nats
\end{enumerate}

\textbf{Edge Case Handling:}
\begin{itemize}
\item scipy.stats.entropy filters out p=0 before log (no log(0) errors)
\item Single-option distributions: p=[1,0] $\rightarrow$ H=0
\item Uniform distributions: p=[0.5,0.5] $\rightarrow$ H=ln(2)
\end{itemize}

\textbf{Validation Metrics:}
\begin{itemize}
\item Success rate: (valid entropy prompts) / (total sampled) $\times$ 100
\item Mean entropy: mean(H\_values)
\item Std entropy: std(H\_values)---variance check (gate criterion: >0)
\item Range check: all(0 $\leq$ H $\leq$ ln(2))
\end{itemize}
