\section{Experimental Setup}
\label{sec:experiments}

We design experiments to answer two research questions:

\textbf{RQ1 (Feasibility):} Can CV\_PR be reliably extracted from 100+ pretrained models?

\textbf{RQ2 (Correlation):} Does CV\_PR correlate negatively with ImageNet accuracy?

These map directly to our claims: RQ1 validates the methodology; RQ2 tests the core hypothesis.

\subsection{Dataset}

We evaluate on models from the timm library (PyTorch Image Models), which provides a unified interface to 1,000+ pretrained architectures with documented ImageNet-1K validation accuracy.

\textbf{Model selection criteria:}
\begin{itemize}
    \item Pretrained on ImageNet-1K
    \item Top-1 accuracy available in timm metadata
    \item Architecture families: ResNet, ViT, EfficientNet, ConvNeXt, DenseNet, RegNet, MobileNet
\end{itemize}

\textbf{Rationale}: timm provides sufficient diversity in architecture type and accuracy range to test whether CV\_PR generalizes across model families. The 100-model target ensures adequate statistical power for correlation testing.

\subsection{Baselines}

For the correlation test (RQ2), we compare against random baseline (null hypothesis: no correlation). For the metric itself, we position against:

\textbf{Condition Number}: $\kappa = \sigma_\text{max} / \sigma_\text{min}$ captures spectral extremes but not shape. If CV\_PR reduces to condition number, our metric adds nothing.

\textbf{Direct Spectral Features}: Unterthiner et al.~\cite{unterthiner2020predicting} used direct weight statistics. We test whether \emph{variance} of spectral estimates adds signal beyond the estimates themselves.

\subsection{Implementation Details}

\textbf{Framework}: PyTorch 2.0+, timm library for model loading

\textbf{Extraction Pipeline}:
\begin{enumerate}
    \item Load pretrained model via \texttt{timm.create\_model(name, pretrained=True)}
    \item Iterate all Conv2d and Linear layers ($\geq$100 elements)
    \item For each weight matrix, compute CV\_PR with 20 seeds
    \item Aggregate via mean across layers
\end{enumerate}

\textbf{Reproducibility}: Random seeds are fixed (0--19) and torch manual seed is set before each projection. Code available in supplementary materials.

\subsection{Evaluation Metrics}

\textbf{RQ1 (Feasibility):}
\begin{itemize}
    \item Completion rate: fraction of models successfully processed
    \item Success criterion: $\geq$95\% completion
    \item CV\_PR finite range: all values in (0, 10)
\end{itemize}

\textbf{RQ2 (Correlation):}
\begin{itemize}
    \item Pearson correlation coefficient ($r$)
    \item Spearman rank correlation ($\rho$)---robust to outliers
    \item 95\% confidence interval via bootstrap
    \item $p$-value for significance
\end{itemize}

\textbf{Success criterion (original hypothesis)}: $r < -0.3$, $p < 0.05$

\textbf{Falsification criterion}: $r \geq 0$ or $p \geq 0.05$
