\section{Discussion}

\subsection{Validated Claims}
NTI+CMI improve detection by $+7.1\%$ AUROC over entropy baseline ($p < 0.001$). Trajectory instability correlates with hallucination on high-entropy samples.

\subsection{Refuted Claims}
\begin{itemize}
    \item \textbf{h-m2}: Signal collapses on confident predictions (NTI coupled to entropy by construction)
    \item \textbf{h-m3}: RCI flip is architectural, not epistemic ($>90\%$ prevalence in both classes)
\end{itemize}

\subsection{Limitations}
\begin{enumerate}
    \item Entropy coupling: cannot detect confident hallucinations
    \item Single model (LLaMA-2-7B): generalization requires replication
    \item Multiple-choice format: free-generation may differ
    \item Correlation only: no causal intervention
\end{enumerate}

\subsection{Future Work}
\begin{itemize}
    \item Entropy-orthogonal features (hidden state geometry)
    \item Multi-model validation (Mistral, LLaMA-3)
    \item Semantic RCI (distance between competing tokens)
    \item Causal intervention (activation patching)
\end{itemize}
