## Executive Summary

The NTI (Normalized Trajectory Instability) metric successfully demonstrates discriminative signal for hallucination detection on TruthfulQA MC1. Mean AUROC of **0.5657** exceeds the 0.55 threshold, validating the existence hypothesis that trajectory instability provides useful signal.

## Experiment Configuration

| Parameter | Value |
|-----------|-------|
| Model | LLaMA-2-7B (meta-llama/Llama-2-7b-hf) |

| Evaluation | 5-fold stratified CV with Logistic Regression |
| Target Layers | 24-31 (8 layers) |
| Metric | NTI = std(entropy) / mean(entropy) across layers |
| Random Seed | 42 |
