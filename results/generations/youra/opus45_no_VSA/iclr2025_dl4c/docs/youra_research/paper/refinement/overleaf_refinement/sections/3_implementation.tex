
\textbf{Base Model:} CodeT5+-220M \citep{wang2023codet5plus} with LoRA \citep{hu2022lora} fine-tuning.

\textbf{Training:} Learning rate 2e-5, weight decay 0.05, warmup steps 200, batch size 8. CE epochs: 10, RL epochs: 5.

\textbf{Refinement:} Self-Refine \citep{madaan2023selfrefine} with K=3 iterations, temperature 0.0 (greedy), max tokens 512.

\textbf{MINE Estimator:} Hidden dimension 512, learning rate 0.001, 5000 iterations, 10,000 permutations.

\textbf{Diversity Controller:} High entropy target 2.5 bits, low entropy target 1.5 bits.
