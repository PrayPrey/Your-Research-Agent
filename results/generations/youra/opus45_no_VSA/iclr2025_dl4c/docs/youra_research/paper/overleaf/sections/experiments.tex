\section{Experimental Setup}
\label{sec:experiments}

We design experiments to answer the following research questions:

\textbf{RQ1 (Superadditivity):} Is the Training$\times$Refinement interaction positive?

\textbf{RQ2 (Mechanism):} Does RL training increase structural coupling $I(F;E)$?

\textbf{RQ3 (Diversity):} Is high feedback diversity necessary for superadditivity?

\subsection{Datasets}

\textbf{HumanEval+} \citep{liu2024evalplus}: 164 Python programming problems with 80$\times$ more test cases than original HumanEval.

\textbf{MBPP+} \citep{liu2024evalplus}: 378 Python programming problems with 35$\times$ more test cases than original MBPP.

\subsection{Implementation}

\textbf{Base Model:} CodeT5+-220M \citep{wang2023codet5plus} with LoRA \citep{hu2022lora} fine-tuning.

\textbf{Training:} Learning rate $2 \times 10^{-5}$, CE epochs 10, RL epochs 5.

\textbf{Refinement:} Self-Refine \citep{madaan2023selfrefine} with $K=3$ iterations.
