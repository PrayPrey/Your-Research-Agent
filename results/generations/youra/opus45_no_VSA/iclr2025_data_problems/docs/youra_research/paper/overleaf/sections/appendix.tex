\section{Implementation Details}
\label{app:implementation}

Full implementation details for reproducibility are provided in this appendix.

\subsection{Contamination Detection Parameters}

\begin{itemize}
    \item N-gram size: 8 (following ConTAM recommendations)
    \item Tokenization: GPT-2 tokenizer (consistent with Pythia)
    \item Matching: Exact token sequence match
\end{itemize}

\subsection{TRAK Attribution Configuration}

\begin{itemize}
    \item Projection dimension $k$: 1024
    \item Number of projections: 32
    \item Checkpoint frequency: Every 1000 steps
    \item Gradient accumulation: 4 steps
\end{itemize}

\subsection{Synthetic Injection Protocol}

For CCR validation experiments, MMLU questions were injected at the following rates:
\begin{itemize}
    \item 0.1\%: 100 questions per 100K training documents
    \item 0.5\%: 500 questions per 100K training documents
    \item 1.0\%: 1,000 questions per 100K training documents
    \item 5.0\%: 5,000 questions per 100K training documents
    \item 10.0\%: 10,000 questions per 100K training documents
\end{itemize}

Injection was performed with uniform random placement within documents to avoid position-based artifacts.
