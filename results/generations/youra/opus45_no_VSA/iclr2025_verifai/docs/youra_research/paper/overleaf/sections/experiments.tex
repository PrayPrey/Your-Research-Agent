\section{Experimental Setup}
\label{sec:experiments}

We design experiments to answer the following questions:

\textbf{RQ1:} Does feedback presentation order affect LLM code repair quality under matched content?

\textbf{RQ2:} If an ordering effect exists, what is its mechanism---early-gain amplification or regression prevention?

\subsection{Datasets}

\textbf{HumanEval} \citep{chen2021evaluating}: 164 hand-crafted Python programming problems with comprehensive test suites.

\textbf{MBPP} \citep{austin2021program}: 500 crowd-sourced Python programming problems covering a broader difficulty range.

\subsection{Implementation Details}

\textbf{Model:} GPT-4o-mini (temperature 0.0)

\textbf{Token Budget:} 500 + 500 (balanced, fits context)

\textbf{Iterations:} 3 (standard in literature)

\textbf{Static Analysis:} Pylint 3.0+, Mypy 1.0+

\textbf{Execution:} Sandboxed Python 3.10 subprocess, 10-second timeout
