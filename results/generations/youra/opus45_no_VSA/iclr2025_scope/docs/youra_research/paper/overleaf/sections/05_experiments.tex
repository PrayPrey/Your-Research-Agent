\section{Experimental Setup}
\label{sec:experiments}

We design experiments to test three core claims: (1) instruction embeddings are linearly separable by task family, (2) a linear probe can select the optimal adapter, and (3) zero-shot IPCR routing achieves near-oracle performance. We additionally test routing robustness to input perturbations.

\subsection{Research Questions}

\begin{itemize}
    \item \textbf{RQ1 (H-E0):} Are instruction prefix embeddings linearly separable by FLAN task family?
    \item \textbf{RQ2 (H-E1):} Can a linear probe predict the oracle adapter selection with high accuracy?
    \item \textbf{RQ3 (H-M1):} Does zero-shot IPCR routing achieve $\geq$90\% of oracle adapter performance?
    \item \textbf{RQ4 (H-M2):} Is routing robust to paraphrase and keyword perturbations?
\end{itemize}

\subsection{Dataset}

\textbf{Task families tested:} cot\_gsm8k (math), cot\_strategyqa (reasoning), cot\_creak (verification), cot\_qasc (science), cot\_ecqa (commonsense), cot\_sensemaking (logic), cot\_esnli (NLI), cot\_aqua\_rat (algebra), stream\_qed, and others.

\textbf{Why FLAN?} FLAN provides structured instruction prefixes across 62 task categories with consistent formatting, enabling systematic evaluation of prefix-based routing. Prior routing work (LoRAHub) evaluated on Big-Bench Hard; no existing work specifically targets FLAN's instruction taxonomy.

\subsection{Implementation Details}

\textbf{Encoder:} sentence-transformers/all-MiniLM-L6-v2 (frozen, 22M parameters)

\textbf{Classifier:} Scikit-learn LogisticRegression
\begin{itemize}
    \item Solver: L-BFGS
    \item Max iterations: 2000
    \item Class weights: balanced
\end{itemize}

\textbf{Adapter configuration:}
\begin{itemize}
    \item Base model: Mistral-7B-Instruct-v0.1
    \item LoRA rank: 16
    \item LoRA alpha: 32
    \item Target modules: q\_proj, v\_proj
\end{itemize}

\textbf{Compute:} Single NVIDIA A100 (40GB). Training time: $\sim$2 hours for 8 adapters.

\subsection{Evaluation Metrics}

\textbf{For separability (RQ1):}
\begin{itemize}
    \item Macro-F1 score (threshold: $\geq$0.75)
    \item Per-family F1 scores
    \item Baseline: stratified random classifier
\end{itemize}

\textbf{For adapter selection (RQ2):}
\begin{itemize}
    \item Top-1 accuracy (threshold: $\geq$70\%)
    \item Top-3 accuracy (threshold: $\geq$85\%)
    \item Improvement over random
\end{itemize}

\textbf{For end-to-end performance (RQ3):}
\begin{itemize}
    \item Relative performance: IPCR accuracy / Oracle accuracy
    \item Threshold: $\geq$90\% of oracle
    \item Statistical significance: paired t-test, $p < 0.05$
\end{itemize}

\textbf{For robustness (RQ4):}
\begin{itemize}
    \item Cosine similarity under paraphrase (threshold: $\geq$0.90)
    \item Accuracy drop under keyword masking (threshold: $<$10\%)
    \item Routing consistency across perturbations
\end{itemize}
