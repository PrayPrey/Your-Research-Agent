
\subsubsection{Research Questions}

\begin{itemize}
\item \textbf{RQ1 (H-E0):} Are instruction prefix embeddings linearly separable by FLAN task family?
\item \textbf{RQ2 (H-E1):} Can a linear probe predict the oracle adapter selection with high accuracy?
\item \textbf{RQ3 (H-M1):} Does zero-shot IPCR routing achieve $\geq 90$\% of oracle adapter performance?
\item \textbf{RQ4 (H-M2):} Is routing robust to paraphrase and keyword perturbations?
\end{itemize}

\subsubsection{Dataset}

Task families tested include: cot\_gsm8k (math), cot\_strategyqa (reasoning), cot\_creak (verification), cot\_qasc (science), cot\_ecqa (commonsense), cot\_sensemaking (logic), cot\_esnli (NLI), cot\_aqua\_rat (algebra), stream\_qed, and others.

\subsubsection{Implementation Details}

\textbf{Encoder:} sentence-transformers/all-MiniLM-L6-v2 (frozen, 22M parameters)

\textbf{Classifier:} Scikit-learn LogisticRegression with L-BFGS solver, max iterations 2000, balanced class weights

\textbf{Adapter configuration:}
\begin{itemize}
\item Base model: Mistral-7B-Instruct-v0.1
\item LoRA rank: 16
\item LoRA alpha: 32
\item Target modules: q\_proj, v\_proj
\end{itemize}

\textbf{Compute:} Single NVIDIA A100 (40GB)

\subsubsection{Evaluation Metrics}

\textbf{For separability (RQ1):} Macro-F1 score (threshold: $\geq 0.75)$, per-family F1 scores

\textbf{For adapter selection (RQ2):} Top-1 accuracy (threshold: $\geq 70$\%), Top-3 accuracy (threshold: $\geq 85$\%)

\textbf{For end-to-end performance (RQ3):} Relative performance (IPCR accuracy / Oracle accuracy), threshold: $\geq 90$\% of oracle

\textbf{For robustness (RQ4):} Cosine similarity under paraphrase (threshold: $\geq 0.90)$, accuracy drop under keyword masking (threshold: <10\%)
