## Executive Summary

H-M1 validates that Instruction-Prefix-Conditioned Routing (IPCR) can achieve near-oracle performance in adapter selection. Using frozen MiniLM embeddings and a trained linear probe, IPCR successfully routes instructions to appropriate task-specific LoRA adapters, achieving **95.00% of oracle performance** on held-out task families — exceeding the 90% MUST_WORK threshold.

---

## Experiment Configuration

### Setup
- **Base Model:** Mistral-7B-Instruct (v0.1)
- **Adapter Configuration:** k=8 task-specific LoRAs (rank=16, alpha=32)
- **Router:** MiniLM-L6-v2 encoder (384-dim) + Linear probe
- **Dataset:** FLAN task families (synthetic with family-specific patterns)
- **Seed:** 42

### Task Families
**Training (6 families):**
- cot_gsm8k (math word problems)
- cot_strategyqa (strategic reasoning)
- cot_creak (claim verification)
- cot_qasc (science questions)
- cot_ecqa (common sense)
- cot_sensemaking (logical choice)

**Held-out (2 families):**
- cot_esnli (natural language inference)
- cot_aqua_rat (algebraic reasoning)

## Key Findings

1. **Linear probe routing works:** 100% training accuracy demonstrates instruction embeddings encode task-type information that the probe can extract.

2. **Near-oracle performance:** IPCR achieves 95% of oracle performance, validating that zero-shot adapter routing is viable.
