\section{Methodology}

Our approach operationalizes the Human$\rightarrow$AI alignment concept through a pipeline of extraction, independence validation, and semantic verification.

\subsection{Agency Proxy Extraction}

We define four agency proxies motivated by HumanAgencyBench's dimensions:

\begin{itemize}
    \item \textbf{Clarifying Questions.} Binary indicator for responses containing question structures that seek clarification before providing advice.
    \item \textbf{Option Enumeration.} Count of explicitly enumerated alternatives presented to the user.
    \item \textbf{Epistemic Hedging.} Ratio of uncertainty markers to total tokens.
    \item \textbf{Explicit Deferral.} Binary indicator for responses that explicitly defer to user judgment.
\end{itemize}

For each proxy, we train a TF-IDF + Logistic Regression classifier using regex-generated labels as ground truth.

\subsection{BAI Computation}

The Bidirectional Alignment Index combines proxy probabilities with length normalization:

\begin{equation}
\text{BAI} = \frac{1}{4} \sum_{p \in \text{proxies}} P(p|\text{response}) \cdot \frac{1}{1 + 0.1 \cdot \log(\text{word\_count})}
\end{equation}

\subsection{Adversarial Probing for Representational Independence}

To test whether BAI occupies a representationally independent subspace, we employ gradient reversal training with:
\begin{itemize}
    \item A shared encoder
    \item Reward probe (standard gradient descent)
    \item BAI probe (gradient reversal)
\end{itemize}

If BAI occupies an independent subspace, the BAI probe should maintain high performance (AUROC $\geq$ 0.7) even after gradient reversal suppresses reward-predictive variance.

\subsection{Disagreement Analysis}

We quantify systematic disagreement through quartile-based analysis, identifying responses in high-BAI/low-reward (HL) or low-BAI/high-reward (LH) quadrants after z-score standardization.

\subsection{Semantic Coherence Validation}

We cluster disagreement responses using BERTopic (all-MiniLM-L6-v2 embeddings, UMAP, HDBSCAN) and check whether discovered topics contain agency vocabulary.
