\section{Experimental Setup}
\label{sec:experiments}

We design experiments to answer four research questions corresponding to our hypothesis decomposition:

\textbf{RQ1 (Existence):} Does metadata completeness predict reduced reproducibility variance after controlling for intrinsic stability, popularity, and algorithm family?

\textbf{RQ2 (Mechanism):} Does preprocessing entropy mediate the metadata-to-variance relationship?

\textbf{RQ3 (Temporal Robustness):} Does the effect persist in early-run subsamples, ruling out reverse causality?

\textbf{RQ4 (Algorithm Robustness):} Does the effect hold within single algorithm families, ruling out algorithm-mix confounds?

\subsection{Baselines and Controls}

We compare the predictive value of metadata completeness against alternative predictors:

\begin{itemize}
    \item \textbf{Naive Correlation:} Simple correlation without controls
    \item \textbf{Intrinsic-Stability-Only Model:} Predicts from dataset characteristics alone
    \item \textbf{Popularity-Only Model:} Predicts from run count and citations
    \item \textbf{Size Baseline:} $\log(\text{NumberOfInstances})$ as sole predictor
\end{itemize}

\subsection{Evaluation Metrics}

\textbf{Primary Metrics (RQ1):}
\begin{itemize}
    \item Relative IQR reduction: Success threshold $\geq$20\%
    \item 95\% CI lower bound: Must exclude $<$10\%
\end{itemize}

\textbf{Mechanism Metrics (RQ2):}
\begin{itemize}
    \item Proportion mediated: Success threshold $\geq$30\%
    \item Sobel Z-statistic: $|Z| \geq 1.96$
\end{itemize}

\textbf{Robustness Metrics (RQ3--4):}
\begin{itemize}
    \item Early-run persistence ratio: $\geq$50\%
    \item Within-algorithm significance: $p < 0.05$
\end{itemize}
