
Experiments address four research questions:

\textbf{RQ1 (Existence):} Is metadata completeness associated with reduced reproducibility variance after controlling for intrinsic stability, popularity, and algorithm family?

\textbf{RQ2 (Mechanism):} Does preprocessing entropy mediate the metadata-to-variance association?

\textbf{RQ3 (Temporal Robustness):} Does the association persist in early-run subsamples?

\textbf{RQ4 (Algorithm Robustness):} Does the association hold within single algorithm families?

\subsubsection{Baselines and Controls}

Alternative predictors examined:
\begin{itemize}
\item \textbf{Naive Correlation}: Simple correlation without controls
\item \textbf{Intrinsic-Stability-Only Model}: Predicts from dataset characteristics alone
\item \textbf{Popularity-Only Model}: Predicts from run count
\item \textbf{Size Baseline}: log(NumberOfInstances) as sole predictor
\end{itemize}

\subsubsection{Evaluation Metrics}

\textbf{Primary Metrics (RQ1)}:
\begin{itemize}
\item Relative IQR reduction: Success threshold $\geq 20$\%
\item 95\% CI lower bound: Must exclude <10\%
\end{itemize}

\textbf{Mechanism Metrics (RQ2)}:
\begin{itemize}
\item Proportion mediated: Success threshold $\geq 30$\%
\item Sobel Z-statistic: |Z| $\geq$ 1.96
\end{itemize}

\textbf{Robustness Metrics (RQ3--4)}:
\begin{itemize}
\item Early-run persistence ratio: $\geq 50$\%
\item Within-algorithm significance: p < 0.05
\end{itemize}
