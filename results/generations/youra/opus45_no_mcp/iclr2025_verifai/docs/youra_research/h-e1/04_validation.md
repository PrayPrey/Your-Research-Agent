## Analysis

### Gate Interpretation

The Jaccard similarity of 0.0 indicates **complete orthogonality** between static and execution error sets. Even when both error types exist for the same problem (90 cases), the specific error categories do not overlap.

This confirms the foundational hypothesis: pylint/mypy detect categorically different errors than test execution.

### Key Findings

1. **Zero Jaccard overlap**: Static and execution error sets show no overlap (Jaccard = 0.0), strongly supporting the hypothesis that these error types are orthogonal.

2. **Static analysis dominant**: 176 problems (32.5%) have static-only errors vs only 1 problem (0.2%) with exec-only errors, suggesting static analysis catches issues that don't manifest as runtime failures.

3. **Clean canonical solutions**: 274 problems (50.6%) pass both static and execution checks with no errors detected, consistent with evalplus canonical solutions being high-quality.

4. **"Both" category**: 90 problems (16.6%) have both error types, but Jaccard=0 indicates the specific error categories don't overlap.

### Mock Data Fix

Previous run hardcoded `exec_errors = set()` instead of calling `run_execution_tests()`. This fix:
- Enabled actual execution test runs
- Revealed 1 exec-only error and 90 "both" category problems
- Confirmed orthogonality holds even with real execution data
