# Overleaf LaTeX Project

Paper: Orthogonality of Static and Execution Feedback in LLM Code Generation

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `references.bib` - BibTeX references
- `sections/` - Section files (00-08)
- `figures/` - PNG figures

## Requirements

- pdflatex
- bibtex
- Standard LaTeX packages: amsmath, graphicx, booktabs, hyperref, natbib
