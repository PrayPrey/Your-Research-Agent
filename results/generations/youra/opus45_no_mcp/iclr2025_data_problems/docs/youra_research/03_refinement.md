## Final Hypothesis

### Title
Semantic Saturation Index for Paraphrase-Resistant Contamination Detection

### Hypothesis ID
H-SSI-v1

### Core Claim
Under standard foundation model evaluation settings, if a model was trained on benchmark items (verbatim or paraphrased), then it will exhibit significantly higher Semantic Saturation Index (SSI = inverse confidence variance across paraphrases) on those items compared to clean models, because training exposure creates robust semantic representations that generalize uniformly across phrasing variations.

### Mechanism
1. Training includes benchmark items in various phrasings
2. Model develops robust semantic representation for contaminated concepts
3. Representation invariance manifests as uniform confidence across paraphrases
4. SSI = 1/variance captures this invariance as contamination signal

## Novelty

**Key Innovation**: SSI exploits paraphrase uniformity as the SIGNAL rather than vulnerability. Instead of trying to match surface forms (which fails on paraphrases), we measure the CONSEQUENCE of paraphrase training — semantic saturation.

**Differentiation**:
| Method | Paraphrase-Resistant | Scalable | Continuous |
|--------|---------------------|----------|------------|
| 13-gram | No | Yes | No |
| DCQ | Partial | Medium | No |
| **SSI (ours)** | **Yes** | **Yes** | **Yes** |

## Experimental Design

**Dataset**: MMLU (14K items, stratified by difficulty)

**Model**: Mistral-7B with controlled contamination variants (clean, 5%, 10%, 20%, 50%)

**Paraphrases**: K=20 per item using multi-method approach (T5, GPT-4, rule-based)

**Baselines**: 
- 13-gram overlap (GPT-3 style)
- DCQ (Data Contamination Quiz)

**Compute**: ~6M forward passes, ~10 hours on A100

## Limitations

- **Domain transfer**: Thresholds may need per-benchmark calibration (MMLU vs GSM8K)
- **Partial contamination**: Intermediate SSI values harder to interpret
- **API access**: Closed models without logprobs cannot be evaluated
- **Calibration**: Model confidence must be meaningful (calibrated)
