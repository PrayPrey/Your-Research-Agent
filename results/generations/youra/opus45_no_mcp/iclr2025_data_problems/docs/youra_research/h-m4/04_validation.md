# Phase 4 Validation Report: H-M4

## Executive Summary

H-M4 tested whether SSI (Semantic Saturation Index = 1/variance) transforms confidence variance into an effective contamination detection metric. Using real MMLU data with Mistral-7B inference, SSI failed to discriminate between clean and contaminated items.

**Gate Verdict: FAIL** - Neither primary nor secondary criteria met.

---

## Key Findings

1. **SSI does not discriminate contamination**: AUC of 0.506 is essentially chance-level classification.

2. **No monotonic relationship**: Pearson r = -0.164 shows weak negative correlation (opposite of expected), not statistically significant (p=0.79).

3. **No practical significance**: Cohen's d = 0.009 indicates negligible effect size.

4. **High within-group variance**: SSI standard deviations exceed means at all levels, indicating distributions overlap completely.

5. **Mechanism not validated**: The inverse-variance transform does not produce a usable contamination signal on real data.

---

## Analysis

The hypothesis that SSI = 1/variance captures contamination signal is not supported by real data:

- **Why it failed:** Real model confidence across paraphrases has high intrinsic variance regardless of contamination status. The 1/variance transform amplifies noise rather than signal.

- **Mock vs Real discrepancy:** Previous simulated results showed PASS because mock data generator explicitly encoded contamination-SSI relationship. Real inference shows no such relationship.
