
\subsubsection{3.1 Theoretical Foundation}

SSI is grounded in learning theory: models trained on diverse phrasings of the same content develop representations invariant to surface form \citep{blum1998combining}. This invariance should manifest as uniform confidence scores across paraphrases. The causal chain is:

\begin{enumerate}
\item \textbf{Contamination exposure}: Training includes benchmark items.
\item \textbf{Representation invariance}: Diverse exposure creates robust encoding.
\item \textbf{Confidence uniformity}: Invariant representations yield consistent predictions.
\item \textbf{SSI signal}: Low variance indicates potential contamination.
\end{enumerate}

\subsubsection{3.2 SSI Formulation}

For each benchmark item x, K paraphrases are generated and model confidence scores extracted:

$$\text{SSI}(x) = \frac{1}{\text{Var}(\{c(x_1), c(x_2), \ldots, c(x_K)\})}$$

where c(x\_i) is the model's confidence (probability assigned to correct answer) on paraphrase i.

\subsubsection{3.3 Controlled Contamination Protocol}

Contaminated model variants are created via LoRA fine-tuning \citep{hu2022lora} of Mistral-7B-v0.1 at levels 0\%, 10\%, 50\% of MMLU test items. Configuration: rank 16, alpha 32, learning rate 2e-5, 3 epochs, target modules q\_proj, v\_proj, k\_proj, o\_proj, effective batch size 32.

\subsubsection{3.4 Paraphrase Generation}

K=20 paraphrases per item generated via T5-paraphrase, GPT-4, and rule-based synonym substitution methods.
