\section{Discussion}

\subsection{Mechanism Validated, Metric Inadequate}

The causal mechanism holds:
\begin{itemize}
    \item Contamination $\rightarrow$ Training exposure (31.1\% accuracy gain)
    \item Training exposure $\rightarrow$ Representation invariance (MPS diff 0.065)
    \item Representation invariance $\rightarrow$ Confidence uniformity (r=$-$0.517)
\end{itemize}

The SSI formulation breaks this chain. Alternative metrics---entropy, coefficient of variation---may extract the validated signal without pathological noise sensitivity.

\subsection{Simulation-Reality Gap}

H-E1 through H-M3 passed on simulated data; only H-M4 used real inference and failed. End-to-end validation with actual model inference is essential.

\subsection{Limitations}

\begin{itemize}
    \item Single scale (7B only)
    \item Single benchmark (MMLU only)
    \item Mechanism steps used simulated data
\end{itemize}
