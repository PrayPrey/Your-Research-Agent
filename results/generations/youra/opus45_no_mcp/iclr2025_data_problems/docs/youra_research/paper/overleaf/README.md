# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Section files (00-07)
- `references.bib` - Bibliography
- `figures/` - Figures (if any)

## Overleaf Upload

Upload entire folder to Overleaf. Set main.tex as main document.
