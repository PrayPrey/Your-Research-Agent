\section{Experiments}

\subsection{Dataset and Model}

\textbf{MMLU}: 14,042 test items across 57 subjects

\textbf{Model}: Mistral-7B-v0.1, LoRA fine-tuned

\subsection{Training Protocol}

LoRA configuration: rank 16, alpha 32, learning rate 2e-5, 3 epochs.

\subsection{Evaluation Metrics}

\begin{itemize}
    \item Primary: AUC for binary classification using SSI
    \item Secondary: Pearson $r$ (contamination level vs.\ SSI), Cohen's $d$
\end{itemize}
