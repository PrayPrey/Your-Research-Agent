# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Individual section files (00-08)
- `figures/` - PNG figures
- `references.bib` - Bibliography

## Overleaf Upload

Upload entire folder contents to Overleaf. Set main document to `main.tex`.
