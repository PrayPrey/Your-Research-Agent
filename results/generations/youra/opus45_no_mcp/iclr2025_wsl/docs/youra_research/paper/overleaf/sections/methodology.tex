\section{Methodology}

\subsection{Ablation Ladder Design}

Our goal is isolating the contribution of structural inductive biases to property prediction. We design a four-step ablation ladder where each step adds exactly one bias:

\begin{table}[h]
\centering
\begin{tabular}{@{}clc@{}}
\toprule
Step & Method & Structural Bias Added \\
\midrule
1 & Flatten+MLP & None (baseline) \\
2 & Layer-wise & Per-layer processing \\
3 & Layer-wise+GRB & Permutation alignment \\
4 & NFN & Permutation equivariance \\
\bottomrule
\end{tabular}
\caption{Ablation ladder with increasing structural sophistication.}
\label{tab:ablation-ladder}
\end{table}

\subsection{Embedding Architectures}

\textbf{Flatten+MLP (Baseline)}: All network parameters are concatenated into a single vector and passed through an MLP encoder. This baseline ignores network structure entirely.

\textbf{Layer-wise Encoding}: For each layer $l$, we compute four statistics: mean, standard deviation, minimum, and maximum of the weight values. These statistics are concatenated across layers and encoded via MLP. This preserves layer-level structure.

\textbf{Layer-wise+GRB}: Before computing layer-wise statistics, we align each model to a reference using Git Re-Basin, removing permutation-induced variance.

\textbf{Neural Functional Transformer}: NFN processes weights using permutation-equivariant layers by design, avoiding explicit alignment.

\subsection{Dataset}

We use the CIFAR-10 Model Zoo containing $N = 61{,}335$ pretrained CNN checkpoints with ground-truth accuracy labels. Key properties:
\begin{itemize}
    \item \textbf{Accuracy variance}: $\sigma = 15.62\%$ (above 10\% threshold)
    \item \textbf{Split}: 80\% train / 20\% test, fixed across methods
\end{itemize}

\subsection{Training Protocol}

\begin{itemize}
    \item \textbf{Optimizer}: AdamW (lr=0.001, weight\_decay=0.0001)
    \item \textbf{Epochs}: 50 with early stopping (patience=10)
    \item \textbf{Seeds}: 5 independent runs
\end{itemize}

\subsection{Evaluation Metrics}

\begin{itemize}
    \item \textbf{Primary}: Pearson correlation ($r$) between predicted and ground-truth accuracy
    \item \textbf{Statistical test}: Paired $t$-test across seeds ($\alpha = 0.05$)
\end{itemize}

\subsection{Success Criteria}

\begin{itemize}
    \item \textbf{P1}: Layer-wise $>$ Flatten+MLP by $\Delta r > 0.1$ ($p < 0.05$)
    \item \textbf{P2}: Layer-wise+GRB $>$ Layer-wise by $\Delta r > 0.05$ ($p < 0.05$)
    \item \textbf{P3}: NFN $>$ Layer-wise+GRB by $\Delta r > 0.05$ ($p < 0.05$)
\end{itemize}
