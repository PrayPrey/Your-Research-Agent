
\subsubsection{Ablation Ladder Design}

The goal is isolating the contribution of structural inductive biases to property prediction. A four-step ablation ladder was designed where each step adds exactly one bias:

\begin{table}[htbp]
\centering
\resizebox{\columnwidth}{!}{%
\begin{tabular}{lll}
\toprule
Step & Method & Structural Bias Added \\
\midrule
1 & Flatten+MLP & None (baseline) \\
2 & Layer-wise & Per-layer processing \\
3 & Layer-wise+GRB & Permutation alignment \\
4 & NFN & Permutation equivariance \\
\bottomrule
\end{tabular}
}
\end{table}

\subsubsection{Embedding Architectures}

\textbf{Flatten+MLP (Baseline)}: All network parameters are concatenated into a single vector and passed through an MLP encoder. This baseline ignores network structure.

\textbf{Layer-wise Encoding}: For each layer l, four statistics are computed: mean, standard deviation, minimum, and maximum of the weight values. These statistics are concatenated across layers and encoded via MLP. This preserves layer-level structure.

\textbf{Layer-wise+GRB}: Before computing layer-wise statistics, each model is aligned to a reference using Git Re-Basin, removing permutation-induced variance.

\textbf{Neural Functional Transformer}: NFN processes weights using permutation-equivariant layers by design, avoiding explicit alignment.

\subsubsection{Training Protocol}

\begin{itemize}
\item Optimizer: AdamW (lr = 0.001, weight\_decay = 0.0001)
\item Epochs: 50 with early stopping (patience = 10)
\item Learning rate schedule: ReduceLROnPlateau (factor = 0.5, patience = 5)
\item Batch size: 256
\item Seeds: 5 independent runs
\end{itemize}

\subsubsection{Evaluation Metrics}

\begin{itemize}
\item Primary: Pearson correlation (r) between predicted and ground-truth accuracy
\item Statistical test: Paired t-test across seeds ($\alpha$ = 0.05)
\end{itemize}

\subsubsection{Success Criteria}

\begin{itemize}
\item P1: Layer-wise > Flatten+MLP by $\Delta r$ > 0.1 (p < 0.05)
\item P2: Layer-wise+GRB > Layer-wise by $\Delta r$ > 0.05 (p < 0.05)
\item P3: NFN > Layer-wise+GRB by $\Delta r$ > 0.05 (p < 0.05)
\end{itemize}
