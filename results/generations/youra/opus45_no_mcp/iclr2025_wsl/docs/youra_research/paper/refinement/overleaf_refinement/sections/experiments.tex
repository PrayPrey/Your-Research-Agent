\subsubsection{Implementation Details}

\textbf{Regressor Head}: Input 128-dimensional, hidden dimension 64, output 1 (predicted accuracy).

\textbf{Training}: AdamW optimizer with ReduceLROnPlateau schedule, batch size 256, early stopping. Hardware: CPU only (CUDA unavailable).
