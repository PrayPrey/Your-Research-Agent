# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Individual section files (00-08)
- `figures/` - All figure files
- `references.bib` - Bibliography

## Upload to Overleaf

1. Zip entire folder
2. Upload to Overleaf as new project
3. Compile with pdflatex
