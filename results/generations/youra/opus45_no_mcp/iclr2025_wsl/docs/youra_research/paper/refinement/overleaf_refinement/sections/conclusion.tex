
This work investigated whether respecting neural network structure improves weight embedding quality for property prediction.

Layer-wise encoding improves accuracy prediction correlation by $\Delta r$ = 0.126 (p < 0.001) over naïve flattening on the CIFAR-10 Model Zoo. This improvement holds across all five random seeds tested.

The complete four-step ablation was not achieved due to computational constraints on alignment preprocessing at the 61K model scale. The contributions of Git Re-Basin alignment and Neural Functional Transformers remain to be evaluated in future work with appropriate computational resources.

Three implications follow from the completed experiments:

\begin{enumerate}
\item Layer-wise encoding should be considered as a baseline rather than flattening when evaluating weight embedding methods.
\item Structural preservation provides measurable benefit for property prediction.
\item Controlled ablation enables fair comparison across embedding methods.
\end{enumerate}
