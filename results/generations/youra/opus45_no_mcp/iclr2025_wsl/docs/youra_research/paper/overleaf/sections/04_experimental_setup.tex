\subsection{Implementation Details}

\textbf{Layer-wise Encoder}: Input $4 \times L$ statistics per layer, hidden 256 units, output 128-dim embedding.

\textbf{Regressor Head}: Input 128-dim, hidden 64 units, output 1 (predicted accuracy).

\textbf{Training}: AdamW optimizer, ReduceLROnPlateau schedule, batch size 256, early stopping.
