
This paper presents the first systematic comparison of token entropy and semantic consistency for hallucination detection on the same benchmark with the same model. Key findings:

\begin{enumerate}
\item Consistency outperforms entropy: AUROC 0.81 versus 0.65, Cohen's d 1.19 versus 0.47.
\item Linear fusion provides no improvement at proof-of-concept scale (N = 20).
\item The signals are moderately negatively correlated (r = $-0.54)$, suggesting partial redundancy.
\end{enumerate}

For practitioners building hallucination detection systems for factual QA, consistency should be the primary signal. The question of whether entropy provides complementary information remains open pending larger-scale experiments (N $\geq$ 500) and exploration of non-linear combination strategies.
