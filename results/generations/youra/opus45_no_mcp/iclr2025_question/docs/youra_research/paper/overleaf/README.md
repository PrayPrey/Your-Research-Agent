# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - LaTeX sections (00-08)
- `references.bib` - BibTeX references
- `figures/` - Figures (if any)

## Output

Compiled PDF: `main.pdf`
