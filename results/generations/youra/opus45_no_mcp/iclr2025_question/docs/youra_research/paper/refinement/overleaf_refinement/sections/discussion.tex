
\subsubsection{Why Consistency Outperforms Entropy}

Consistency measures behavioral outcomes across multiple samples, while entropy measures internal states from logit distributions. When a model hallucinates, it may generate confident but inconsistent responses. Entropy fails to flag these cases; consistency captures them. The large effect size for consistency (d = 1.19 versus d = 0.47 for entropy) indicates this difference is practically meaningful.

\subsubsection{Why Fusion Did Not Improve}

Three factors may explain the collapse to pure consistency:

\begin{enumerate}
\item \textbf{Small sample size:} N = 20 with a 2-sample validation set cannot reliably estimate fusion weights.
\item \textbf{Signal dominance:} Consistency (AUROC 0.81) substantially outperforms entropy (AUROC 0.65), so the weaker signal adds noise rather than complementary information at this scale.
\item \textbf{Negative correlation:} The moderate negative correlation (r = $-0.54)$ suggests partial redundancy---high-entropy questions tend to produce low-consistency outputs.
\end{enumerate}

The SHOULD\_WORK gate allows documenting H-M3 as a limitation rather than terminating the research line. The complementarity hypothesis is inconclusive, not refuted.

\subsubsection{Limitations}

\begin{itemize}
\item \textbf{Sample size:} N = 20 for H-M2 and H-M3 limits statistical power and generalizability.
\item \textbf{Single model:} Only Llama-2-7B-chat was tested; larger models or different architectures may yield different results.
\item \textbf{Single dataset:} Only TriviaQA was used; Natural Questions, TruthfulQA, and other benchmarks were not tested.
\item \textbf{Entropy baseline:} Token entropy was compared, not semantic entropy \citep{kuhn2023semantic}, which clusters responses by meaning before computing entropy and reports AUROC 0.75--0.85.
\item \textbf{Inference cost:} Consistency requires 10 forward passes per question for 10 samples; entropy can be computed from a single pass. This $10\times$ cost difference affects deployment decisions.
\end{itemize}

\subsubsection{Practical Implications}

\begin{enumerate}
\item Prioritize consistency-based detection when multiple generations per query are feasible.
\item Consider entropy as a fallback when multiple generations are impractical.
\item Fusion at small scale does not appear to provide benefit; larger-scale validation is needed before deploying combined approaches.
\end{enumerate}
