\section{Discussion}

\subsection{Why Consistency Outperforms Entropy}

Consistency measures behavioral outcomes (do multiple attempts agree?) while entropy measures internal states (how uncertain is the token distribution?). When a model hallucinates, it may generate confident but inconsistent responses across samples. Entropy fails to flag these cases; consistency captures them.

The large effect size for consistency ($d$=1.19 vs $d$=0.47) indicates this is practically meaningful, not merely a statistical artifact.

\subsection{Why Fusion Failed}

Three factors explain the collapse to pure consistency:

\begin{enumerate}
    \item \textbf{Small sample size:} $N$=20 with 2-sample validation cannot reliably estimate fusion weights
    \item \textbf{Consistency dominance:} The stronger signal (0.81) overwhelms the weaker (0.65)
    \item \textbf{Linear assumption:} Non-linear combinations might extract value that linear fusion misses
\end{enumerate}

We emphasize that H-M3's failure does not disprove fusion's potential---it demonstrates that at PoC scale, consistency alone suffices.

\subsection{Limitations}

\begin{itemize}
    \item \textbf{Sample size:} $N$=20 for H-M2/H-M3 limits statistical power
    \item \textbf{Single model:} Llama-2-7B-chat only; larger models may differ
    \item \textbf{Single dataset:} TriviaQA only; other tasks may show different patterns
    \item \textbf{Entropy baseline:} We compare against raw token entropy, not semantic entropy \citep{kuhn2023semantic}, which clusters responses by meaning before computing entropy and achieves higher AUROC (0.75--0.85). A direct comparison with semantic entropy remains future work.
    \item \textbf{Inference cost:} Consistency requires 10 forward passes per question (for 10 samples), while entropy can be computed from a single pass. This 10$\times$ cost difference is critical for practitioners weighing deployment tradeoffs.
\end{itemize}

\subsection{Practical Implications}

\begin{enumerate}
    \item \textbf{Start with consistency} if you can afford multiple generations per query
    \item \textbf{Entropy as fallback} when multiple generations are impractical
    \item \textbf{Skip fusion at small scale} until validated on your specific task
\end{enumerate}
