# Overleaf LaTeX Project

## Compilation

```bash
cd overleaf
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Section .tex files (00-08)
- `figures/` - PNG figures
- `references.bib` - BibTeX references

## Overleaf Upload

Upload entire folder to Overleaf. Set main.tex as main document.
