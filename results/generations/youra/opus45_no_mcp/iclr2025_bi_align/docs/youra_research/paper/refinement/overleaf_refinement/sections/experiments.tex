\subsubsection{Models}

Three RLHF-trained models were evaluated:

\begin{itemize}
\item Llama-2-7B-Chat (meta-llama/Llama-2-7b-chat-hf)
\item Llama-2-13B-Chat (meta-llama/Llama-2-13b-chat-hf)
\item Mistral-7B-Instruct (mistralai/Mistral-7B-Instruct-v0.2)
\end{itemize}

\subsubsection{Task Classification}

Tasks are classified into Type A (correctness, 1,977 tasks, 89.4\%) and Type B (user-state-modeling, 235 tasks, 10.6\%) based on keyword markers including user belief references (''you think'', ''your opinion''), context markers (''given that'', ''considering''), and hedge markers (''might'', ''could'', ''possibly'').

\subsubsection{Hyperparameters}

Clustering: K-means with k=2, seed=42, n\_init=10. Inference: batch\_size 8-16, float16, device\_map=auto. Inversion threshold: 0.1. Silhouette threshold: 0.3.
