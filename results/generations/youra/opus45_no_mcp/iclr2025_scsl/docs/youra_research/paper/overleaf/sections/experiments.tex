\section{Experimental Setup}

We evaluate on three standard spurious correlation benchmarks: \textbf{Waterbirds} (bird species with background as spurious attribute), \textbf{CelebA} (hair color with gender as spurious attribute), and \textbf{ColoredMNIST} (digit classification with color as spurious attribute).

We use ResNet-50 with SGD (momentum 0.9, LR 0.001 constant, weight decay $10^{-4}$, batch size 128). We run 5 seeds per benchmark. Constant learning rate eliminates confounds from learning rate schedules.

\textbf{Evaluation Metrics:} Detection rate ($>80\%$ target), timing variance ($<5$ epochs), SNR ($>2.0$), normalized timing (15--40\% hypothesis).
