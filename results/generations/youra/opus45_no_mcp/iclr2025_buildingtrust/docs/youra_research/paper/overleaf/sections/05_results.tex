\subsection{H-M1: CoT Reasoning Detection}

CoT prompting reliably produces multi-step reasoning chains:

\begin{itemize}
    \item \textbf{CoT reasoning rate:} 100\% (817/817 outputs contain multi-step reasoning)
    \item \textbf{Baseline reasoning rate:} 0\% (0/817 outputs contain reasoning)
    \item \textbf{Rate difference:} 100 percentage points (exceeds 50\% threshold)
    \item \textbf{Mean reasoning steps:} 4.49 (exceeds 2.0 threshold)
\end{itemize}

\subsection{H-M2: Hedging Marker Presence}

CoT outputs contain substantial epistemic hedging markers:

\begin{itemize}
    \item \textbf{Hedging presence rate:} 82.0\% (670/817 outputs contain $\geq$1 marker)
    \item \textbf{Mean markers per output:} 2.84
    \item \textbf{Median markers per output:} 2
\end{itemize}

Top 5 most frequent markers:
\begin{enumerate}
    \item ``may'' --- 787 occurrences
    \item ``could'' --- 619 occurrences
    \item ``but'' --- 337 occurrences
    \item ``however'' --- 255 occurrences
    \item ``likely'' --- 198 occurrences
\end{enumerate}

\subsection{H-M3: Positional Ordering}

Structural analysis confirms markers are positioned to influence confidence generation:

\begin{itemize}
    \item \textbf{CoT-then-confidence ordering:} 100\% (817/817 outputs)
    \item \textbf{Markers precede confidence:} 100\% (of outputs with both markers and confidence)
\end{itemize}

\subsection{H-M4: Hedging-Confidence Correlation}

The primary finding: hedging marker count negatively correlates with verbalized confidence.

\begin{itemize}
    \item \textbf{Spearman $r$:} $-0.315$
    \item \textbf{$p$-value:} $9.22 \times 10^{-17}$
    \item \textbf{Sample size:} $n=664$ (outputs with valid confidence extraction)
    \item \textbf{95\% CI:} $[-0.382, -0.246]$
\end{itemize}

The correlation coefficient of $-0.315$ exceeds the $-0.2$ threshold by 57\%, indicating a stronger-than-expected relationship.
