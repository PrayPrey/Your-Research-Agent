
\subsubsection{Mechanism Hypothesis}

The hypothesized self-reading mechanism proceeds as follows:

\begin{enumerate}
\item CoT prompting forces reasoning articulation before answering.
\item Reasoning reveals epistemic uncertainty through hedging markers.
\item Hedging markers appear in-context before confidence generation.
\item The model incorporates uncertainty signals into its confidence estimate.
\end{enumerate}

This predicts a negative correlation between hedging marker count and verbalized confidence.

\subsubsection{Dataset}

TruthfulQA \citep{lin2022teaching} was used, an adversarial benchmark testing model tendency toward common misconceptions. The generation split contains 817 items across categories including health, law, finance, and common sense. TruthfulQA was selected because it presents genuinely difficult questions where calibration matters and its adversarial design creates variation in difficulty.

\subsubsection{Model}

GPT-3.5-turbo was accessed via OpenAI API with temperature = 0 for deterministic outputs. A single model was used to establish proof-of-concept; replication on other models (Llama-2-70B, Claude, GPT-4) is deferred to future work.

\subsubsection{Hedging Marker Detection}

Seventeen epistemic hedging markers were identified based on linguistic literature \citep{hyland1998hedging}: ''may,'' ''could,'' ''might,'' ''possibly,'' ''perhaps,'' ''likely,'' ''unlikely,'' ''but,'' ''however,'' ''although,'' ''alternatively,'' ''uncertain,'' ''not sure,'' ''seems,'' ''appears,'' ''probably,'' ''suggest.''

\subsubsection{Confidence Extraction}

Verbalized confidence was parsed from outputs using regex matching for patterns such as ''Confidence: X\%'' with fallback to percentage mentions.

\subsubsection{Positional Analysis}

Structural ordering was verified by identifying CoT, answer, and confidence segments and confirming markers appeared before confidence statements.

\subsubsection{Correlation Analysis}

Spearman rank correlation was computed between hedging count and confidence, with significance testing.
