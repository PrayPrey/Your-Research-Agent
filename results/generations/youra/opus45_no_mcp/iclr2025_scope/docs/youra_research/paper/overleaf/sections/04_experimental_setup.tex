\section{Experimental Setup}

\subsection{Datasets}

Four benchmarks spanning retrieval density: GSM8K~\cite{cobbe2021gsm8k} (0.1), MMLU~\cite{hendrycks2021mmlu} (0.5), HotpotQA~\cite{yang2018hotpotqa} (0.7), Natural Questions~\cite{kwiatkowski2019nq} (0.9). Total: 26,376 evaluation samples.

\subsection{Baselines}

\textbf{Transformer + LoRA}: Standard LoRA on attention projections.

\textbf{Mamba-converted + LoRA}: LoRA on analogous Mamba projections after conversion.

\subsection{Implementation}

Model: 512-dimensional reduced architecture. LoRA: rank=16, alpha=32. Training: AdamW, lr=$2 \times 10^{-4}$, cosine schedule, 3--5 epochs. Seed: 42.
