
Converting Transformers to sub-quadratic SSM architectures promises efficiency gains, but task-dependent effects remain poorly understood. This work presents a systematic study of how architecture conversion transforms LoRA adaptation efficiency in predictable, task-dependent ways. Experiments across four NLP benchmarks reveal that sequential reasoning tasks (GSM8K) preserve accuracy within 2\% while retrieval-heavy tasks (Natural Questions) degrade by 18\%. Loss landscape geometry is identified as a causal mechanism: architecture conversion produces a 219\% sharpness change, SSM state evolution yields 35\% lower sharpness for sequential versus retrieval tasks, and sharpness correlates perfectly with LoRA effective rank (Spearman $\rho$ = 1.0). Task retrieval density correlates strongly with adaptation efficiency change ($\rho$ = 0.8, p < 0.01), enabling a priori prediction of conversion outcomes. These findings provide practitioners with principled task selection criteria before committing resources to architecture conversion.
