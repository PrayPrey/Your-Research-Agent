\section{Experimental Setup}

\subsection{Datasets}

Four benchmarks spanning retrieval density: GSM8K (0.1), MMLU (0.5), HotpotQA (0.7), Natural Questions (0.9). Total: 26,376 evaluation samples.

\subsection{Baselines}

\textbf{Transformer + LoRA}: Standard LoRA on attention projections.

\textbf{Mamba-converted + LoRA}: LoRA on analogous Mamba projections after conversion.

\subsection{Implementation}

Model: 512-dimensional reduced architecture. LoRA: rank=16, alpha=32. Training: AdamW, lr=$2 \times 10^{-4}$, cosine schedule, 3--5 epochs. Seed: 42.
