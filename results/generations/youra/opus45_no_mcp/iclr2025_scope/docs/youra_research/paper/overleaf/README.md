# Overleaf LaTeX Project

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure

- `main.tex` - Main document
- `sections/` - Section files (00-08)
- `figures/` - Paper figures
- `references.bib` - Bibliography

## Requirements

- ICML 2025 style files (icml2025.sty, icml2025.bst)
- TeX Live 2024+ or Overleaf
