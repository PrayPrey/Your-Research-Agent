## 1. Executive Summary

This PRD specifies the implementation requirements for testing hypothesis H-M2: Under Mamba's selective scan operation, if state evolution follows sequential token processing, then the loss landscape exhibits lower sharpness for sequential reasoning tasks compared to retrieval tasks.

Building on H-M1's validated finding (219% sharpness change, sign flip in landscape geometry), this experiment measures task-specific sharpness patterns within the Mamba architecture.

**Gate Condition:** sharpness_ratio(sequential/retrieval) < 0.8

---

## 2. Problem Statement

H-M1 demonstrated that Mamba exhibits fundamentally different loss landscape geometry than Transformers. H-M2 investigates whether this difference manifests as task-dependent patterns:
- Sequential reasoning tasks (GSM8K) should show lower sharpness due to alignment with SSM state evolution
- Retrieval tasks (Natural Questions) should show higher sharpness due to misalignment with sequential flow
