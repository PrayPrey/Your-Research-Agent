
\subsubsection{4.1 Research Questions}

\begin{itemize}
\item \textbf{RQ1:} Do trustworthiness dimensions exhibit significant pairwise partial correlations after controlling for scale and RLHF alignment?
\item \textbf{RQ2:} Is RLHF the mechanism behind joint safety--ethics co-optimization?
\item \textbf{RQ3:} What is the cluster structure, and does it match the predicted RLHF-sensitive vs. RLHF-insensitive grouping?
\item \textbf{RQ4:} What is the minimum sufficient evaluation set and its bootstrap stability?
\end{itemize}

\subsubsection{4.3 Baselines}

\begin{itemize}
\item \textbf{Raw Spearman correlation} --- without confound control; expected positive bias
\item \textbf{Scale-only control} --- partial correlation removing only $\log_{10}(\text{params})$ (not RLHF binary)
\item \textbf{Epoch AI capability baseline} --- median raw $\rho$ = 0.73 across 17 capability benchmarks; reported here as a field reference point only, not a methodologically equivalent comparison (see Section 2.3)
\end{itemize}

\subsubsection{4.4 Implementation}

Python 3.10; scipy 1.11, networkx 3.1, numpy 1.25, sklearn 1.3. Bootstrap: np.random.default\_rng(seed=42), 1000 resamples of 14/16 models.
