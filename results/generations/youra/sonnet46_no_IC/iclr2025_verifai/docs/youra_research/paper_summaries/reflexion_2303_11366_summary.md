# Reflexion: Language Agents with Verbal Reinforcement Learning

## Key Metadata
- **Authors:** Shinn et al.
- **Year:** 2023
- **Venue:** NeurIPS 2023 (arXiv 2303.11366)
- **Core Contribution:** Verbal reinforcement learning — LLM generates verbal self-reflection on failures; accumulates in episodic memory; 91% HumanEval pass@1 without weight updates.

## Section Summaries

### Abstract
Reflexion is a framework that reinforces language agents through verbal self-reflection rather than parameter updates. After each failed attempt, the agent generates a verbal reflection on what went wrong, stores it in an episodic buffer, and conditions subsequent attempts on this accumulated memory. Achieves 91% pass@1 on HumanEval (vs. ~67% baseline GPT-4), establishing a new upper bound for prompting-based code generation.

### Introduction & Motivation
RL-based training is expensive and requires differentiable reward signals. Reflexion achieves reinforcement-like learning through verbal feedback stored in working memory, enabling agents to improve across episodes without gradient updates. Applied to code generation, decision making, and reasoning tasks.

### Methodology
Three components: (1) Actor (generates code/actions); (2) Evaluator (tests against unit tests, returns pass/fail); (3) Self-Reflection (generates verbal analysis of failure from execution trace + task description). The verbal reflection is appended to the context for the next attempt. Episodic memory: fixed-length sliding window of reflections. Models: GPT-4, GPT-3.5. Benchmarks: HumanEval, MBPP (code); AlfWorld (decision making); HotpotQA (reasoning).

Key: feedback = execution pass/fail + verbal self-reflection generated by the LLM itself. No static analysis, no type constraints. Metric: pass@1 at fixed attempt count (typically 5 attempts).

### Experiments & Results
| Method | pass@1 | Benchmark |
|---|---|---|
| GPT-4 (no feedback) | ~67% | HumanEval |
| Reflexion (GPT-4) | 91% | HumanEval |
| GPT-3.5 + Reflexion | ~77% | HumanEval |
Compute: 5 attempts × (generation + reflection). Not compared to best-of-N at same compute. No static analysis or type-constraint comparison.

### Discussion & Conclusion
Reflexion demonstrates verbal feedback as a powerful improvement signal. 91% HumanEval is near the ceiling of HumanEval difficulty. Limitation: verbal self-reflection depends on the model's ability to accurately identify its own errors — weaker models may generate inaccurate reflections. No comparison to structural signals (static analysis, type constraints).

## Key Contributions
- Verbal RL framework for LLM agents without gradient updates
- 91% HumanEval pass@1 — sets execution + verbal feedback upper bound
- Episodic memory architecture for accumulated self-reflection
- Generalizable to non-code tasks (decision making, reasoning)

## Potential Relevance
Establishes the upper bound for execution + verbal feedback on HumanEval (91%). For Gap 3, this is the strongest known execution-feedback result. The key question is whether pylint/mypy or type-constrained decoding, applied in a similar iterative fashion, can approach this level — or whether execution remains the dominant signal. The 4,616-citation status makes Reflexion a required baseline in any feedback type ranking paper.
