## Local Compilation

```bash
cd overleaf/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Output: `main.pdf`

## Overleaf Upload

1. Zip the entire `overleaf/` folder
2. Go to Overleaf → New Project → Upload Project
3. Upload the zip
4. Set compiler to **pdfLaTeX**
5. Click Compile
