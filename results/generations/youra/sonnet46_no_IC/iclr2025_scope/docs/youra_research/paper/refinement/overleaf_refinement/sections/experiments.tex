
The experiments address three research questions:

\textbf{RQ1:} Does erank($W_0$) correlate significantly with PARA oracle ranks for BERT-base-uncased ($r \geq 0.65, p < 0.05$)?

\textbf{RQ2:} Does the erank-oracle correlation generalize across model families?

\textbf{RQ3:} Do erank($W_0$) and participation ratio PR($W_0$) agree in layer ranking ($\rho \geq 0.80$)?

\subsubsection{4.3 Training Protocol}

\textbf{NLP (BERT, DeBERTa):} AdamW, lr = $2 \times 10^{-5}$, weight decay = 0.01, batch size 32, warmup 6\%, minimum 3 epochs, baseline rank $r_{\text{base}} = 8$.

\textbf{Vision (ViT):} AdamW, lr = $1 \times 10^{-4}$, weight decay = 0.01, batch size 128, warmup 6\%, minimum 5 epochs.

\textbf{Oracle sweep:} For each target layer, 5 rank values $\times$ 2 seeds = 10 training runs; mean accuracy used for argmax.

\textbf{Hardware:} $4\times$ NVIDIA H100 NVL (95,830 MiB each). Oracle sweeps completed for 5 of 72 BERT-base-uncased target layers in the current experimental run.

\subsubsection{4.4 Evaluation Metrics}

\textbf{Primary:} Pearson $r$ (erank vs. oracle rank), one-tailed $p$-value.

\textbf{Secondary:} Pearson $\rho$ (erank vs. PR) for metric agreement.

Bootstrap confidence intervals were attempted (1000 resamples) but returned NaN at $n = 5$ due to the degenerate bimodal structure of the data --- all bootstrap resamples yield near-identical oracle rank splits. Statistical significance is therefore assessed via the exact one-tailed $t$-distribution.
