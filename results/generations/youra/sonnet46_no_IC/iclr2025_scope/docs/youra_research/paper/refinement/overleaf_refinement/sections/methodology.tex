
\subsubsection{3.1 Effective Rank of Pretrained Weight Matrices}

For a weight matrix $W_0 \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$ with singular values $\sigma_1 \geq \cdots \geq \sigma_k > 0$:

$$\text{erank}(W_0) = \exp\!\left(-\sum_{i=1}^{k} p_i \log p_i\right), \quad p_i = \frac{\sigma_i}{\sum_j \sigma_j}$$

This is the exponentiated Shannon entropy of the normalized singular value distribution, and equals the Roy and Vetterli [2007] definition.

\textbf{Relationship to alternatives.} Spectral entropy $H(\sigma/\|\sigma\|_1)$ lacks the natural scale $[1, \text{rank}(W_0)]$. Stable rank $\|W_0\|_F^2 / \|W_0\|_2^2$ is dominated by the largest singular value. erank is normalized, bounded, and captures the full distributional shape of the singular spectrum.

\textbf{Implementation.} Computed in fp32 precision via \texttt{torch.linalg.svdvals} for all weight matrices with $\geq 2$ dimensions and $< 50$M entries. Singular values below $\epsilon = 10^{-10}$ are excluded before normalization.

\begin{verbatim}
def compute_erank(W: torch.Tensor, eps: float = 1e-10) -> float:
    S = torch.linalg.svdvals(W.float())
    S = S[S > eps]
    p = S / S.sum()
    return (-(p * torch.log(p)).sum()).exp().item()
\end{verbatim}

\subsubsection{3.2 PARA Oracle: Ground-Truth Per-Layer Rank}

The PARA (Per-layer Argmax Rank Assignment) oracle establishes ground-truth optimal rank for each target layer:

\begin{enumerate}
\item Freeze all LoRA adapters at baseline rank $r_{\text{base}} = 8$.
\item For each target layer $l$, independently sweep rank over $\mathcal{R} = \{4, 8, 16, 32, 64\}$, training 2 random seeds per rank setting.
\item Assign $r_l^* = \arg\max_{r \in \mathcal{R}} \overline{\text{val\_acc}}(r)$, where $\overline{\text{val\_acc}}$ is the mean accuracy across seeds.
\end{enumerate}

This marginal oracle protocol is an established proxy for optimal per-layer rank [Zhang et al., 2023; Tripathi et al., 2026]. The marginal oracle is not equivalent to joint-optimal rank allocation (all layers optimized simultaneously), which is a limitation discussed in Section 6.

\subsubsection{3.3 Secondary Metric: Participation Ratio}

The participation ratio is defined as:

$$\text{PR}(W_0) = \frac{(\sum_i \sigma_i)^2}{\sum_i \sigma_i^2}$$

PR does not require full entropy computation and is tested for agreement with erank (P5) as a metric robustness check.

\subsubsection{3.4 Statistical Test Design}

\textbf{Primary test (H-E1 / P1):} Pearson $r(\text{erank}(W_0), r_l^*)$ over oracle-measured layers. One-tailed test ($H_1: r > 0$) at $\alpha = 0.05$, pre-registered threshold $r \geq 0.65$. Direction was pre-registered prior to running oracle sweeps.

\textbf{Metric agreement (P5):} Pearson correlation between erank and PR($W_0$). Threshold: $\rho \geq 0.80$.

\textbf{Hypothesis gate:} H-E1 is satisfied if $r \geq 0.65$ with $p < 0.05$ in $\geq 2/3$ model families (pre-registered). At present, only 1 of 3 families has oracle data; the gate is marked PENDING.
