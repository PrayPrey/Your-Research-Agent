# Overleaf LaTeX Project

Paper: **Where Does WGA Improvement Come From? Backbone vs. Head Robustification in ResNet-50 on Waterbirds**

## Compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Requirements

- ICML 2025 style files (`icml2025.sty`, `icml2025.bst`) — download from https://icml.cc/Conferences/2025/PaperInformation/StyleFiles
- Place style files in this directory alongside `main.tex`
