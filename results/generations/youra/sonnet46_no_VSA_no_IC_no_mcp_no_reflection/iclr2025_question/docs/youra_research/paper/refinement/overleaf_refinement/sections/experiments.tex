
Our experimental design is structured to answer four nested questions, each resolving one layer of ambiguity in the negative result:

\begin{itemize}
\item \textbf{Q1 (Primary):} Does SMC-NLI achieve AUROC > 0.60 on HaluEval QA with Llama-3-8B-Instruct?
\item \textbf{Q2 (Mechanism):} Does SMC-Embed achieve similar AUROC, ruling out NLI OOD as the primary failure mode?
\item \textbf{Q3 (Implementation):} Is the implementation correct, ruling out engineering error as a confound?
\item \textbf{Q4 (Distribution):} What is the per-label distribution of SMC scores, characterizing the mechanism failure?
\end{itemize}

Full methodology and implementation details are described in Section 3. Here we summarize the hardware setup and evaluation protocol specifics.

\textbf{Hardware:} $5\times$ NVIDIA H100 NVL (95GB VRAM per device), with the model loaded using \texttt{device\textbackslash \_map=''auto''}. Total inference: 10,000 forward passes for LLM sampling.

\subsubsection{Evaluation Protocol}

\textbf{Primary metric:} AUROC for binary hallucination classification, computed with \texttt{sklearn.metrics.roc\textbackslash \_auc\textbackslash \_score}. AUROC is threshold-free and appropriate for binary classification tasks \citep{Xiong2023Can}.

\textbf{Secondary metrics:}
\begin{itemize}
\item SMC-NLI standard deviation across questions (threshold: >0.05 for meaningful variation)
\item Per-label mean SMC-NLI (expected to differ between correct and hallucinated if the stochastic hallucination assumption holds)
\item ROC curves: visual confirmation of performance across all thresholds
\end{itemize}

\subsubsection{Baselines}

\textbf{Random classifier (AUROC=0.50):} The minimum meaningful threshold.

\textbf{SMC-Embed:} Internal control. If SMC-NLI fails due to NLI OOD, SMC-Embed should outperform it. Equal failure of both metrics indicates mechanism-level failure.

We do not compare against token-probability baselines \citep{Kadavath2022Language} because our evaluation protocol is strictly black-box: logit access would require white-box methods outside the scope of this investigation.
