## Local compilation

```bash
cd overleaf/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Overleaf upload

1. Zip this folder: `zip -r overleaf.zip overleaf/`
2. Upload to Overleaf → New Project → Upload
3. Download `icml2025.sty` from https://icml.cc/Conferences/2025/StyleAuthorInstructions
4. Upload `icml2025.sty` to the Overleaf project root
5. In `main.tex`: comment out the shim block and uncomment `\usepackage{icml2025}`
6. Change `\bibliographystyle{plainnat}` to `\bibliographystyle{icml2025}`
7. Compile

## Notes

- Local compilation uses `article` class + compatibility shims (no icml2025.sty required)
- `plainnat` bibliography style used locally; switch to `icml2025` on Overleaf
- All figures are PNG; pdflatex accepts PNG directly
