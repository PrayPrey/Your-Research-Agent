# Paper Summary: DAPO (P3)

**Title:** DAPO: An Open-Source LLM Reinforcement Learning System at Scale  
**Authors:** Yu et al. (ByteDance / Tsinghua)  
**arXiv:** 2503.14476 (2025)  
**Status:** [INFERRED] — MCP unavailable; summary from training knowledge

---

## Abstract
DAPO introduces a GRPO-based RL system for LLM post-training that addresses reward hacking, training instability, and entropy collapse. Open-source implementation for code and math RL post-training.

---

## Key Contributions
- GRPO (Group Relative Policy Optimization) as PPO replacement: no critic network needed
- Addresses reward hacking via clip-higher training (asymmetric clipping)
- Token-level policy gradient instead of sequence-level (better gradient signal)
- Dynamic sampling: oversample from models where reward variance is high
- Open-source implementation (trl-compatible) for reproducible RL post-training

---

## Methodology
- RL algorithm: GRPO variant (group of N completions, relative reward assignment)
- Reward signal: Binary pass/fail for code tasks (same as prior work)
- Training: Code and math reasoning tasks
- Key innovations: clip-higher, token-level loss, dynamic oversampling
- No reward granularity study — reward design not the focus

---

## Experiments & Results
- Code performance: competitive with PPO-based methods with less compute
- Stability: reduced reward collapse during training vs. standard GRPO
- Efficiency: 2-3x faster than PPO (no critic network)
- Ablation: each component (clip-higher, token-level, dynamic sampling) contributes

---

## Limitations & Gaps
- Still uses binary reward for code tasks — no partial credit exploration
- Scale study limited to medium models (7B-class)
- Algorithm paper, not reward formulation paper — does not address reward granularity

---

## Relevance to Research Gap
**Algorithm backbone.** DAPO's GRPO implementation is the recommended RL algorithm for the reward granularity ablation — simpler than PPO, more stable, open-source. The key insight: GRPO naturally allows testing reward granularity because group-relative reward assignment scales to continuous reward signals (ratio, similarity) as well as binary. This paper justifies using GRPO as the RL algorithm when varying reward signals.
