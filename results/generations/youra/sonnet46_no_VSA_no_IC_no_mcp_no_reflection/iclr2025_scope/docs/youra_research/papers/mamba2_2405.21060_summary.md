# Paper Summary: Mamba-2 — Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality
**arXiv:** 2405.21060 | **Authors:** Tri Dao, Albert Gu | **Year:** 2024

---

## Abstract
Mamba-2 establishes Structured State Space Duality (SSD): SSMs with scalar-times-identity A matrices are mathematically equivalent to a form of linear attention. This unification simplifies the A matrix from a full diagonal to a scalar per head, dramatically simplifying the state-aware adaptation problem.

## Architecture
- **SSD layer:** A is now a scalar per SSM head (not per channel as in Mamba-1); A = α·I where α ∈ ℝ
- **Simplified state dynamics:** h_t = α·h_{t-1} + B_t·x_t; y_t = C_t·h_t
- **Multi-head SSM:** Groups of channels share a scalar A — reduces A parameters from d_model to num_heads
- **Linear layers:** Same in_proj, out_proj structure as Mamba-1; dt_proj removed (Δ integrated differently)

## Methodology
- SSD algorithm: O(n·d_state) space, supports both recurrent and parallel computation
- Attention equivalence: SSD = linear attention with data-dependent decay
- Hybrid: Mamba-2 layers can be freely mixed with standard attention (Jamba-style)

## Experiments & Results
- Mamba-2-2.7B matches Mamba-1.4B and Transformer++ at comparable parameter count on Pile
- Training: 2-3× faster than Mamba-1 due to simplified scan; equivalent downstream accuracy
- State size d_state=128 is default (vs 16 in Mamba-1)

## Relevance to State-Aware PEFT
- **Key simplification:** Scalar A per head means state-aware PEFT is trivially applicable via IA³-style learned scalar multiplier: α_adapted = α_pretrained · (1 + s) where s is a learned scalar per head
- **Parameter count:** num_heads learned scalars (e.g., 16-64 total) — essentially free in parameter budget
- **B and C:** Still d_model→d_state projections (nn.Linear) — LoRA applicable
- **Gradient stability:** Scalar A perturbation is bounded by clamping α ∈ (0,1) to maintain stability
- **Conclusion:** Mamba-2 is the IDEAL target for state-aware PEFT — scalar A enables the cleanest possible state adaptation experiment
