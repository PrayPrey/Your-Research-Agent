# Thor: Wielding Hammers to Integrate Language Models and Automated Theorem Provers

**arXiv ID:** 2205.10893  
**Authors:** Jiang, A. Q., Li, W., Tworkowski, S., Czechowski, K., et al.  
**Year:** 2022  
**Citations:** 148

## Key Contributions

- **Hybrid Architecture:** Integrates language models with automated theorem provers (hammers) for premise selection
- **Performance:** 39%→57% on PISA benchmark
- **Novel Finding:** 8.2% of problems solved by hybrid system that neither LLM nor automated prover solves independently
- **Approach:** Uses hammers for premise selection from large libraries, then LLM generates proof tactics

## Relevance to Research Question

Directly demonstrates LLM+automated prover integration effectiveness. Provides evidence that hybrid approaches outperform either component alone, addressing the core question of whether LLM guidance improves automated theorem proving.

**Critical Gap:** Thor reports "39%" as baseline but unclear if this is LM-only or prover-only performance - need pure non-LLM baseline for quantifying LLM contribution.
