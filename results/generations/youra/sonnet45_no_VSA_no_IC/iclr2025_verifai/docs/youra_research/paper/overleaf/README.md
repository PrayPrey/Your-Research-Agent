## Quick Start

Compile with pdflatex + bibtex:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Or use latexmk:

```bash
latexmk -pdf main.tex
```

## Dependencies

- **LaTeX distribution**: TeX Live 2023+ or MiKTeX
- **Required packages**: booktabs, amsmath, amsfonts, amssymb, graphicx, hyperref
- **ICML 2025 style**: icml2025.sty (download from ICML website if missing)

## ICML 2025 Style

The main.tex uses icml2025 document class. If icml2025.sty is unavailable:

1. Download from https://icml.cc/Conferences/2025/StyleAuthorInstructions
2. Place icml2025.sty in the same directory as main.tex
3. Or comment out `\usepackage{icml2025}` and use standard `\documentclass{article}`
