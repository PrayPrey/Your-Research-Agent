
We evaluate five sub-hypotheses on miniF2F Lean 4 test set (N=244 Olympiad-level problems). All experiments use Lean 4 proof checker for deterministic validation, 300s timeout, and identical Mathlib version. For H-M1 and H-M2, infrastructure validation used simplified problems to test methodology feasibility before full evaluation on real olympiad-difficulty data.

\subsubsection{4.1 Baseline Configuration (H-E1)}

\textbf{Prover:} lean-auto with Duper backend (deterministic hammer, breadth-first search over Mathlib premises)  
\textbf{Dataset:} miniF2F Lean 4 test set (N=244)  
\textbf{Timeout:} 300s per problem  
\textbf{Metrics:} Success rate (primary), tactic count per solved problem, error classification

\textbf{Expected outcome:} 15\% [10\%, 25\%] success, ~10 tactic evaluations/problem.

\subsubsection{4.2 NL Understanding Ablation (H-M1)}

\textbf{Design:} Paired comparison with NL-intact vs NL-ablated variants  
\textbf{NL ablation method:} Strip all docstrings and inline comments preserving formal statement structure  
\textbf{Dataset:} Infrastructure validation used simplified problems; full validation pending  
\textbf{Statistical test:} McNemar $\chi^2$ for paired binary outcomes, bootstrap 95\% CI  
\textbf{Gate criterion:} $\Delta \geq$ 25 percentage points AND p < 0.05

\textbf{Example ablation:} Remove ''For all prime p, prove $p^2$ - 1 is divisible by 24'' comment, retain formal statement structure.

\subsubsection{4.3 Proof Depth Filtering (H-M2)}

\textbf{Design:} Post-hoc stratification by tactic count  
\textbf{Stratification:} Full dataset (all depths) vs Shallow subset ($\leq 3$ tactics)  
\textbf{Dataset:} Infrastructure validation used simplified problems yielding 96.3\% shallow-solvable distribution (unrealistic for olympiad mathematics)  
\textbf{Statistical test:} McNemar $\chi^2$ for paired comparison  
\textbf{Gate criterion:} $\Delta \geq$ 5 percentage points AND p < 0.05

\textbf{Limitation:} Real miniF2F depth distribution (literature reports median=9 tactics) likely yields larger depth effects than simplified validation data.

\subsubsection{4.4 Corpus Pattern Matching (H-M3)}

\textbf{Design:} Random tactic sampling from Mathlib distribution  
\textbf{Sampler:} Draw tactics from Mathlib corpus with empirical frequency weights  
\textbf{Budget:} 15 tactic evaluations/problem  
\textbf{Dataset:} Proof-of-concept completed on simplified problems (48\% success); full validation pending  
\textbf{Gate criterion:} Success $\in$ [18\%, 25\%]

\subsubsection{4.5 Tactic Budget Control (H-C1)}

\textbf{Design:} Post-hoc statistical analysis on H-E1 solved problems  
\textbf{Metrics:} Mean tactic count $\mu$, standard deviation $\sigma$, coefficient of variation CV = $\sigma /\mu$  
\textbf{Gate criterion:} CV $\leq$ 1.0  
\textbf{Budget recommendation:} $\mu + 1\sigma$ (captures ~90\% of baseline strategies)

\subsubsection{4.6 Implementation Details}

\textbf{Infrastructure:} Lean 4.15.0, Mathlib 4 (Lean 4 compatible), miniF2F Lean 4 port  
\textbf{Compute:} 32-core CPU, 128GB RAM  
\textbf{Tactic extraction:} Parse Lean proof checker output for tactic count (deterministic)  
\textbf{Reproducibility:} All experiment configurations, Lean code, random seeds documented
