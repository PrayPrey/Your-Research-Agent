## Verification Protocol

Train 350M and 1B models with three conditions:
1. SFT baseline (no execution feedback)
2. Binary feedback (1 bit: pass/fail)
3. Error-type feedback (2.3 bits: top-5 Python exceptions)

Evaluate on HumanEval using BigCode harness. Compute absolute improvement (Binary - SFT) and relative retention (Binary - SFT) / (Error-type - SFT). Check dual threshold: ≥8 pp AND ≥80%.

Run 3 seeds per condition, report mean ± std. Statistical test: two-sample t-test with Bonferroni correction (α=0.0167).
