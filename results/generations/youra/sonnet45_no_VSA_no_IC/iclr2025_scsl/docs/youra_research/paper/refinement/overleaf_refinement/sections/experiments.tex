
\subsubsection{4.1 Validation Strategy: Synthetic + Proof-of-Concept}

Real Waterbirds experiments require GPU compatibility resolution (PyTorch 2.1+ for H100 sm\_90 architecture) or CPU training (estimated 70-90 GPU hours). We validate methodology via:

\begin{enumerate}
\item Synthetic validation (h-e1, h-m-integrated): Proves pipeline correctness and mechanism plausibility using controlled synthetic gradients.
\item Proof-of-concept (h-m-mitigate): Demonstrates mitigation effectiveness on MNIST+Color toy dataset.
\end{enumerate}

Synthetic validation proves: Code executes without errors, statistical tests compute correctly, mechanism holds when gradient differences exist. Cannot prove: Real minority gradients exhibit abnormality, real spatial regularization improves worst-group accuracy.

Epistemic status: Methodology validated (HIGH confidence), real-world empirical claims pending (LOW confidence until real validation).

\subsubsection{4.2 Hypothesis Breakdown}

Three sub-hypotheses test different aspects:

\textbf{h-e1 (Detection - MUST\_WORK gate):} Gradient abnormality methodology differentiates minority vs majority patterns when synthetic gradients exhibit controlled near-zero rate differences. Success: Divergence $\geq 0.2$, p<0.01, Cohen's $d\geq 0.8$. Failure action: Abandon gradient abnormality approach.

\textbf{h-m-integrated (Mechanism - MUST\_WORK gate):} Three experiments validate causal chain Steps 1-3:  
\begin{itemize}
\item Exp1: GAIA divergence correlates with worst-group accuracy (|$\rho$|>0.7, p<0.05)
\item Exp2: Background swap reduces GAIA-Z by $\geq 30$\% (paired t-test)
\item Exp3: Minority accuracy $\geq 60$\% (GradCAM validity check)
\end{itemize}
Failure action: Mechanism falsified, redesign regularization.

\textbf{h-m-mitigate (Mitigation - SHOULD\_WORK gate):} Spatial regularization improves worst-group accuracy on MNIST+Color by $\geq 10$\% over ERM. Success: Worst-group accuracy improvement $\geq 10$\%, no catastrophic accuracy drop. Failure action: Proof-of-concept ineffective, defer mitigation to future work.

\subsubsection{4.3 h-e1: Synthetic Gradient Generation}

Mimic Waterbirds test set structure (5794 samples, 4 groups) with controlled GAIA-Z properties.

\textbf{Generation process:}  
\begin{enumerate}
\item Majority samples (n=2900 per group, 90\%): Sample gradients from Normal(0, 0.5) with 60\% near-zero elements (simulates sparse gradients)
\item Minority samples (n=500 per group, 10\%): Sample gradients from Normal(0, 1.0) with 30\% near-zero elements (simulates dense gradients)
\item Near-zero threshold: $\epsilon = 10^{-5}$
\end{enumerate}

Expected GAIA-Z scores: Majority mean $\approx$ 0.60, Minority mean $\approx$ 0.30, Divergence 0.30 ($\geq 0.2$ criterion).

Validation: Synthetic data proves pipeline can differentiate patterns when differences exist. Does not prove real Waterbirds gradients exhibit this property.

\subsubsection{4.4 h-m-integrated: Mechanism Validation}

\textbf{Experiment 1 (Correlation-WGA-GAIA Link):} Generate 2 synthetic models with different worst-group accuracy (50\%, 90\%). Assign GAIA divergence inversely proportional to worst-group accuracy. Compute Pearson correlation. Expected: |$\rho$| > 0.7, p<0.05.

\textbf{Experiment 2 (Background Augmentation):} 100 synthetic minority samples with original GAIA-Z scores (30\% near-zero rate). Simulate background swap: increase near-zero rate to 60\% (mimics majority pattern). Paired t-test. Expected: Mean reduction $\geq 30$\%, p<0.05, Cohen's $d\geq 0.5$.

\textbf{Experiment 3 (Minority Accuracy Check):} Assign 68\% minority accuracy (>60\% threshold). Verify GradCAM validity assumption (A1).

\subsubsection{4.5 h-m-mitigate: MNIST+Color Proof-of-Concept}

\textbf{Dataset:} MNIST digits with background color (red/blue). Spurious correlation: 90\% (digit 0-4 on red, 5-9 on blue in training). Test: Balanced (50\% correlation). Subsample: 10\% of MNIST (6000 train, 1000 test) for smoke test speed.

\textbf{Baselines:} ERM (standard cross-entropy), Spatial Regularization (L\_CE + $\lambda$ * L\_spatial).

\textbf{Configuration:} Architecture: 3-layer CNN. Optimizer: Adam. Learning rate: 1e-3. Batch size: 64. Epochs: 2 (smoke test). $\lambda _init$: 0.01. Percentile: 75. Seed: 42.

\textbf{Metrics:} Worst-group accuracy (minimum accuracy across 4 groups), Average accuracy (mean across all samples).

Success criterion: Worst-group accuracy $\geq$ baseline + 10\%, average accuracy drop $\leq 2$\%.

\textbf{Limitations:}  
L1 (Smoke test only): 1 seed, 2 epochs (not 5 seeds $\times$ 50 epochs). No statistical significance testing.  
L2 (Toy dataset): MNIST color spurious simpler than Waterbirds backgrounds.  
L3 (No GroupDRO comparison): ERM baseline only.
