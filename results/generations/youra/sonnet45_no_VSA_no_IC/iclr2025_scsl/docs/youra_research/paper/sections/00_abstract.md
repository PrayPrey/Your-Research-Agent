# Abstract

Gradient attribution fails to detect unknown spurious correlations — practitioners cannot identify shortcuts using saliency maps alone [@adebayo2022post]. We extend GAIA (Gradient Abnormality for OOD Detection) [@chen2023exploring] to detect spurious correlations within in-distribution data via gradient *process* abnormality, not attribution. Minority samples (e.g., waterbirds on land) exhibit gradient scattering when spurious shortcuts conflict with core features. We validate methodology via synthetic experiments and proof-of-concept tests: (1) gradient abnormality pipeline (GradCAM → GAIA-Z → statistical testing) differentiates minority vs majority patterns in controlled synthetic data (divergence 0.30, p<0.0001, Cohen's d=198.75), (2) synthetic causality tests show background swap reduces abnormality by 39.4% (p<0.001, d=2.96), supporting spurious-conflict mechanism, and (3) MNIST+Color smoke test (1 seed, 2 epochs) demonstrates spatial gradient regularization improves WGA by +23pp (78% vs 55%) without catastrophic accuracy drop. **All validation results are synthetic or minimal proof-of-concept** — real Waterbirds experiments require GPU compatibility resolution (PyTorch 2.1+ for H100 sm_90 support) or CPU training (~70-90 GPU hours). We position this as a Tier 3 methodology contribution with clear path to Tier 2 empirical validation, complementing embedding-based approaches (SCER) by operating on gradient space.
