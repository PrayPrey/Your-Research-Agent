# Paper Summary: Metadata Conflicts and DataCite Completeness (Strecker 2026)

**arXiv ID:** 2603.25468  
**Authors:** Dorothea Strecker  
**Citations:** 0 (new)

## Key Contributions
- First analysis of metadata conflicts across disciplinary repositories
- Two conflict types identified: implementation conflicts + inter-standard conflicts
- Impact on DataCite metadata completeness measured across 8 repositories

## Methodology
- Comparative analysis of 8 geoscience/social science repositories
- Metadata conflict taxonomy development
- DataCite completeness scoring

## Experiments & Results
- Both implementation AND inter-standard conflicts contribute to incomplete metadata
- Workflows/decisions drive implementation conflicts
- Inherent schema differences drive inter-standard conflicts
- Metadata completeness is multifaceted (not single-score problem)

## Potential Relevance
- **Gap 3:** Cross-platform schema differences → completeness variability
- **Design insight:** Conflicts arise from both technical (schema) and human (workflow) factors
- **Measurement:** Completeness requires multi-dimensional assessment
