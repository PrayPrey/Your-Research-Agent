# Paper Summary: Machine Learning Pipelines - Provenance, Reproducibility, FAIR (Samuel et al. 2020)

**arXiv ID:** 2006.12117  
**Authors:** Sheeba Samuel, F. Löffler, Birgitta König-Ries  
**Citations:** 52

## Key Contributions
- End-to-end reproducibility framework for ML pipelines
- FAIR data principles applied to ML workflows
- ProvBook tool for provenance capture in Jupyter Notebooks

## Methodology
- Provenance tracking via ProvBook extension
- FAIR assessment of ML workflow documentation
- Case studies with real ML pipelines

## Experiments & Results
- Factors beyond source code/datasets influence reproducibility
- Provenance capture improves workflow documentation quality
- FAIR practices essential for reproducible ML pipelines
- Jupyter integration enables lightweight provenance collection
