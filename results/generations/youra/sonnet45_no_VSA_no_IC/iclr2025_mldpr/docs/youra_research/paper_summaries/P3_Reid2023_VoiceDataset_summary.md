# Paper Summary: Right the docs - Voice Dataset Documentation (Reid & Williams 2023)

**arXiv ID:** 2303.10721  
**Authors:** Kathy Reid, Elizabeth T. Williams  
**Citations:** 3

## Key Contributions
- First characterization of voice dataset documentation (VDD) shortcomings
- Interview study (13 ML practitioners) + rubric analysis (9 datasets)
- Fragmented codification hinders dataset comparison/combination

## Methodology
- Semi-structured interviews with ML practitioners using voice datasets
- Documentation rubric applied to 9 major voice datasets
- Gap analysis between practitioner needs vs actual documentation

## Experiments & Results
- VDDs inadequate for bias reduction efforts
- Fragmented documentation prevents cross-dataset comparison
- Need for standardized documentation formats
- Missing provenance, demographic metadata, recording conditions

## Potential Relevance
- **Gap 1:** Domain-specific documentation completeness patterns
- **Gap 2:** Reconstruction challenges due to missing technical specifications
- **Gap 3:** Lack of standardized schema leads to fragmentation
