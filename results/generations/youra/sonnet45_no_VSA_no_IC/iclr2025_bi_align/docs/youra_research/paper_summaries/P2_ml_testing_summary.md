# Paper Summary: Machine Learning Testing Survey (P2)

**Title:** Machine Learning Testing: Survey, Landscapes and Horizons  
**Authors:** J Zhang, M. Harman, Lei Ma, Yang Liu  
**Year:** 2019  
**arXiv ID:** 1906.10742  
**Citations:** 899

---

## Key Contributions

Comprehensive survey of **144 ML testing papers** establishing testing workflow foundations. Covers properties (correctness, robustness, fairness), components, workflow, and test generation/evaluation.

---

## Methodology

**Systematic literature review** across:
- Test property categories (functional, non-functional)
- ML component testing (data, model, framework)
- Workflow testing approaches
- Test generation and evaluation techniques

Establishes taxonomy for ML system testing.

---

## Experiments & Results

Survey identifies **key testing dimensions:**
- **Property-based testing:** Correctness, robustness, fairness, interpretability
- **Component testing:** Data quality, model validation, framework reliability
- **Workflow testing:** End-to-end pipeline validation
- **Test generation:** Automated test case creation, coverage metrics

---

## Potential Relevance

**Research gap alignment:** Provides **foundational testing taxonomy** applicable to research workflow validation. Distinguishes between component testing (individual phases) and workflow testing (phase transitions).

**Adaptation potential:** Property-based testing (correctness, robustness) maps to constraint validation. Workflow testing principles apply to multi-phase research pipelines.
