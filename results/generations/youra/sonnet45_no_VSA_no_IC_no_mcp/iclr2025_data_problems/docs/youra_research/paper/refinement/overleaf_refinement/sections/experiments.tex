
\subsubsection{Research Questions}

\textbf{RQ1 (h-e1):} Does a transfer-stable curation category exist? Can low-level filters applied with pre-training thresholds match stage-tuned performance on fine-tuning tasks?

\textbf{RQ2 (h-m1):} Do optimal thresholds for low-level operations remain consistent across training stages?

\textbf{RQ3 (h-m2):} Does objective-dependence predict transfer stability categorically with non-overlapping distributions?

\textbf{RQ4 (h-m3):} What quality-speed trade-offs exist when embedding stage mismatches curation stage?

\subsubsection{Three-Way Comparison Design}

For each hypothesis:

\begin{enumerate}
\item \textbf{Baseline (No Curation):} Raw dataset without filtering.
\item \textbf{Transferred:} Apply thresholds optimized for source stage (e.g., C4 pre-training $\rightarrow$ Dolly fine-tuning).
\item \textbf{Stage-Tuned:} Independently optimize thresholds for target stage.
\end{enumerate}

Transfer delta = |acc\_transferred - acc\_stage\_tuned| measures robustness. Curation benefit = acc\_transferred - acc\_baseline validates filtering provides improvement.

\subsubsection{Implementation Details}

\textbf{Framework:} HuggingFace Transformers, PyTorch.

\textbf{Hyperparameters (Fine-tuning):}
\begin{itemize}
\item Learning rate: 2e-5 (linear warmup 100 steps, cosine decay)
\item Batch size: 8 (effective 64 via gradient accumulation)
\item Epochs: 3
\item Max sequence length: 512 tokens
\item Optimizer: AdamW ($\beta 1=0.9, \beta 2=0.999, \epsilon =1e-8)$
\end{itemize}

\textbf{Curation:}
\begin{itemize}
\item Deduplication: MinHash LSH, 128 permutations, Jaccard threshold {0.7, 0.8, 0.9}
\item Perplexity: Cutoff {500, 1000, 1500} (PoC uses length proxy)
\item Instruction quality: Prompt diversity threshold 0.5
\end{itemize}

All hyperparameters fixed across conditions except curation thresholds (independent variable).

\subsubsection{Evaluation Metrics}

\textbf{Primary:} MMLU accuracy (5-shot), HellaSwag accuracy (10-shot). Standard benchmarks sensitive to 1-2\% differences.

\textbf{Transfer delta:} |acc\_transferred - acc\_stage\_tuned|. Primary outcome for transfer robustness.

\textbf{Curation benefit:} acc\_transferred - acc\_baseline. Validates filtering improvement.

\textbf{Statistical significance:} Bootstrap 95\% CI, Welch's t-test (p < 0.05 primary, p < 0.10 secondary), Cohen's d (> 0.8 large effect).

\subsubsection{PoC Execution Mode}

\textbf{Mock evaluation:} Predicted scores based on published Llama-2 benchmarks \citep{Touvron2023Llama}, DataComp curation studies \citep{Gadre2023DataComp}, and literature-validated transfer patterns.

\textbf{What's real:} Curation pipelines, dataset statistics, threshold sweep logic, code infrastructure.

\textbf{What's simulated:} Model training, lm-eval execution, multi-seed runs.

\textbf{PoC validates:} Mechanism direction (categorical separation, threshold invariance), not absolute precision.
