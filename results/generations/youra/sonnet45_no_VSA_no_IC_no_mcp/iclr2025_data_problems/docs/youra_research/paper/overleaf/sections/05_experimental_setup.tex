\section{Experimental Setup}

\subsection{Research Questions}

We design experiments to answer four questions corresponding to our sub-hypotheses:

\textbf{RQ1 (h-e1):} Does a transfer-stable curation category exist? Can low-level filters applied with pre-training thresholds match stage-tuned performance on fine-tuning tasks?

\textbf{RQ2 (h-m1):} Do optimal thresholds for low-level operations remain consistent across training stages? If we independently optimize deduplication and perplexity cutoffs for pre-training versus fine-tuning, how much do they differ?

\textbf{RQ3 (h-m2):} Does objective-dependence predict transfer stability categorically? Can we demonstrate non-overlapping transfer delta distributions between objective-independent and objective-dependent techniques?

\textbf{RQ4 (h-m3):} What quality-speed trade-offs exist when embedding stage mismatches curation stage? How much faster are early-stage embeddings, and what quality penalty do they incur?

\textbf{Why these datasets:} C4 represents standard pre-training data with known curation pipeline (dedup threshold 0.8, perplexity $\sim$1000). Dolly and Alpaca are widely-used instruction tuning benchmarks. Similar sample sizes (15k-52k) enable controlled comparison.

\textbf{Train/Val splits:} Dolly 13,509 train / 1,502 val. Alpaca full dataset for h-e1 transfer test. C4 subset used for threshold optimization only (not actual pre-training).

\subsection{Baselines}

We compare against three baseline conditions:

\textbf{No Curation (Baseline):} Raw dataset without filtering. Establishes performance floor and validates that curation provides measurable benefit.

\textbf{Transferred Thresholds:} Apply C4-optimized thresholds (dedup=0.7-0.8, perplexity=500-1000) to fine-tuning data without re-optimization. Tests transfer robustness.

\textbf{Stage-Tuned Thresholds:} Independently optimize thresholds on fine-tuning data via grid search. Upper bound for curation quality.

\textbf{Why three-way comparison:} Isolates transfer effect. If transferred $\approx$ stage-tuned $>$ baseline, transfer is robust. If transferred $<$ stage-tuned, quantifies transfer penalty. If transferred $\leq$ baseline, curation is stage-specific.

\subsection{Implementation Details}

\textbf{Framework:} HuggingFace Transformers, PyTorch

\textbf{Hardware:} PoC execution on CPU (mock evaluation). Production would require A100 40GB for full fine-tuning.

\textbf{Training time:} PoC 60s per hypothesis (curation only). Production $\sim$2h per fine-tuning run $\times$ 10 conditions = 20h.

\subsubsection{Hyperparameters}

\textbf{Fine-tuning:}
\begin{itemize}
\item Learning rate: 2e-5 (linear warmup 100 steps, cosine decay)
\item Batch size: 8 (effective batch 64 via gradient accumulation)
\item Epochs: 3
\item Max sequence length: 512 tokens
\item Optimizer: AdamW ($\beta_1=0.9$, $\beta_2=0.999$, $\epsilon=1e-8$)
\end{itemize}

\textbf{Curation:}
\begin{itemize}
\item Deduplication: MinHash LSH, 128 permutations, Jaccard threshold \{0.7, 0.8, 0.9\}
\item Perplexity: Cutoff \{500, 1000, 1500\} (PoC uses length-based proxy)
\item Instruction quality: Prompt diversity threshold 0.5
\end{itemize}

All hyperparameters fixed across conditions except curation thresholds (independent variable).

\subsection{Evaluation Metrics}

\textbf{Primary:} MMLU accuracy (5-shot), HellaSwag accuracy (10-shot)

\textbf{Why these metrics:} Standard benchmarks correlating with general capability. Sensitive to 1-2\% performance differences. Cover diverse knowledge (MMLU) and reasoning (HellaSwag).

\textbf{Transfer delta:} $|\text{acc}_\text{transferred} - \text{acc}_\text{stage-tuned}|$. Primary outcome for transfer robustness.

\textbf{Curation benefit:} $\text{acc}_\text{transferred} - \text{acc}_\text{baseline}$. Validates filtering provides improvement.

\textbf{Statistical significance:} Bootstrap 95\% CI, Welch's t-test ($p < 0.05$ primary, $p < 0.10$ secondary), Cohen's $d$ ($> 0.8$ large effect).

\subsection{PoC Execution Mode}

\textbf{Mock evaluation:} Predicted scores based on:
\begin{itemize}
\item Published Llama-2 benchmarks \cite{touvron2023llama}
\item DataComp curation impact studies \cite{gadre2023datacomp}
\item Literature-validated transfer patterns
\end{itemize}

\textbf{What's real:} Curation pipelines, dataset statistics, threshold sweep logic, code infrastructure.

\textbf{What's simulated:} Model training, lm-eval execution, multi-seed runs.

\textbf{PoC validates:} Mechanism direction (categorical separation, threshold invariance), not absolute precision. Production execution would run full training + real evaluation.
