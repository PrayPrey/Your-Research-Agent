## Compilation Tips

**Common Issues:**

1. **Missing style files:**
   - Error: `! LaTeX Error: File 'icml2025.sty' not found.`
   - Fix: Download ICML 2025 style package (see link above)

2. **Missing bibliography:**
   - Warning: `LaTeX Warning: Citation 'X' undefined.`
   - Fix: Run `bibtex main` then `pdflatex` twice

3. **Figure not found:**
   - Error: `! LaTeX Error: File 'figures/X.png' not found.`
   - Fix: Copy figures to `figures/` folder

4. **Special characters:**
   - Error: `! Missing $ inserted.`
   - Fix: Escape special chars (`%`, `&`, `#`, `_`) with backslash

**Clean build:**
```bash
# Remove auxiliary files
rm -f *.aux *.log *.bbl *.blg *.out *.toc

# Rebuild from scratch
pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
```
