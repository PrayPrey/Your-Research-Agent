## Compilation Instructions

### Local Compilation

1. Ensure pdflatex and bibtex are installed
2. Run the following commands:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

3. Output PDF will be `main.pdf`
