
\subsubsection{Datasets}

\textbf{Benchmark Paper Corpus:} 20 diverse benchmarks stratified across modalities:

\begin{itemize}
\item \textbf{Vision (8):} ImageNet, COCO, Cityscapes, MNIST, CIFAR-10, PASCAL VOC, OpenImages, ADE20K
\item \textbf{Language (7):} SQuAD, WMT14, GLUE, WikiText-103, Natural Questions, WMT16, BoolQ
\item \textbf{Audio (3):} LibriSpeech, Common Voice, TIMIT
\item \textbf{Multimodal (2):} VQA v2, MS-COCO Captions
\end{itemize}

Benchmarks are selected with $\geq 50$ citations to ensure sufficient usage data. Stratified sampling ensures coverage across major modalities.

\textbf{Citation Data:} Extracted via Semantic Scholar API for 2015-2024 papers citing selected benchmarks. Historical split: pre-2023 for training, 2023-2024 for test.

\textbf{Synthetic Citation Contexts (H-E1):} 100 template-generated validation claims vs baseline mentions for SciBERT classifier training.

\subsubsection{Baselines}

\textbf{Random Baseline:} Random assignment of benchmarks to coverage families. Expected citation overlap $\leq 50$\%.

\textbf{Citation-Count Baseline:} Rank by popularity (total citations).

\textbf{Manual Expert Review:} Gold standard for accuracy but requires weeks per hypothesis (not scalable).

\subsubsection{Evaluation Metrics}

\textbf{H-M1 (Feature Extraction):} Cohen's kappa for categorical features (task, modality, metrics), ICC for continuous (dataset size). Target: kappa >0.80.

\textbf{H-M2 (Clustering Quality):} Intra-family cosine similarity, silhouette score, modularity on citation network. Target: similarity $\geq 0.60$.

\textbf{H-M3 (Prediction Accuracy):} Jaccard similarity of citation sets within families. Target: >70\% with p<0.05 vs random.

\textbf{H-E1 (Classification):} Precision/recall on held-out synthetic test set. Target: precision >85\%.

\subsubsection{Implementation Details}

\begin{itemize}
\item \textbf{Embeddings:} SentenceBERT (all-MiniLM-L6-v2) for benchmark descriptions
\item \textbf{Clustering:} K-means with $k\in {2,4,6,8}$, selected via silhouette score (optimal k=4)
\item \textbf{Citation Classifier:} SciBERT fine-tuned on synthetic data (80/20 train/test split)
\item \textbf{Statistical Testing:} Permutation test (1000 iterations) for citation overlap significance
\end{itemize}
