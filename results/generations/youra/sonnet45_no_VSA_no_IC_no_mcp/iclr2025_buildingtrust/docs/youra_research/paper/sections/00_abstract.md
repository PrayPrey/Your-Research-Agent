# Abstract

LLM benchmark evaluation produces aggregate accuracy scores without explaining individual failures, blocking targeted correction strategies. When models fail factual questions, practitioners apply retrieval-augmented generation (RAG) or chain-of-thought (COT) prompting uniformly, missing opportunities to match interventions to root causes. We demonstrate that attention entropy over entity spans provides a diagnostic signal distinguishing entity-substitution errors from non-entity failures. Entity-substitution errors exhibit near-zero entropy (mean = 0.062) — the model deterministically attends elsewhere — while non-entity errors show diffuse attention (mean = 0.300). This pattern enables threshold-based classification with 86.7% accuracy on GPT-2 TruthfulQA failures (p < 0.001, Cohen's d = -1.13). Zero-entropy entity-errors (60% of cases) reveal precision errors (focused-but-wrong attention), grounding matched correction where entity-error routes to RAG (retrieve correct entity) rather than COT (reasoning decomposition). Mock validation shows matched routing achieves +24 percentage point improvement over mismatched routing, demonstrating pipeline feasibility pending real-world deployment. Our framework scales interpretability from manual analysis (10-20 examples in prior work) to automated diagnostic routing (73 processed samples), transforming benchmark evaluation from aggregate scoring to actionable failure diagnosis for targeted LLM reliability improvement.
