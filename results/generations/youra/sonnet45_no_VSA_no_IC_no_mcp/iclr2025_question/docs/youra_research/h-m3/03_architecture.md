## Implementation Notes

### Key Constraints
- No ML training (deterministic rule-based classifier)
- Reuse validated k from h-m1 (r ≥0.7 prerequisite)
- Full corpus validation (all 30 hypotheses, no train/test split)
- Statistical rigor (binomial test p <0.05 required)

### Expected Runtime
- Data loading: <1s
- Classification: <1s (deterministic, no training)
- Evaluation: <1s
- Visualization: <5s
- Total: <10s

### Success Validation
```python

assert accuracy_gate1 > 0.80, "Must exceed 80% threshold"
assert p_value < 0.05, "Must be statistically significant"
```

## Subtask Breakdown

### A-1: Data Loading (Complexity: 6)

**Subtasks:**
1. Create `ViabilityCorpusLoader` class (2)
   - Load CSV from h-m1 path
   - Validate required columns: O_10, O_full, hypothesis_type, threshold
2. Create `ScalingFactorLoader` class (2)
   - Load k from h-m1/results/scaling_factor.json
   - Validate k >0
3. Schema validation (1)
   - Check numeric types for O_10, O_full
   - Check no missing values
4. Integration test (1)
   - Load corpus, verify 30 rows
   - Load k, verify value

**Deliverables:**
- `data_loader.py`
- `scaling_loader.py`
- Test passing on actual h-m1 data

---

### A-2: Classifier Implementation (Complexity: 8)

**Subtasks:**
1. `RandomBaseline` class (2)
   - 50% probability for each class
   - Fixed seed=42 for reproducibility
2. `Gate1ViabilityClassifier.predict` (3)
   - Compute O_pred = O_10 * k
   - Compare to threshold (default 0.10)
   - Return ("viable"|"non-viable", O_pred)
3. `Gate1ViabilityClassifier.predict_batch` (2)
   - Vectorized prediction for array
   - Return predictions list and O_pred list
4. Unit tests (1)
   - Test edge cases (O_10=0, threshold boundary)

**Deliverables:**
- `classifier.py`
- Unit tests passing

---

### A-3: Evaluation Module (Complexity: 10)

**Subtasks:**
1. Accuracy computation (2)
   - sklearn.metrics.accuracy_score
   - (TP + TN) / Total
2. Confusion matrix (3)
   - sklearn.metrics.confusion_matrix
   - Extract TP, TN, FP, FN counts
   - Map to viable/non-viable labels
3. Binomial test (3)
   - scipy.stats.binom_test
   - Test n_correct vs null_p=0.5
   - Alternative='greater' for one-sided test
4. Metrics aggregation (2)
   - Combine all metrics into dict
   - Include baseline vs Gate 1 comparison

**Deliverables:**
- `evaluator.py`
- Test on synthetic data
