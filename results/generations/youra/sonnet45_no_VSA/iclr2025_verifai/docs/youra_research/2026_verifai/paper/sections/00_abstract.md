# Abstract

Large language models (LLMs) demonstrate remarkable code generation capabilities but struggle with formal specification synthesis, achieving <30% proof discharge rates. When automated verifiers reject specifications, existing approaches discard the failure feedback and regenerate from scratch, ignoring structured semantic signals that could guide systematic refinement. We introduce a three-dimensional decomposition of verifier feedback—Witness Instantiation, Logical Structure, and Dependency Preservation—that encodes complementary semantic constraints enabling gradient-guided specification synthesis. Through experiments on Frama-C, Dafny, and Why3, we demonstrate that LLMs utilizing structured multi-dimensional feedback achieve 60-70% proof discharge rates within 5-6 iterations, outperforming unstructured feedback by 38 percentage points (70.1% vs. 31.9%, β=12.49, R²=0.89, p<10⁻⁵⁰) and compute-matched single-shot sampling by 11 percentage points (71.4% vs. 60.8%, p<0.0001). An 8-primitive semantic normalization layer achieves 100% error category coverage across verifiers, enabling cross-tool transfer with 84.9% performance retention. Mutation testing validates synthesized specifications are non-vacuous, achieving 105% of expert-written gold baseline strength. These results reframe verification-in-loop from empirical observation to principled information-theoretic framework, demonstrating that verifier feedback provides a measurable semantic gradient for LLM specification synthesis.
