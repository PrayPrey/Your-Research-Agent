# Abstract

Large language models achieve impressive accuracy on code generation benchmarks, yet their confidence scores are dramatically miscalibrated. To our knowledge, we quantify this for the first time, measuring Expected Calibration Error (ECE) of 0.53 for Code Llama 7B on MBPP—3-6× higher than image classifiers. This extreme miscalibration prevents effective resource allocation in agentic code generation systems, where decisions about iteration and execution depend on knowing when the model is likely correct. We apply temperature scaling, a post-hoc calibration method, and achieve 84.8% ECE reduction (0.53 → 0.08) while preserving pass@1 accuracy. To our knowledge, our findings establish the first ECE benchmark for code generation and demonstrate that code generation exhibits substantially higher baseline miscalibration than discriminative tasks, creating more room for calibration improvement. This work provides the foundation for future confidence-based iteration control policies in agentic systems, where calibrated confidence enables principled decisions about when to iterate, execute, or stop.
