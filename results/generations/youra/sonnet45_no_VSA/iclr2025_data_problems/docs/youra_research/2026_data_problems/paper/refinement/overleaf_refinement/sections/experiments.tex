
This section describes the simulation design that enables validation of the experimental protocol.

\subsubsection{Simulation Data Generation}

Mock data was generated with the following characteristics:

\textbf{Logit representation:} Binary logits for two classes (correct/incorrect). Real Code Llama outputs would have vocabulary-sized logits (~32K dimensions), but binary representation suffices to test optimization convergence and ECE computation.

\textbf{Baseline confidence distribution:} Concentrated in [0.9, 1.0] to reflect overconfidence. This is consistent with observations in Kadavath et al. (2022) that language models overestimate correctness.

\textbf{Ground truth assignment:} Binary correctness labels (0 or 1) assigned with systematic mismatch from confidence levels, creating high baseline ECE. For example, predictions with confidence 0.95 are assigned accuracy ~0.40, producing calibration error of ~0.55 in high-confidence bins.

\textbf{Sample sizes:} 200 calibration samples, 195 validation samples (matching MBPP split design).

\subsubsection{Validation Metrics}

\textbf{Primary:} ECE before and after calibration, ECE reduction percentage
\textbf{Secondary:} Pass@1 accuracy (should be unchanged), optimization convergence (NLL trajectory), per-bin calibration error

\subsubsection{Implementation}

Code structure:
\begin{verbatim}
h-e1-temp-scaling/
├── config.py               (Experiment configuration)
├── simulate_experiment.py  (Simulation mode - used)
├── src/
│   ├── calibration.py      (Temperature scaling)
│   └── evaluation.py       (ECE computation + visualization)
\end{verbatim}

The implementation generates five figures: (1) ECE comparison, (2) reliability diagram, (3) confidence distribution, (4) optimization convergence, (5) per-bin error.

\subsubsection{Relationship to Production Experiments}

A production experiment would replace simulated logits with actual Code Llama 7B outputs obtained by:
\begin{enumerate}
\item Loading Code Llama 7B (meta-llama/CodeLlama-7b-hf)
\item Generating one code solution per MBPP problem
\item Executing generated code against test cases
\item Extracting logits and computing max-softmax confidence
\end{enumerate}

The simulation validates that steps after logit extraction (temperature optimization, ECE computation, visualization) function correctly. Logit generation is the only component not validated.
