
Three research questions structure the experiments:

\textbf{RQ1:} Is the 134-problem EvalPlus failure set fully recoverable from archive for reproducible repair experiments?

\textbf{RQ2 (pre-registered):} Does specification-aligned repair (Condition C) achieve significantly higher round-1 pass@1 than blind reprompting (Condition B)?

\textbf{RQ3 (pre-registered, exploratory):} Does the HumanEval+ fix rate exceed the MBPP+ fix rate under Condition C?

\subsubsection{4.3 Evaluation Metrics}

\textbf{Primary:} Round-1 pass@1 --- binary pass or fail per problem; all EvalPlus augmented tests must pass, not only the prompted failing test.

\textbf{Secondary:} Fix rate (proportion of working-set problems fixed under Condition C; threshold 15\%), token efficiency ratio (fix rate per 1000 additional input tokens relative to Condition A).

\subsubsection{4.4 Implementation Details}

\begin{itemize}
\item Model: GPT-4o-mini (OpenAI API), temperature = 0.2, seed = 42
\item Test selection: \texttt{plus\textbackslash \_input[0]} (deterministic, pre-registered)
\item Evaluation oracle: EvalPlus augmented test suite (all tests must pass for a pass verdict)
\item EvalPlus version: 0.3.1
\item Estimated cost for mechanism experiments: approximately \$0.05 USD (256 API calls total)
\item Hardware: $5\times$ NVIDIA H100 NVL (not used for existence verification; mechanism experiments require CPU and network only)
\end{itemize}
