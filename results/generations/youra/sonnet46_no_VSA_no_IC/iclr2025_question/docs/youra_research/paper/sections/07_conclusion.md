# Conclusion

We began with a simple observation: every autoregressive LLM computes token log-probabilities for free during generation, and aggregating them into a single confidence score is a universal step in zero-cost hallucination detection — yet no systematic study had asked whether the aggregation function choice matters and why. The answer is that it matters by up to 12 AUROC points, and the reason is mechanistic.

The optimal aggregation function is determined by the hallucination type. Recall-failure hallucinations concentrate uncertainty at a single worst-case token, making the minimum log-probability the maximally discriminative statistic. Imitative-falsehood hallucinations distribute uniform confidence throughout the generated sequence, making the mean log-probability the appropriate integration of distributed uncertainty. This three-step mechanism — hallucination type → distribution shape → aggregation optimality — is confirmed at three independent measurement levels across two model families.

Our main contributions are:

1. **A principled aggregation selection criterion** for zero-cost hallucination detection: use min log-probability for factual recall tasks (TriviaQA-type); use mean log-probability for imitative-falsehood tasks (TruthfulQA-type). Confirmed with AUROC differentials of 0.056–0.119 (factual recall) and 0.111–0.120 (imitative falsehood), both with bootstrap 95% CIs excluding zero, across LLaMA-2-7B and Mistral-7B-v0.1.

2. **Direct distributional evidence** for the mechanism's first step: hallucinated responses on TriviaQA show significantly higher token distribution peakedness than correct responses (ratio 2.936 vs. 2.533, p = 0.002, n = 488), converting the peaked/flat taxonomy from assumption to measured fact.

3. **An unexpected zero-cost detection result**: raw unnormalized log-probability sum achieves the highest AUROC on TriviaQA (0.895–0.896), exceeding both normalized aggregations and surpassing published multi-sample Semantic Entropy (≈0.79) at one-tenth the inference cost. Sequence-level joint probability is an underexplored factual-recall hallucination signal that warrants further investigation.

**Future Directions.** Three immediate paths emerge from this work. First, NQ completion: re-running inference on Natural Questions with existing code would complete P1 verification across both factual-recall benchmarks within the current 7B model regime. Second, length stratification: the `length_stratified_auroc` function in h-e1 is implemented but unexecuted — running it would determine whether raw_sum's advantage on TriviaQA is a genuine sequence-level calibration signal or a length-confidence confound, resolving the most important open question raised by our P3 refutation. Third, adaptive aggregation: given that optimal aggregation is benchmark-type-dependent, a lightweight unsupervised classifier based on observed token distribution shape (e.g., peakedness ratio) could provide type-agnostic zero-cost detection without requiring prior knowledge of the hallucination class. This application of our mechanism would represent a natural next step from mechanism confirmation to mechanism-guided system design.

The question we started with has a concrete answer: the best token log-probability aggregation function for hallucination detection depends on what kind of hallucination you expect — and that choice is now principled, not arbitrary. The token log-probability sequence contains more structure than is typically exploited, and reading that structure correctly costs nothing.
