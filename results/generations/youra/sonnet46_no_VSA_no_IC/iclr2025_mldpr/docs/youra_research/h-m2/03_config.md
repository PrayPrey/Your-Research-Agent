## H-M2 Configuration

```python
# config.py
from dataclasses import dataclass, field, asdict
import json
from pathlib import Path

@dataclass
class H_M2_Config:
    # Statistical test parameters
    alpha: float = 0.05                        # BF test significance threshold
    variance_ratio_threshold: float = 1.0      # gate: var_post / var_pre < 1.0
    min_segment_size: int = 3                  # early-fail guard
    center: str = "median"                     # Brown-Forsythe (NOT 'mean')
    random_seed: int = 42

    # Output paths
    figures_dir: str = "docs/youra_research/h-m2/figures"
    results_json_path: str = "docs/youra_research/h-m2/results/h_m2_results.json"

    # Input reference (from h-m1)
    h_m1_results_path: str = "docs/youra_research/h-m1/results/coverage_report.json"

    # Figure specs (consistent with h-m1)
    figure_dpi: int = 150
    figure_size: tuple = field(default_factory=lambda: (8.0, 5.0))

    def save_yaml(self, path: str) -> None:
        import yaml
        d = asdict(self)
        Path(path).parent.mkdir(parents=True, exist_ok=True)
        with open(path, "w") as f:
            yaml.dump(d, f, default_flow_style=False)

    def save_json(self, path: str) -> None:
        d = {k: v for k, v in asdict(self).items()}
        Path(path).parent.mkdir(parents=True, exist_ok=True)
        with open(path, "w") as f:
            json.dump(d, f, indent=2)

CONFIG = H_M2_Config()
```

## Notes

- No hyperparameter grid — fixed statistical test, single config.
- `center: "median"` is non-standard default; Brown-Forsythe requires it (not `"mean"` which gives Levene).
- `variance_ratio_threshold: 1.0` is the exact boundary value; use `<` (strict) in gate logic.
- `save_yaml` / `save_json` included for reproducibility logging; no external dep beyond stdlib + PyYAML (already used in scipy environments).
