## 1. Executive Summary

H-M2 tests whether fairness rank stability (partial ρ_fairness: BBQ-Disambig→BBQ-Ambig, MMLU-controlled) is higher than adversarial robustness rank stability (partial ρ_robustness: GLUE→AdvGLUE and ANLI R1→R3, MMLU-controlled) by a margin Δρ ≥ 0.2. The theoretical mechanism: adversarial benchmark construction specifically targets models that pass the in-distribution version, systematically disrupting rank ordering more than distributional underspecification does for fairness.

Using TrustLLM (Huang et al., ICML 2024) per-model scores for the same N_common overlapping LLMs established by H-E1/H-M1, the experiment extends the h-m1 DataFrame with robustness columns (GLUE, AdvGLUE, ANLI-R1, ANLI-R3) and computes three partial Spearman ρ values (MMLU-controlled), then tests Δρ significance via a Fisher z-test for the difference between two independent correlations.

**Scope:** Robustness data extraction from TrustLLM, DataFrame extension, three partial ρ computations, Δρ calculation, Fisher z-test for difference, sensitivity analysis (Winogrande control), visualization. No model training. Pure statistical meta-analysis extending h-m1 infrastructure.

**Prerequisite:** H-M1 PASS (VALIDATED) — partial ρ_fairness > 0.4, p < 0.05 confirmed; h-m1 DataFrame and pingouin methodology reused.

## 2. Problem Statement

LLM trustworthiness benchmarks assess models under various conditions. H-M1 established that fairness failures are stable across context conditions (BBQ-Disambig vs. BBQ-Ambig). H-M2 asks whether this stability is *greater* than adversarial robustness stability — i.e., whether adversarial benchmark construction specifically disrupts rank ordering more than distributional underspecification does for fairness.

**Theoretical motivation:** Adversarial benchmark construction (AdvGLUE, ANLI-R3) explicitly selects examples that fool models passing the in-distribution benchmark, creating a systematic adversarial selection pressure. This should disrupt rank stability more than the ambiguity shift in BBQ.

**Gate Condition (SHOULD_WORK):** Δρ = partial_ρ_fairness − mean(partial_ρ_AdvGLUE, partial_ρ_ANLI) ≥ 0.2
**Failure Mode:** CONTINUE — document as limitation ("dimension asymmetry not detected at threshold"), proceed to H-M3. H-M1 result remains valid regardless.

### FR-3: Statistical Analysis

**FR-3.1 — Raw Δρ (Baseline — No Control)**
- Compute raw Spearman ρ per dimension without MMLU control (scipy.stats.spearmanr)
  - ρ_fair_raw: spearmanr(bbq_disambig, bbq_ambig)
  - ρ_advglue_raw: spearmanr(glue_score, advglue_score)
  - ρ_anli_raw: spearmanr(anli_r1_score, anli_r3_score)
- Δρ_raw = ρ_fair_raw − mean(ρ_advglue_raw, ρ_anli_raw)
- Report: all raw ρ values and Δρ_raw

**FR-3.2 — Partial ρ_fairness (MMLU-Controlled, Recomputed on N_common_robust)**
- Recompute on N_common_robust subset (may differ slightly from h-m1 if some models dropped)
- `pingouin.partial_corr(data=df, x='bbq_disambig', y='bbq_ambig', covar=['mmlu'], method='spearman', alternative='two-sided')`
- Report: rho_fairness, p_fairness, CI95%, n_fair

**FR-3.3 — Partial ρ_AdvGLUE (MMLU-Controlled)**
- `pingouin.partial_corr(data=df, x='glue_score', y='advglue_score', covar=['mmlu'], method='spearman', alternative='two-sided')`
- Report: rho_advglue, p_advglue, CI95%

**FR-3.4 — Partial ρ_ANLI (MMLU-Controlled)**
- `pingouin.partial_corr(data=df, x='anli_r1_score', y='anli_r3_score', covar=['mmlu'], method='spearman', alternative='two-sided')`
- Report: rho_anli, p_anli, CI95%

**FR-3.5 — Δρ Computation**
- rho_robust_mean = mean(rho_advglue, rho_anli)
- delta_rho = rho_fairness − rho_robust_mean
- Report: delta_rho, rho_robust_mean

**FR-3.6 — Fisher z-Test for Difference Between Two Correlations**
- Implement independent_corr formula (psinger/CorrelationStats):
  ```python
  z_fair = 0.5 * np.log((1 + rho_fairness) / (1 - rho_fairness))
  z_rob  = 0.5 * np.log((1 + rho_robust_mean) / (1 - rho_robust_mean))
  se_diff = np.sqrt(2 / (n_fair - 3))   # same N for all pairs
  z_stat  = (z_fair - z_rob) / se_diff
  p_val   = 2 * (1 - norm.cdf(abs(z_stat)))  # two-tailed, exploratory
  ```
- Guard: if |rho_fairness| > 0.999 or |rho_robust_mean| > 0.999 → fallback to Kendall τ
- Report: z_stat, p_value (two-tailed)
- Label as EXPLORATORY in all outputs

**FR-3.7 — Gate Evaluation**
- Primary gate: delta_rho >= 0.2
- Secondary: rho_advglue < rho_fairness AND rho_anli < rho_fairness (both individually)
- Tertiary: p_value < 0.10 (lenient exploratory threshold)
- Log: gate_directional = True/False; label PASS or FAIL with "SHOULD_WORK: failure does not stop pipeline"

**FR-3.8 — Sensitivity Analysis (Winogrande Control)**
- Repeat FR-3.2, FR-3.3, FR-3.4 with Winogrande as covariate instead of MMLU
- Compute Δρ_winogrande
- Compare: Δρ_winogrande ≈ Δρ_mmlu (within 0.1 → robustness confirmed)
- Report: all Winogrande-controlled ρ values and Δρ_winogrande
