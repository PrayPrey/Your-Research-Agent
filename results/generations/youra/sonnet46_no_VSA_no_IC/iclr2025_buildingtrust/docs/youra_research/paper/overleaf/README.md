## Compilation (Overleaf)

1. Download `icml2025.sty` from https://icml.cc/Conferences/2025/StyleAuthorInstructions
2. Create new Overleaf project
3. Upload all files (maintaining folder structure)
4. Place `icml2025.sty` in root directory
5. Set compiler to pdfLaTeX
6. Compile

## Notes

- ICML 2025 style file (`icml2025.sty`) must be downloaded separately and placed in the root directory
- Without `icml2025.sty`, compilation will fail; fall back to `\documentclass[12pt]{article}` for draft mode
